# Live Matches

> Watch live sports and events from aggregated stream sources.

## What it is

Live Matches pulls schedules and streams from **Forja Live** engine catalogs (Streamed, PPV, StreamFree by default; TimStreams, ESPN, … optional), installed **Stremio** sport addons, and **Forja Sports** — the same enabled **Catalog** JS schedule as Forja Live, matched to channels on your own Xtream portal. Browse by sport category, pick a match, and watch in the native IPTV player. Some third-party streams cannot be replayed in the native mpv player because their HLS URLs are session-bound.

## How to open it

Tap **Live Sports** in the navigation bar.

## What you can do

- Use the **server** button (label shows **Forja Live**, **Forja Sports**, or **Stremio**) to switch sources. **Forja Live** ↔ **Forja Sports** keeps the match list (same Catalog schedule — only play path changes); **Stremio** loads its own schedule. Legacy PPV / Streamed / MutStreams catalog rows are hidden from the sheet; a saved preference for a hidden row clamps back to **Forja Live**. Forja remembers the last choice across app restarts. Next to it, a matching **Catalog** button (label shows **All**, **PPV**, **Streamed**, …) filters the Forja Live / Forja Sports schedule by engine catalog. A **schedule** button next to that opens one sheet with **Status** (**Airing** / **Upcoming** / **Airing + upcoming**) and **Horizon** (**1h** / **3h** / **6h** / **24h**). Chip label is **Airing**, **Next · 3h**, or **1h** (default: Airing + upcoming · 1h). **Airing** is in-play and 24/7 only — including catalog rows that are airing but still have no streams. Horizon applies when upcoming is included; widening it re-fetches catalogs, narrowing or changing Status only filters what is already loaded. Idle server / Catalog / schedule stay neutral; **hover** (desktop) and **D-pad focus** (TV) brighten the chip the same way as IPTV **Portals** (green ring when focused). **Forja Live** and **Forja Sports** load the same enabled engine catalogs — **default on:** Streamed, PPV, StreamFree (TimStreams, ESPN, … stay available in Settings → Forja Sports). Picking one catalog loads only that source; **All** loads every enabled catalog. Once a catalog finishes loading, it stays cached for the session — switching catalogs or back to **All** does not drop or re-fetch it (Refresh clears the cache). ESPN also enriches other catalogs with team names when **Catalog → ESPN** is on in Settings and catalog **All** (or ESPN) is selected. Opening a **Forja Live** card resolves streams through the paired live plugin into the native player (**Engine** resolve; on miss shows an error toast — never the site embed player). Opening a **Forja Sports** card matches channels on your Xtream portal. **Forja Sports** is on by default with all leagues matched.
- Switch sport category circles (centered on desktop and TV). **24/7** covers always-on channels from catalogs that expose them (no schedule date — e.g. Willow Cricket, Tennis Channel, Rally TV). Those appear only on the 24/7 chip — hidden from All and from other sports (card grid and timeline) — and stay tappable as LIVE
- On **phone / desktop**, switch between **card view** and **timeline view** with the button to the right of Refresh. Timeline is the default; Forja remembers this choice across app restarts. Timeline view places each **1-hour** group on a continuous clock — a 00:10 card sits at 00:00 on the ruler (not stuck at the top). Same-hour streams share one horizontal line (swipe sideways for more without moving time). Opening the timeline (or switching to it / reloading) lands on **now**, not the first card; click the playhead time badge to jump back to now anytime. Vertical scroll moves the clock; **Day / 12h / 6h** set how many hours one screen height covers. The ruler tints each day a different colour (today stays white), and a green **NOW** line marks the current time. Hovering a card highlights it in place and lifts just that card above overlapping neighbours (no scale). **Miscellaneous / Other** events that are still airing (e.g. a stage race that started hours ago) stay pinned on the NOW line instead of sitting in the past.
- On **TV (Android TV / leanback)**, Live Matches is **cards only** — no timeline view and no view toggle. The server sheet lists the same sources as desktop (**Forja Live**, plus **Forja Sports** / **Stremio** when enabled) — not a trimmed TV-only set. A saved preference for a hidden server is clamped to **Forja Live**; the IPTV **Portals** button appears on **Forja Sports**. Forja Live and Forja Sports cards share the green source badge (TimStreams, StreamFree, …); pick a catalog from the **Catalog** top-bar button and schedule Status/Horizon from the **schedule** button (**Airing** / **Upcoming** / **Airing + upcoming**, plus **1h**–**24h**). Opening a **Forja Live** match opens the right-side **Sources** panel with that catalog’s plugin streams — rows appear from the catalog immediately (same as desktop); Engine unlock runs when you pick a row. Never the Forja Sports Xtream matcher. With **Catalog → PPV**, only PPV rows appear (labeled **PPV**); other catalogs stay scoped to the selected plugin. Opening **Forja Sports** opens the Xtream channel panel. The TV multi-source picker for Forja Sports ∪ Stremio still applies on non–Forja Live servers. Forja Sports finishes matching first, then Stremio fills in (avoids overloading leanback sets). Match and channel tiles are **landscape** (same continue-watching width, 16:9 art + title/league under — not square/portrait IPTV poster cells). Sport category circles are **centered** and scaled to fit when needed (same as Anime / Home mood rows). D-pad moves **server → Catalog → schedule → Portals (Forja Sports) → Refresh → sport chips → match cards**. **↑** from sport chips returns to the **Servers** button (or Catalog / schedule when those are shown — including after choosing **Stremio**). Focused server / Catalog / schedule use the same brand-green focus chrome as **Portals**; focused **Refresh** turns white. Activating **Refresh** keeps D-pad focus on **Refresh** after the catalog reloads. Picking a server, catalog, or schedule option keeps focus on that top-bar button. Within the card grid, **←/→** stay on the current row (row ends do not wrap). **↑** from the first card row returns to sport chips, then the schedule / Catalog / server buttons (not skipping past them). **←** from the left edge of a row returns to the nav rail. Empty lists autofocus **Refresh**. Entering the tab restores the last grid focus
- Browse upcoming and live events — live matches appear first. Only **live** matches are tappable and show the play button (green and floated upward, with a slowly pulsing play icon, on hover/focus). Upcoming cards still highlight and lift on hover in the timeline; they show the start time badge only. **Card view** shows start–finish (or kickoff only) above the match title when schedule data is available. Catalogs that report concurrent viewers (PPV, StreamFree, TimStreams, …) show a viewer count on the card; when the same event is merged across catalogs, the counts are **added**. Merging treats PPV-style **Away at Home** and Streamed-style **Home vs Away** as the same fixture (team order / connector do not matter). Opening a live card always opens the stream picker — if nothing resolved, the panel says **No streams available** (cards do not show a separate “Not yet available” badge). The stream picker header totals viewers across every listed stream (per-stream when the source provides it, otherwise each catalog’s audience once); rows show the same. Card and timeline views refresh ● LIVE badges about once a minute while the tab is open.
- Open a match and watch the stream in the **native IPTV player**. **Forja Live** resolves through the live sport plugin (**Engine**). On **desktop**, Streamed GOAT, PPV embedindia GASM, and WatchFooty sportsembed unlocks use a local Node worker; on **Android / Android TV**, GOAT/GASM run in an off-screen WebView (`lock.wasm` / `gasm.wasm`) when Node is missing, and **Streamed** playback keeps that WebView alive as a CDN proxy so ExoPlayer never re-fetches `strmd.st` directly (native re-GETs fail with 403/503). **WatchFooty** catalogs all sports (not football-only) with posters; Engine unlocks every sportsembed source variant to HLS in parallel (CDN-dead rows dropped; no site embed player). **Stremio** sport streams that return direct HTTP(S) HLS open immediately (premium / bait links are skipped). On **Android / Android TV**, those Stremio streams keep addon request headers so ExoPlayer can demux HLS URLs that omit a `.m3u8` suffix. **Forja Sports** ranks matched channels by confidence (4K + both teams, both in name and EPG, both combined, then nickname-only), opens a **right-side channel panel** immediately while searching (phase labels like **Searching Forja Sports…**, skeleton placeholders, then channels appear as they land — same flat **Sources**-style rows as movies: logo, title, category on the right, **T1–T4** as meta chips), then opens the chosen channel in the native IPTV player (other matches stay available under **Source** with the same row layout). Hover or focus a channel row for a moment to **alive-check** it — left green/red bar like the movie Sources panel (same probe as IPTV Live). Matched channels for a game stay cached **30 minutes** so re-opening the same card does not re-search the portal.
- Back / Escape exits the player and **stops audio**. On **Android TV**, remote **Back** twice leaves; remote **Exit** is separate
- On **Android TV**, pressing **Home** (or switching to another app) **pauses** the live stream; returning to Forja resumes. Desktop can keep playing in the background.
- When a **Forja Live** match has several streams, opening the card shows step-by-step loading (**Finding streams…**, **Checking sources…**, **Building stream list…**) while catalog mirrors load in parallel, drops dead listings, and shows one merged picker — TimStreams rows and so on — sorted by viewer count (busiest first). Tap a row to play in the native IPTV player; the loading dialog advances through **Unlocking source…**, **Preparing playback…**, and **Loading other servers…** when needed. On miss, a toast appears. On **TV**, the first row autofocuses; **↑/↓** moves the list. Rows use the same flat movie **Sources** tile (fill + soft border on hover/focus, **HD** / viewer meta chips, provider on the right) — same for the **Servers** picker. **Forja Live**, **Stremio**, and **Forja Sports** multi-source sessions in the native player share the same **Source** menu: the row that is playing shows **Playing**, scrolls into view when you open the menu, and on TV takes D-pad focus first (**↑/↓** / **OK** to switch)
- Double-click the video to enter/exit fullscreen on desktop. On **TV**, there is no fullscreen button — the player is already immersive
- Refresh lists for new events

## Tips

- Streams are third-party — availability changes with broadcasts and region
- Escape still backs out of the player on all platforms (and stops the stream)
- The **Stremio** server chip uses your saved Live assignment + sport catalogs on disk — opening Live Sports does not re-fetch every installed VOD addon first. Opening **Stremio** itself refreshes only Live-assigned addons.
