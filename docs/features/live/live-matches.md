# Live Matches

> Watch live sports and events from aggregated stream sources.

## What it is

Live Matches pulls schedules and streams from **Forja Live** engine catalogs (Streamed, PPV, StreamFree by default; TimStreams, ESPN, … optional), installed **Stremio** sport addons, and **Forja Sports** — the same enabled **Catalog** JS schedule as Forja Live, matched to channels on your own Xtream portal. Browse by sport category, pick a match, and watch in the native IPTV player. Some third-party streams cannot be replayed in the native mpv player because their HLS URLs are session-bound.

## How to open it

Tap **Live Sports** in the navigation bar.

## What you can do

- Use the **server** button (label shows **Forja Live**, **Forja Sports**, or **Stremio**) to switch sources. Legacy PPV / Streamed / MutStreams catalog rows are hidden from the sheet; a saved preference for a hidden row clamps back to **Forja Live**. Forja remembers the last choice across app restarts. Next to it, a matching **Catalog** button (label shows **All**, **PPV**, **Streamed**, …) filters the Forja Live / Forja Sports schedule by engine catalog. A **time** button next to that (**Live** / **1h** / **3h** / **6h** / **All**, default **1h**) limits how far ahead catalogs load and what appears in the grid — **Live** is airing and 24/7 only; wider windows also keep live and 24/7 visible. Widening the window (e.g. **3h** → **6h**) re-fetches catalogs; narrowing only filters what is already loaded. **Forja Live** and **Forja Sports** load the same enabled engine catalogs — **default on:** Streamed, PPV, StreamFree (TimStreams, ESPN, … stay available in Settings → Catalog). Picking one catalog loads only that source; **All** loads every enabled catalog. Once a catalog finishes loading, it stays cached for the session — switching catalogs or back to **All** does not drop or re-fetch it (Refresh clears the cache). ESPN also enriches other catalogs with team names when **Catalog → ESPN** is on in Settings and catalog **All** (or ESPN) is selected. Opening a **Forja Live** card resolves streams through the paired live plugin into the native player (**Engine** resolve; on miss shows an error toast — never the site embed player). Opening a **Forja Sports** card matches channels on your Xtream portal. **Forja Sports** is on by default with all leagues matched.
- Switch sport category circles (centered on desktop and TV). **24/7** covers always-on channels from catalogs that expose them (no schedule date — e.g. Willow Cricket, Tennis Channel, Rally TV). Those appear only on the 24/7 chip — hidden from All and from other sports (card grid and timeline) — and stay tappable as LIVE
- On **phone / desktop**, switch between **card view** and **timeline view** with the button to the right of Refresh. Timeline is the default; Forja remembers this choice across app restarts. Timeline view places each **1-hour** group on a continuous clock — a 00:10 card sits at 00:00 on the ruler (not stuck at the top). Same-hour streams share one horizontal line (swipe sideways for more without moving time). Opening the timeline (or switching to it / reloading) lands on **now**, not the first card; click the playhead time badge to jump back to now anytime. Vertical scroll moves the clock; **Day / 12h / 6h** set how many hours one screen height covers. The ruler tints each day a different colour (today stays white), and a green **NOW** line marks the current time. Hovering a card highlights it in place and lifts just that card above overlapping neighbours (no scale). **Miscellaneous / Other** events that are still airing (e.g. a stage race that started hours ago) stay pinned on the NOW line instead of sitting in the past.
- On **TV (Android TV / leanback)**, Live Matches is **cards only** — no timeline view and no view toggle. The server sheet lists the same sources as desktop (**Forja Live**, plus **Forja Sports** / **Stremio** when enabled) — not a trimmed TV-only set. A saved preference for a hidden server is clamped to **Forja Live**; the IPTV **Portals** button appears on **Forja Sports**. Forja Live and Forja Sports cards share the green source badge (TimStreams, StreamFree, …); pick a catalog from the **Catalog** top-bar button and a schedule window from the **time** button (**Live** / **1h** / **3h** / **6h** / **All**). Opening a match from Forja Live stays on plugin sources; Forja Sports opens the Xtream channel panel. The TV multi-source picker for Forja Sports ∪ Stremio still applies where that flow is used. Forja Sports finishes matching first, then Stremio fills in (avoids overloading leanback sets). Match and channel tiles are **landscape** (same continue-watching width, 16:9 art + title/league under — not square/portrait IPTV poster cells). Sport category circles are **centered** and scaled to fit when needed (same as Anime / Home mood rows). D-pad moves **server → Catalog → time → Portals (Forja Sports) → Refresh → sport chips → match cards**. Focused server / Catalog / time use a white focus border; **Portals** keeps brand-green focus; focused **Refresh** turns white. Within the card grid, **←/→** stay on the current row (row ends do not wrap). **↑** from the first card row returns to sport chips, then the time / Catalog / server buttons (not skipping past them). **←** from the left edge of a row returns to the nav rail. Empty lists autofocus **Refresh**. Entering the tab restores the last grid focus
- Browse upcoming and live events — live matches appear first. Only **live** matches are tappable and show the play button (green and floated upward, with a slowly pulsing play icon, on hover/focus). Upcoming cards still highlight and lift on hover in the timeline; they show the start time badge only. Opening a live card always opens the stream picker — if nothing resolved, the panel says **No streams available** (cards do not show a separate “Not yet available” badge). Card and timeline views refresh ● LIVE badges about once a minute while the tab is open.
- Open a match and watch the stream in the **native IPTV player**. **Forja Live** resolves through the paired live plugin (**Engine**). **Stremio** sport streams that return direct HTTP(S) HLS open immediately (premium / bait links are skipped). On **Android / Android TV**, those Stremio streams keep addon request headers so ExoPlayer can demux HLS URLs that omit a `.m3u8` suffix. **Forja Sports** ranks matched channels by confidence (4K + both teams, both in name and EPG, both combined, then nickname-only), opens a **right-side channel panel** immediately while searching (phase labels like **Searching Forja Sports…**, skeleton placeholders, then channels appear as they land — same flat **Sources**-style rows as movies: logo, title, category on the right, **T1–T4** as meta chips), then opens the chosen channel in the native IPTV player (other matches stay available under **Source** with the same row layout). Hover or focus a channel row for a moment to **alive-check** it — left green/red bar like the movie Sources panel (same probe as IPTV Live). Matched channels for a game stay cached **30 minutes** so re-opening the same card does not re-search the portal.
- Back / Escape exits the player and **stops audio**. On **Android TV**, remote **Back** twice leaves; remote **Exit** is separate
- On **Android TV**, pressing **Home** (or switching to another app) **pauses** the live stream; returning to Forja resumes. Desktop can keep playing in the background.
- When a **Forja Live** match has several streams, opening the card **Resolving streams…** loads catalog mirrors in parallel, drops dead listings, and shows one merged picker — TimStreams rows and so on — sorted by viewer count (busiest first). Tap a row to play in the native IPTV player via GOAT/`/hls-proxy`, or toasts on miss. On **TV**, the first row autofocuses; **↑/↓** moves the list. Focused rows use a flat highlight (background fill, no zoom) with bold white title text — same for the **Servers** picker. **Stremio** matches with several streams instead open in the native player, where the **swap** control in the bottom row opens the **Source** menu (on TV it centers, focuses the stream that is playing, and takes **↑/↓** / **OK**)
- Double-click the video to enter/exit fullscreen on desktop. On **TV**, there is no fullscreen button — the player is already immersive
- Refresh lists for new events

## Tips

- Streams are third-party — availability changes with broadcasts and region
- Escape still backs out of the player on all platforms (and stops the stream)
