# Playback speed

> Watch faster or slower — from 0.25× to 2×.

## What it is

Adjust how fast video plays without changing pitch (within player limits). Useful for lectures, slow scenes, or binge-watching at 1.25×.

## How to open it

Open the speed control from the player menu during playback.

## What you can do

- Select preset speeds (typically 0.25× through 2×)
- Return to normal 1× speed anytime

## Tips

- Speed changes apply to the current session; not all stream types support every speed on every platform
- Audiobooks have their own speed control in the audiobook player
