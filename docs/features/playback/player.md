# Player

> One player for movies, series, IPTV, and more — desktop and mobile.

## What it is

Forja routes all video playback through a unified player. Controls use a flat overlay (no glass chrome):

- **Top bar** — back arrow (muted until hover or D-pad focus, then white), centered title, **S# E#** for TV episodes, and **Player**, **Cast**, and **PiP** on the top right (platform-gated; Android TV shows **Player** only)
- **Paused overlay** — show logo, rating/year meta, and synopsis on the left when playback is paused (when TMDB metadata is available)
- **Center actions** — large play/pause and ±10s buttons in the middle while controls are visible; hidden while checking sources or buffering (status roulette takes the center instead)
- **Status roulette** — center-right slide-up indicator when checking sources, switching servers, or buffering (no bottom snackbars). Episode switches and mid-playback torrent/magnet switches use a separate bottom-right loading card instead (current video keeps playing until the new stream is ready). If every source fails, the detailed failure and Retry / Stream actions appear once under the centered title
- **Episode switch card** — compact translucent card at bottom-right above the seek bar (no border, no full-screen dim) when picking another episode, Next/Previous, or another torrent/magnet: label plus live status (`Loading episode info…`, `Checking sources…`, `Starting Local Torrent Engine…`, `Opening stream…`). Video stays visible behind it until the new stream is ready
- **Bottom bar** — full-width seek bar, then play/pause, ±10s, volume, and **current / total** time on the left; **Sources** (link/magnet icon — torrent / Stremio / Nuvio catalog panel when playing a magnet **or** a Stremio Direct / Nuvio stream; same as media-details Sources, including the **Nuvio** kind chip when Direct torrent scrapers are enabled). While Sources is available for that session the flat **Source** server picker (layers + name + chevron) stays hidden so catalog playback is not duplicated as a “server”. **Source** appears only for web/anime/drama streams. Then episodes (TV), audio, subtitles, quality, settings, and fullscreen on the right. On desktop torrent playback, when **Settings → Torrent stats** is on, a transparent stats card sits bottom-right above the seek bar while controls are visible (download/upload speed, peers, download size/%, ETA). It lifts above Skip Intro / Next Episode when those buttons are showing. Seeders show as — unless indexer metadata is available later — librqbit does not expose a live seeder count.
- **Floating menus** — audio, subtitles, quality, servers, player, and settings open as compact popup panels anchored to the button you tapped (above or below, depending on space). Menus use a flat dark shell with **brand-green** selected chips (green fill / dark text) and green-tinted list selection. Options sit **directly under the panel header** (icon + title + close) — no nested cards. **Quality** is a row of segmented chips; **Audio** and **Servers** are full-width chips; **Player** lists full-width chips under muted **Built-in** / **External app** labels. **Subtitles** shows Off in the header, then embedded in-stream tracks (when present), a **Load from file** row, and one drill-in row per online-subtitle language (with a count). **Settings** is a drill-in list — each parameter (Auto selection, Video decode, Playback speed, Aspect ratio, Loop, and Torrent stats on desktop torrent) is a row with its current value; tapping opens that parameter's own second page showing just its chips under the header. Subtitle style lives in the **Subtitles** menu (tune icon in its header), not in Settings. The **Back** control (muted until hover or D-pad focus, then white) returns to the parent list. Dismiss with the outlined square **Close** control in the menu header
- **Episodes / Sources / Source panels** — TV **Episodes**, torrent **Sources** (magnet button), and web **Source** (server picker) open right-side panels. Player **Episodes**, **Sources**, **Source**, and **Filters** use a translucent dark shell (no freeze-frame image; no BackdropFilter over live video). **Filters** opens docked to the left of Sources only when you tap the tune control (Filters only covers the area left of Sources so source rows stay tappable); closing Sources dismisses Filters. **Source** lists servers with status glyphs — tap a server to load its streams in parallel. Selected and currently **playing** rows use the same brand-green accent as floating menus. The **Episodes** top bar has a brand-green **Season** pill (when the show has multiple seasons), a combined **Search** field + **Auto next** switch (skip-next icon), and a squared **Close** control. A range dropdown (**1 - 50**, **51 - 100**, …) appears below when the list is long. Episode rows show thumbnails, air date (orange when not yet aired), show backdrop with dim overlay on not-yet-aired thumbnails, runtime, synopsis, and resume progress. Not-yet-aired episodes stay visible but cannot be opened.

Seek bar uses Forja brand green for the played fill and thumb across the main player, trailer player, ExoPlayer chrome, IPTV VOD, music, and audiobook players. On desktop the thumb stays on the playhead; hover shows a timestamp (and a current-frame thumbnail when available — preview never seeks) and a click on the bar seeks. **Source** is one flat bottom-right control showing the active server name; tap it for the grouped list. The player handles torrent streams, direct HLS/MP4 links, debrid URLs, Jellyfin, and hub content.

On **Android**, when **Settings → Playback → Built-in engine** is **ExoPlayer**, the same flat overlay chrome applies (top bar, paused hero, center actions, status roulette, bottom seek bar). **Sources** opens a **two-column** dialog (left = servers, right = streams for the selected server — check a server to load/probe its streams, then pick a stream to play). **Episodes** (hub or TMDB), **Audio**, **Subtitles**, **Quality**, lean **Settings** (speed + fit), and **Player** open the same floating popup panels as MediaKit. Exo **Subtitles** lists in-stream text tracks plus online languages (Wyzie / Levrx / scrapers / addons) and provider sideloads (e.g. Asian Drama local SRT/VTT); picking a language downloads and applies it without leaving playback. **PiP** and **Cast** are hidden on Exo. ASS subtitle styling, seek preview, torrent localhost, the catalog link **Sources** panel, and a separate audio URL still need **MediaKit**. ExoPlayer draws through a TextureView so the Flutter embed stays a single coherent frame (SurfaceView inside the platform view tiled or shifted the picture on Android TV). **IPTV live** on Android uses the same Settings engine choice; with Exo it keeps a deeper live buffer (no forced soft 720p/1080p bitrate cap). Home/Search movie opens are unchanged.

On **Android TV**, **MediaKit** uses **MediaCodec embed** output (`vo=mediacodec_embed`) with Flutter Impeller disabled (Skia) so frames hit the Flutter surface without mpv OpenGL — Impeller + `vo=gpu` was audio-only / black on leanback (and ATV emulators hit `EGL_BAD_ATTRIBUTE`). Phones keep Impeller; phone MediaKit still prefers software decode when you pick MediaKit over Exo.

On **Android TV** (MediaKit or ExoPlayer), D-pad moves focus between chrome controls instead of remote playback shortcuts. Focus order: **back** and top-right **Player** (engine / external-player switch — Cast and PiP are hidden on TV), then the **progress bar**, then the bottom transport row split like desktop — **play/pause**, ±10s, volume on the left; **Sources**, **Source**, **Episodes**, audio, subtitles, quality, settings, lock on the right — then **Skip Intro** / **Next Episode** when shown. **IPTV** on TV uses the same green focus chrome for top-right **Player** / source / stats / PiP as the movie player. Trailer chrome on TV matches the same split: play / ±10s / mute left, audio / subtitles / quality / speed right; when there are multiple trailers, a **More videos** card sits bottom-right (←/→ slides previews, **OK** plays). The focused control turns **green** (icon, soft fill, outline) with no scale lift. On the progress bar: **OK** selects the thumb, **←/→** nudge the preview, **OK** commits the seek (**Back** cancels); **↑** from the bar focuses **Next Episode** or **Skip Intro** when those chips are showing, otherwise the top **back** control. Hardware **volume** keys adjust player volume even while chrome is focused; when chrome is hidden, D-pad **↑/↓** also adjust volume. Audio, subtitles, quality, settings, episodes, and **Source** menus or panels take D-pad focus when opened (focus lands on the **currently selected** option when there is one, otherwise the first; **↑/↓/←/→** walk one option per press inside the menu only — not the player chrome; focused row uses a gray fill + thin border with no scale; **OK** picks; **Back** closes and returns focus to the chrome button that opened the menu). **Subtitle settings** (from the subtitles menu) is a D-pad focusable dialog — **OK** on a slider arms it, then **←/→** nudge (**OK** commits, **Back** cancels); color / font chips, delay ±, and Bold need **OK** to change; **Back** closes the dialog when nothing is armed (then focus returns to the Subtitles button). App **toasts** (top-right status messages) expose focusable **action** and **dismiss** controls on TV. **Episodes** on TV opens focused on the **playing** episode; **↑/↓** moves between episode rows (**OK** plays); **↑** from the first episode focuses **Season** (when shown) or **Search**; **OK** on Season opens the season menu; **→** from Season reaches **Search** (browse focus — keyboard only after **OK**), then **Auto next**, then **Close**; **↓** from any top-bar control returns to the episode list. **Sources** and **Source** side panels are D-pad focusable (close, season/range chips, list rows). **Back** (remote or the top-left back control) closes an open menu, panel, subtitle settings dialog, or toast focus target first; a second **Back** exits the player. Controls stay visible on TV (no auto-hide).

## How to open it

Tap **Play** on any details screen, stream list, IPTV channel, or hub episode.

On desktop, playback opens in a **full-window layer** above the app shell — the left nav rail is hidden until you tap back.

## What you can do

- Play, pause, seek (click the bar; hover preview on desktop when supported), and adjust volume (hover the volume icon to expand the slider — main player, trailer, and IPTV). After a title ends, the progress bar still moves — click back on the bar or restart from the beginning without reopening the player
- Double-click the video (desktop) to enter/exit fullscreen — films also support **F** or the fullscreen button; trailers use the fullscreen button or double-click; IPTV / Live Matches use the fullscreen button or double-click
- Back / Escape exits the player and **stops audio** immediately (mpv/Exo are stopped before the route closes). On desktop, the mouse **Back** side button and a strong two-finger horizontal trackpad swipe do the same as the player Back control. Leaving returns to **details** (movies/TV, Anime, Asian Drama) — not the stream-loading overlay. Leaving the player also **stops background source checks** for that session (server probes, Nuvio scrapers, embeds). Leaving media details — or switching shell tabs while the loading screen is still checking servers — stops torrent / Stremio / Nuvio / webstreaming fetches for that title so they do not keep running in the background.
- Skip ±10 seconds from the bottom bar or large center controls
- Open **Source** (bottom right) — a right-side panel with server rows and stream lists underneath. Headless WebView sniffs load embed URLs inside an iframe by default (some providers still force a direct load). Stream rows append a language **flag** when the title includes a flag emoji or a recognizable language (e.g. `🔗 CloudStream Pro from VidSrc 🇩🇪`). Tap an empty server to **check** it (loads its stream list). Tap a loaded server to **expand/collapse** its streams. Hover a loaded server to show a **reload** icon beside the name (drops the Play cache for this title and refetches that server from the network). Header **reload** does the same for the active server when no host reload callback is wired. When a server returns **multiple streams**, the panel lists every row first, then probes them **one by one** (server subtitle shows `Checking 2/5…`; each row shows Checking → ready/failed). Tap a stream row to re-check it anytime (probe does not interrupt playback). Playing rows stay on the **catalog** URL even when playback goes through the local PNG-strip proxy — checking another server does not hide or replace the active stream row. **Playing** is scoped to the active server — the same CDN URL under another server stays a playable row (not a blue pause on the wrong host). Each server also shows a **score badge**: the **number is the provider’s running Σ** across titles (count **up or down**, never below **0**); the **+/− prefixes** are this film/episode’s server and stream verdicts only (Asian drama not scored). Per-title outcomes update Σ by their delta (a title at **−2 −2** drops Σ by 4, floored at 0 — fails while already at 0 stay at 0). Title score is the **net** of two **linked** verdicts committed together when the check finishes: extract OK + stream OK → **+2 +2**; extract OK + all streams dead → **+2 −2** (net 0); extract empty → server **−2**. Cancel / mid-check / extract-only does **not** leave a lone server **+2**. Stream **−2** only when every known stream is dead — not on the first miss. So an up server whose streams are all dead nets **+2 − 2 = 0**, an up server with a working stream nets **+4**, and a server that never resolved nets **−2** or **−4**. A **+/− prefix** shows this title’s verdicts; re-checking the same title re-evaluates them instead of drifting. Server dots: **green** = up (streams listed / extract succeeded), **gray** = not checked yet, **red** = failed. Playing is **Playing now** / the stream pause control — not the server dot. **CHECKING SOURCES** / Auto tries servers in order until one works for open. If you **manually** check or pick a server/stream, a fail **stops** — no auto hop. Tap an unloaded server to fetch its streams. Hover a live stream to reveal the **play** arrow and switch; failed streams never show play.
- When you leave the player and press **Play** again for the same movie or episode in the same session, Forja reopens the last working web stream directly on that server — no full provider recheck. If you switched server or quality in the player, that selection is remembered.
- First-time search checks providers one at a time in your settings order until one works; after that, playback stays on the server that worked unless you turn **Auto server** back on in player settings.
- Open **Episodes** from the bottom bar — a right-side panel lists the season’s episodes with thumbnail, title, air date (orange when not yet aired), runtime, and synopsis. The top bar has a brand-green **Season** pill when the show has multiple seasons, **Search** to filter by title or episode number, and an **Auto next** switch (same preference as Settings → Playback → Auto next episode). Use the range dropdown under the top bar when there are more than 50 episodes. Picking an aired episode closes the panel and shows a compact translucent loading card at bottom-right above the seek bar (`Season X · Episode Y`) with live status (`Loading episode info…`, `Checking sources…`, provider name while checking, `Opening stream…`) while Forja resolves the stream and reloads in-player; not-yet-aired episodes do not launch playback. The same card appears for Next/Previous episode
- Pick another torrent, Stremio, or Nuvio stream from the player **Sources** panel — the panel opens on **Torrents** when available (else Nuvio, then Stremio), loads only that kind, keeps results for about 30 minutes, and shows **reload** on the selected category tab only. Switching away from a kind while it is still loading stops that fetch. Provider chips (indexers, Stremio addons, Nuvio scrapers) sit under the kind tabs. Torrents and Stremio show their complete fetched response; Nuvio loads a scraper when you tap its chip (tap again clears its rows); more selected scrapers load lazily one at a time. It closes immediately after a pick, and the CHECKING SOURCES roulette shows while the magnet/stream resolves. Reopening **Sources** borders the currently playing torrent/stream and scrolls it into view.
- Switch **audio**, **subtitles**, and **quality** from dedicated bottom-bar buttons
- Open **Settings** popup for auto selection, **Auto skip intro**, speed, aspect ratio, loop, and hardware decode — a drill-in list where each parameter opens its own second page with On/Off or value chips (same brand-green chrome as other floating menus). Subtitle style is reached from the **Subtitles** menu header (tune icon). On desktop torrent sessions, toggle **Torrent stats** (off by default) to show live download/peer info above the seek bar while controls are visible
- Use picture-in-picture on Android and desktop
- Tap **Cast** on supported platforms (AirPlay on macOS/iOS, Chromecast on Android/iOS/Windows). Native casting is not wired yet — the player shows a status message (e.g. “AirPlay is not available yet”) instead of failing silently
- Skip intro/recap/credits when IntroDB has data (optional **Auto skip intro** in Settings → Playback or the player Settings menu for intro/recap)
- Jump to next episode for TV content (optional **Auto next episode** — Settings or Episodes panel switch). Auto next only runs after a real watch reaches the end — a torrent that fails to start (or EOFs before video) does not skip ahead
- Launch an external player instead of built-in (Settings)

## Tips

- If a **cached** stream list is dead (open/check fails), Forja drops that cache immediately and tries the other URLs from the list — with **Auto server** On it then re-searches servers from scratch like the first Play. Manual **reload** / **check** never reuse the saved Play cache. If you **pinned** a server (or Auto server is Off), it refreshes that server only and stops so you can pick another from **Source**. Mid-play failures with Auto On can still try the next server in order. **Anime** follows the same dead-cache path: a saved episode stream that expired no longer sticks on one failed row with an empty Source list — the full server list stays available and Forja re-searches from scratch
- Direct HTTP MP4/MKV/HLS opens use a browser-like User-Agent (and extractor Referer when provided). Pasting the same URL in Chrome is a close match; bare `libmpv` is not
- Seek preview needs a decodable frame; live or buffering streams may show time only
- Quality shows detected HLS variants. While **Auto** is active the menu hides Auto and highlights the resolution currently playing; pick a chip to lock that playlist (Auto reappears so you can unlock). Auto prefers a mid-high rung for a faster start (lock a higher chip when you want top quality). Single-quality or direct streams show the current decoded resolution (e.g. 1080p)
- Long sessions benefit from [torrent cache settings](../settings/torrent-settings.md) when streaming magnets
