# Account switching

> Keep several Forja accounts on one device and switch between them without signing out.

## What it is

Forja remembers the accounts you sign in to on this device. Switching changes the active account in one step. Each account keeps its own profiles, My List, continue watching, IPTV portals and connected services on the device, so switching back restores everything without linking again.

## How to open it

- **Who's watching?** — the account row above the profiles (desktop, phone, Android TV)
- **Settings → Profile & account → Accounts on this device**

## What you can do

- **Switch** — pick an account chip on Who's watching, or **Switch** in Settings. Forja flushes the current account's pending changes, then opens the last profile you used on the other account (or asks you to pick one). Accounts with two-factor sign-in ask for the code first.
- **Add account** — opens the normal sign-in for your platform: the code / QR link on desktop and Android TV, email and password or Web login on phone. The account you were on stays saved. Signing in to an account already on the device just switches to it.
- **Remove from this device** — open **Manage** on Who's watching, or **Remove** in Settings, on an account that is not the active one. This ends that account's session on this device only. Its local data stays on the device until you clear it from Settings → Data & backup while that account is active. The active account uses **Sign out** instead.
- **Sign out** — still available for the active account. After a sign-out, or if a session expires, the sign-in screen lists the other accounts saved on this device so one tap gets you back in.

## Tips

- Switching needs a connection. Offline, Forja keeps the current account and says so.
- If an account's session was ended elsewhere (password change, portal revoke), its chip shows **Sign in again**. Nothing else changes until you do.
- The code / QR link or Web login started from **Add account** asks the portal which account to use when the browser is already signed in: **Continue as** that account, or **Use another account** (which signs that browser out first).
- On Android TV, moving over the account row only highlights a chip. Press OK to switch.
- Up to five accounts per device.
