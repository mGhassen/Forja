# MDBList

> Link an MDBList API key in Settings.

## What it is

MDBList aggregates movie/TV lists from multiple services. Forja stores your API key for account linking. There is no in-app MDBList list browser right now — use [My List](../movies-tv/my-list.md) for local + Simkl bookmarks.

## How to open it

**Settings → Addons → Connected services → MDBlist** (admin accounts) — enter API key.

## What you can do

- Save MDBList API key
- See configured username when the key works

## Setup

1. Create account at mdblist.com
2. Generate API key in MDBList settings
3. Paste key in Forja Settings

## Tips

- Pairs with [Trakt](trakt.md) for tracking vs list curation on those services’ own sites
