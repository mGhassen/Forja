# MDBList

> Browse your MDBList lists and top lists inside Forja.

## What it is

MDBList aggregates movie/TV lists from multiple services. Add your API key to pull your lists and explore MDBList top lists in the [External lists](../movies-tv/external-lists.md) browser.

## How to open it

**Settings → Accounts → MDBList** — enter API key.

## What you can do

- Save MDBList API key
- See configured username
- Browse your lists and top lists (via Settings → Lists)

## Setup

1. Create account at mdblist.com
2. Generate API key in MDBList settings
3. Paste key in Forja Settings

## Tips

- MDBList is list browsing — playback still uses Forja details and sources
- Pairs well with [Trakt](trakt.md) for tracking vs list curation
