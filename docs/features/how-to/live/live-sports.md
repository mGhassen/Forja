# Watch Live Sports

> Open a match, pick a Providers stream, play natively.

## Steps

1. Install the Live Sports hub + live packs under **Forja Packs**. Configure **Setup** under **Addons → Live Sports** (or expand the hub under Forja Packs).
2. Open the **Live Sports** tab → **Sports** shelf.
3. Use **Catalog** / **Schedule** filters; tap a match.
4. In **Providers**, tap a stream row. Forja unlocks to a native play URL (no embed WebView).
5. If unlock fails: **No playable stream** — pick another row. Use the **Live TV** tab in the panel when Forja Sports matches your IPTV portal.

## Tips

- The schedule can list a match before any site has links.
- Reload / Update the live pack if unlock modules go stale after an upstream change.
