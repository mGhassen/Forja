# Add an IPTV portal (Xtream, M3U, or Stalker)

> Connect a live TV / VOD provider to the IPTV hub.

## Steps

1. Install and enable the **IPTV** hub pack (**Settings → Forja Packs**). Show **IPTV** under **Features** if needed.
2. Open the **IPTV** tab → **Portals**, or **Settings → Addons → IPTV**.
3. **Xtream:** host URL, username, password.
4. **M3U:** playlist URL (M3U / M3U8).
5. **Stalker:** portal URL + MAC (and any required credentials).
6. Save and wait for the portal catalog to load (progress on the portal card).
7. Select the portal, then browse **Live** / **Movies** / **Series**.

## Tips

- Portal passwords use the device vault; share codes and CSV export still contain secrets.
- Clear stale shelves from **Settings → Data & backup → IPTV portal cache** when needed.
