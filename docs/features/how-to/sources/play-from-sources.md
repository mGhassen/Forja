# Play a title from Sources

> Open the Sources panel and pick Torrents, Stremio, Nuvio, or Forja.

## Steps

1. Open a title from Home or My List.
2. Tap white **Play** / **Resume** (link icon) to open **Sources**. Green Play races Forja Auto instead.
3. Pick a kind tab. Optionally pick a provider chip, then tap a stream row.
4. Use **Filters** (tune) for quality / size / language / tech when available.
5. Wait for the loading screen; the native player opens when a playable URL is ready. Escape / click outside closes Sources and cancels in-flight checks.

## Tips

- Scrapes load when you open Sources, not merely when you open details.
- Tapping a Forja HTTP row that 404s stays on details with a toast — it does not silently probe every sibling file.
