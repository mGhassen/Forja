# Play torrents on desktop

> Stream a magnet with the on-device torrent engine.

## Steps

1. Enable **Direct torrent** under **Settings → Addons** (and related torrent toggles).
2. Optionally leave debrid unset, or keep it for cached titles.
3. Open a title → **Sources → Torrents** → pick a result.
4. Wait for the torrent engine to open a playable file in the native player.
