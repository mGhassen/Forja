# Use Nuvio scrapers

> Load Nuvio stream scrapers in Sources.

## Steps

1. Turn on **Nuvio** under **Settings → Addons**.
2. Open Nuvio settings (chevron). Enable scrapers you want; optionally **Select All by default**.
3. Open a title → **Sources → Nuvio**.
4. Use **All** or tap scraper chips (multi-select). Rows appear as scrapers finish.
