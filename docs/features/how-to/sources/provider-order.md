# Understand Auto provider order and scores

> How Auto picks servers and how to reset learned scores.

## Steps

1. Leave player server mode on **Auto** unless you want to pin a server from the player menu.
2. Enable the Forja / Nuvio plugins you actually use.
3. Play normally — domain scores plus a live reliability Σ may nudge order by at most ±2 ranks.
4. To reset learned scores for this profile: **Settings → Data & backup → Provider scores**.
