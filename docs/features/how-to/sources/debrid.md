# Add debrid and play torrents via cloud

> Resolve magnets to HTTP through Real-Debrid, TorBox, and other debrid plugins.

## Steps

1. Install the **Debrid** pack under **Forja Packs** if needed.
2. Open **Settings → Addons → Debrid**.
3. Select the active plugin and paste its API key.
4. Open a title → **Sources → Torrents** (or a Stremio hash stream) → pick a magnet. Forja resolves through debrid when the title is cached remotely.

## Tips

- Uncached torrents still need local or LAN torrent playback.
- Clear the active plugin to force local/LAN only.
