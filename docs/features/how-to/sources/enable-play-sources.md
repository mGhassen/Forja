# Turn on play sources (torrent, Stremio, Nuvio, Forja)

> Choose which Sources tabs appear on a title.

## Steps

1. Open **Settings → Addons**.
2. Turn on the host rows you need (**Stremio**, **Nuvio**, Direct torrent / related torrent rows, …). **OK / click the row** toggles; the **chevron** opens settings.
3. Install provider / debrid / hub packs under **Forja Packs** when those rows are missing.
4. Open a title → white **Play** (link icon) → **Sources**. Only enabled kinds appear (**Torrents** / **Stremio** / **Nuvio** / **Forja**).
