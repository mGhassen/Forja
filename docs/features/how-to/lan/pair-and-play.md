# Pair LAN and play torrents on TV / phone

> Desktop downloads; the paired device plays. Pair once on the same Wi‑Fi.

## Steps

1. **Desktop:** **Settings → LAN → Enable LAN server**. Note IP:port and the 6-digit code. Keep Forja running.
2. **TV / phone:** **Settings → LAN** → Discover on Wi‑Fi or enter IP/port → enter the code → **Pair with desktop**.
3. On the client, enable **Direct torrent** under Playback / Addons.
4. Open a title → Sources → Torrents → pick a magnet. Desktop downloads; client plays.
5. Leaving the player stops that download on the desktop. Watch **Torrent activity** on the desktop for progress; trash stops and deletes that cache entry.

## Tips

- You do not re-enter the code per title.
- Direct HTTP Stremio/Nuvio streams still play unpaired; magnets need the desktop.
