# First-run packs step

> Choose Official packs, Community Packs, or Skip after sign-in / guest start.

## Steps

1. After sign-in and profile pick (or guest first run), Forja shows the packs step when the profile is not yet onboarded.
2. Pick **Official packs**, **Community Packs**, or **Skip for now**.
3. Completing or skipping marks the profile onboarded (synced) so the step does not repeat on other devices for that profile. Guest uses a local flag only.
4. You can install later anytime under **Settings → Forja Packs**.
