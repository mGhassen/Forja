# Install Official packs

> Seed Forja with the recommended ForjaHQ pack set (Home, providers, hubs, …).

## Steps

1. Open **Settings** from the profile avatar at the bottom of the left rail (phone: Settings tab).
2. Open **Forja Packs**.
3. Tap **Official packs** — a checkable list opens in the detail pane (rows start unchecked in Settings; onboarding may pre-check Recommended).
4. Check the packs you want. Rows tagged **Not on this device** stay off this platform’s rail unless you force them.
5. Tap **Install** / **Install N packs** and wait until **Pending download** clears.
6. Leave Settings — hub tabs appear on the rail when those packs finish (also check **Features** if a tab is hidden).

## Tips

- Cold start / first profile can offer Official packs before you reach Settings — same checklist.
- Use **Download all** if several rows stay pending.
