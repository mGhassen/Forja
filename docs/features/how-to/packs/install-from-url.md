# Install a pack from a manifest URL

> Install any Forja pack by pasting its `manifest.json` URL or a local checkout path.

## Steps

1. Open **Settings → Forja Packs**.
2. Paste one or more manifest URLs (or a local folder / `…/manifest.json`). Multiple lines or commas open a batch checklist; a single URL installs immediately.
3. Tap **Install** and wait for the download.
4. Expand the pack (chevron) to see plugins and pack settings.

## Tips

- `forja://install?manifest=…` deep links open this screen and ask before installing.
- Failed installs show a DNS / timeout message, not a raw exception.
