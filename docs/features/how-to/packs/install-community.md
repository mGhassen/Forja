# Install Community packs

> Add packs from the Forja web catalog onto this device / profile.

## Steps

1. In a browser, sign in to the Forja account portal.
2. Open **Community Packs** (or Profile → Forja Packs on the web).
3. Browse product bundles (**Get this set**) or individual packs. Filter by kind / topic if needed.
4. Select packs → **Add to Forja** / **Add N to Forja**. On the device, Forja opens **Settings → Forja Packs** with a checklist.
5. Confirm which packs to download → **Install**.
6. When signed in, you can also assign membership to profiles from the web (cloud/trash icon → profile picker); the app downloads membership packs after sync.

## Tips

- Install URLs are not shown in the community UI — use Add to Forja.
- Pack updates still ask before downloading; membership adds can auto-download with a toast (**View** opens Forja Packs).
