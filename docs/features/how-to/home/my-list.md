# Add titles to My List

> Pin Plan to Watch / Watching / On Hold / Completed / Dropped.

## Steps

1. Install / enable the **My List** hub pack so the tab exists (**Forja Packs**).
2. On Home or details, tap the glass **+** (or poster bookmark).
3. Pick a status. Tap the active status again to remove it.
4. Open the **My List** tab to browse buckets. Connect Simkl to sync statuses and history.
