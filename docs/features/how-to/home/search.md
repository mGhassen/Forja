# Search from Home

> Find titles with Home pack Search (filter lens included).

## Steps

1. On Home (or a Home details page), open the top-bar **Search** tab or press **Cmd+F** / **Ctrl+F**.
2. Type a title. Optionally open the filter lens (type, score, year, genre, country, language).
3. Press **Enter** / **OK** to run — results do not fire on every keystroke. Filter-only search works after you submit the lens.
4. Open a result for details / play.

## Tips

- Idle Search shows recent queries and recommendations.
- Anime / Asian Drama keep their own pack search on those tabs.
