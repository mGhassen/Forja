# Filter providers by SUB / DUB language

> Limit which Forja movie/TV plugins race by subtitle or dub language.

## Steps

1. Open a movie or series from Home.
2. In the hero actions, open **SUB** or **DUB** (Languages) and pick languages. Empty = all. Use SUB or DUB, not both.
3. Same preference lives under Home pack settings (**Settings → Forja Packs** → expand Home).
4. Green Play and **Sources → Forja** respect the filter. It does not pull other-hub providers into Home.
