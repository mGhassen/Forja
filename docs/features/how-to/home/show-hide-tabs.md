# Show, hide, and reorder tabs

> Control which installed features appear on the rail and which opens at launch.

## Steps

1. Install / enable the pack or addon that owns the tab first (**Forja Packs** / **Addons**). Fresh install: only Settings is on the rail.
2. Open **Settings → Features**.
3. Toggle tabs on or off. **Settings** always stays visible.
4. Drag to reorder (desktop).
5. Tap the **star** beside a visible tab (or Settings) to set the launch default for this profile.

## Tips

- Turning a pack off removes its tab from Features entirely — Features only hides among available features.
- Layout syncs with the profile via cloud sync after local save.
