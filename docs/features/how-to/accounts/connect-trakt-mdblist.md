# Connect Trakt or MDBList

> Link Trakt OAuth or paste an MDBList API key.

## Steps

1. **Trakt:** **Settings → Addons → Connected services → Trakt** → complete the login / device flow → confirm the account name.
2. **MDBList:** same Connected services → **MDBList** → paste API key → save.
3. Use list / rating surfaces that read those services (external lists, details).
