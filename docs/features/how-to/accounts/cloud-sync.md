# Cloud sync packs and settings across devices

> Keep pack membership, Features, and synced settings on one profile.

## Steps

1. Sign in with the same Forja account and select the same **profile** on each device.
2. Install / enable packs on one device (or assign membership from the web catalog).
3. On the other device, wait for sync — missing packs download when membership says so; mid-session adds may ask before download.
4. Features layout and many addon flags sync after local save.
5. Switch profiles under **Settings → Profile & account** when you want a different set.

## Tips

- API keys for debrid / LAN stay device-local where noted in Settings.
- Local checkout pack paths are not remapped through the published catalog.
