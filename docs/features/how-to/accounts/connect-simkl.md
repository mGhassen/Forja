# Connect Simkl

> Sync My List statuses and watch history with Simkl.

## Steps

1. Open **Settings → Addons → Connected services → Simkl** (path may appear under Connected services inside Addons).
2. Tap **Login with Simkl** and enter the PIN at simkl.com/pin.
3. Choose **How should lists sync?** (Keep local / Use Simkl / Merge / Merge + delete / No sync).
4. Tap **Sync Now** for a full pass. Status changes still push immediately when connected.
