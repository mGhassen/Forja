# Clear cache, scores, or watch data

> Free disk and reset learned / viewing data for this profile.

## Steps

1. Open **Settings → Data & backup** (phone / desktop — not on Android TV).
2. **Safe to clear:** Stream cache · Images & WebView · IPTV portal cache (when IPTV is on) · Downloaded updates.
3. **Learned:** Provider scores (Settings Score / Auto order for this profile).
4. **Watch data:** Continue watching · Watched episode marks (destructive for this profile; Simkl cloud history is not deleted from Continue watching clear).
5. Confirm each action.

## Tips

- Prefer Stream cache when Play opens a dead URL.
- Prefer Provider scores when Auto keeps favoring a flaky extractor.
