# Backup or restore settings

> Export / import a JSON backup on phone/desktop.

## Steps

1. Open **Settings → Data & backup**.
2. Export a backup JSON, or import a previously exported file.
3. IPTV portals CSV tools appear when IPTV is available (not on Android TV).
