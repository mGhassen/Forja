# Download for offline playback

> Save titles into Downloads on phone/desktop.

## Steps

1. Open **Settings → Downloads** (phone / desktop).
2. Start a download from a playable source that supports offline save (when the title offers it).
3. Watch from **Downloads** when the job finishes. Check storage used / free on the same page.

## Tips

- Not every stream type can be saved — availability depends on source and platform.
