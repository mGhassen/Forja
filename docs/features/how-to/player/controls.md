# Use the player (subs, audio, speed, skip, next, PiP, external)

> Day-to-day controls while a video is playing.

## Steps

1. Open any title / channel with **Play**.
2. **Subtitles:** CC menu → Off / File / language folders (in-stream + online). Style via the tune control in that menu.
3. **Audio:** audio menu → pick a track when the file has more than one.
4. **Speed / aspect / loop:** Settings drill-in from the player gear (or dedicated Speed control when shown).
5. **Skip intro / segments:** confirm the skip chip when it appears, or scrub.
6. **Next episode:** accept **Next episode** near the end, or open Episodes in the player.
7. **PiP / mini player (desktop/phone):** PiP control or demote to in-app mini (Escape path / button when enabled in Playback settings).
8. **External player:** Player menu → External app (hidden on Android TV).
9. **Sources mid-play:** link/magnet Sources or Source server picker when available for that session.
