# Magnet player

> Paste any magnet link and stream files without searching TMDB.

## What it is

The Magnet tab is a quick path from magnet URI to playback. Paste a link, see the file list inside the torrent, pick a video file, and stream it through the torrent engine.

## How to open it

The **Magnet** tab is temporarily hidden from the navigation bar and Settings → Features.

## What you can do

- Paste a magnet link
- Wait for metadata and file list
- Select which file to play (for multi-file torrents)
- Stream via [torrent playback](../playback/torrent-playback.md)

## Tips

- Works with any valid magnet — no movie metadata required
- Large swarms buffer faster; tweak [torrent settings](../settings/torrent-settings.md) if stuttering
