# Cloud sync

> **Coming soon** — This feature is planned but not available yet in the current release.

> Sync your lists, watch history, and settings across devices via the cloud.

## What it is

Cloud sync will back up your Forja data (watch progress, My List, preferences) to a remote account so you can pick up on another device. The planned backend is Supabase.

## How to open it

Not available yet. A sync module exists in the codebase but is not wired to the app.

## What you will be able to do

- Sign in and sync watch history across phones, tablets, and desktops
- Restore lists and settings on a new install
