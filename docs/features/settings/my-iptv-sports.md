# My IPTV sports

> Match today’s ESPN games to live channels on your Xtream portal in Live Matches.

## What it is

On-device Sports matcher (Sportio-style): ESPN’s public schedule for the leagues you care about, then name/EPG matching against live channels on **one** saved Xtream portal. Streams play in the native IPTV player. No self-hosted addon.

## How to open it

- **Settings → My IPTV sports** (own Settings category)
- Then **Live Matches → Servers → My IPTV**

## What you can do

- Enable the My IPTV server in Live Matches
- Pick which Xtream portal to search
- Choose leagues (All / None, or chips) — first Enable with no leagues selects all
- Optionally narrow live folders by **sport** (Soccer, Basketball, …) plus Global — default is **all live channels** (no ticking required)
- Open a match to get tier-ranked HLS sources from that portal

## Setup

1. Add an Xtream portal under IPTV (if you don’t have one)
2. Settings → My IPTV sports → Enable → pick portal → leagues (folders stay “All live” unless you narrow)
3. Live Matches → Servers → My IPTV

## Tips

- The game list is ESPN for **today** only — not the same catalog as PPV/Streamed
- Folder mapping is optional and by sport family: e.g. Soccer covers EPL, MLS, La Liga, World Cup
- Leave folders empty / All selected → searches all live channels; open a sport only if you want to exclude noise
- Folder picker starts with everything checked, has All / None + filter — Done with all checked does not save thousands of ids
