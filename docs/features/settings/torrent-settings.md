# Torrent settings

> Cache, connections, and sort order for torrent search and playback.

## What it is

Controls how the torrent engine behaves: result sort order on details screens, RAM vs disk cache for streaming, cache size, and peer connection limits.

## How to open it

**Settings → Sources** (torrent engine / sort — only when **Direct torrent** is on and built-in torrent search is available on this platform)

## What you can do

- Set **sort preference** (e.g. seeders high to low)
- Choose **cache type**: RAM or disk
- Adjust **RAM cache size** (MB) when using RAM cache
- Set **connection limit** for the torrent engine

## Tips

- Higher RAM cache smooths playback on fast connections
- Disk cache helps on memory-constrained devices with large files
- Sort by seeders for fastest starts on [torrent playback](../playback/torrent-playback.md)
