# Torrent settings

> Providers, cache, connections, and sort order for torrent search and playback.

## What it is

Controls how torrent search and the torrent engine behave: which built-in providers to query, result sort order, RAM vs disk cache, cache size, and peer connection limits.

## How to open it

**Settings → Sources** (torrent providers / engine / sort — only when **Direct torrent** is on and built-in torrent search is available on this platform)

## What you can do

- Enable or disable each **torrent provider** (Knaben, The Pirate Bay, UIndex, Torrents CSV, Nyaa, YTS, SolidTorrents, TheRARBG, Torrentio)
- Set **sort preference** (e.g. seeders high to low)
- Choose **cache type**: RAM or disk
- Adjust **RAM cache size** (MB) when using RAM cache — on **TV**, focus the slider and use **Left/Right**
- Set **connection limit** for the torrent engine — same D-pad nudge on **TV**

## Tips

- Disable providers you don’t use to speed up search
- Higher RAM cache smooths playback on fast connections
- Disk cache helps on memory-constrained devices with large files
- Sort by seeders for fastest starts on [torrent playback](../playback/torrent-playback.md)
