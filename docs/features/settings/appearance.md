# Appearance

> Themes, presets, and light mode.

## What it is

Customize how Forja looks. Choose from theme presets (cinematic, midnight, royal purple, crimson, ocean, emerald, sunset) or enable **light mode** for a brighter UI (also noted as better for performance on some devices).

## How to open it

**Settings → Appearance**

## What you can do

- Toggle light mode on/off
- Pick a theme preset — accent colors update across the app
- Preview theme on the settings screen

## Tips

- Theme choice is saved locally and included in [backup & restore](backup-restore.md)
- Light mode reduces GPU load on some Android devices
