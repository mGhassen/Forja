# Appearance

> Light mode and the fixed Forja theme.

## What it is

Customize how Forja looks. The app uses a single **Forja** flat cinematic theme (muted shell chrome + brand green accents). You can enable **light mode** for a brighter UI on shell, lists, and settings — the Home hero backdrop stays cinematic dark.

## How to open it

**Settings → Appearance**

## What you can do

- Toggle light mode on/off — shell, lists, and settings use a bright palette; the Home hero backdrop stays cinematic dark

## Tips

- Light mode is saved locally and included in [backup & restore](backup-restore.md)
- Light mode uses flat surfaces (no glass blur). Hero imagery keeps a dark gradient for readable titles.
