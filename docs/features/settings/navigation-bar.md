# Navigation bar

> Show, hide, and reorder tabs in the main shell.

## What it is

Customize which sections appear in the bottom nav (mobile) or side rail (desktop) and in what order. **Settings** always stays visible and cannot be removed.

## How to open it

**Settings → Navigation Bar**

## What you can do

- Toggle visibility for each tab (Home, IPTV, Music, etc.)
- Drag to reorder visible tabs
- Select the star beside a visible tab to make it the menu that opens when you launch the app
- Restore a cleaner bar by hiding unused hubs

## Tips

- Hidden tabs are still reachable if another screen deep-links to them
- Order is saved per device — use [backup & restore](backup-restore.md) to copy layout
