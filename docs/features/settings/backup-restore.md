# Backup & restore

> Export and import all settings and tokens as one JSON file.

## What it is

Move your Forja configuration between devices or keep a backup. Export includes settings, addon lists, API keys stored in secure storage, theme, navbar layout, and related preferences.

## How to open it

**Settings → Backup & Restore**

## What you can do

- **Export** — save a JSON file to disk
- **Import** — load a previously exported file (replaces current settings after confirm)

## Tips

- Treat export files as sensitive — they contain API keys and tokens
- Import is destructive to current settings — confirm before proceeding
- Complements (does not replace) future [cloud sync](../coming-soon/cloud-sync.md)
