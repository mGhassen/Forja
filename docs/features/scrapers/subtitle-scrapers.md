# Subtitle scrapers

> HTML-based subtitle search from SubtitleCat and MySubs.

## What it is

Besides API subtitle sources (Wyzie, Levrx) and Stremio subtitle addons, Forja scrapes **SubtitleCat** and **MySubs** when you have a title name. SubtitleCat can also offer on-demand Google translation for some tracks.

## How to open it

Automatic when you open the subtitle menu during [playback](../playback/subtitles.md).

## What you can do

- See SubtitleCat and MySubs results mixed with API and addon tracks
- Pick any track like other subtitle sources

## Setup

No configuration — scrapers run when title metadata is available from the playing item.

## Tips

- Accurate title + year on the details page improves hit rate
- Results stream in — more tracks may appear after the menu opens
