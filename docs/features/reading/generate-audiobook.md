# Generate audiobook

> Turn an EPUB into a spoken audiobook with AI voices.

## What it is

Upload an EPUB from your library and send it to Paper2Audio for text-to-speech processing. Pick a voice, track job status, and listen to the generated audiobook when ready.

## How to open it

From **Audiobooks** — generate / upload EPUB flow (Generate Audiobook screen).

## What you can do

- Select an EPUB to convert
- Choose TTS voice
- Submit generation job and monitor progress
- Play the result in the audiobook player when complete

## Setup

Requires network access to Paper2Audio service. No extra API key in Forja for basic use.

## Tips

- Long books take time to process — jobs run asynchronously
- Quality depends on source EPUB structure and chosen voice
