# Books

> Search and read EPUB books with customizable reader.

## What it is

Browse a books library, search titles, and continue reading where you stopped. The EPUB reader supports font size, dark mode, and focus/line reading modes for comfortable long-form reading.

## How to open it

Tap **Books** in the navigation bar.

## What you can do

- Search the book library
- Resume from continue reading
- Adjust font size and theme in the reader
- Use focus or line reading mode
- Navigate chapters and progress

## Tips

- Reading position is saved per book
- Generate an audiobook from EPUB via [Generate audiobook](generate-audiobook.md)
