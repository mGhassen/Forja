# Stremio catalog

> **Archived:** Out of scope or not in the default navigation surface. See [Archive](../README.md).

> Browse a full Stremio addon catalog — genres, search, and pagination.

## What it is

Beyond search snippets, you can open a dedicated catalog browser for any installed Stremio addon that exposes a catalog. Filter by genre, search inside the catalog, and paginate through results.

## How to open it

From addon-related flows in the app (Search catalog sections, details Sources). Home no longer shows Stremio catalog rails.

## What you can do

- Browse addon catalog entries with posters and metadata
- Filter by genre when the addon supports it
- Search within the catalog
- Load more pages of results
- Open an item to stream via the addon

## Setup (if needed)

Install addons in **Settings → Providers & Addons** — paste a Stremio manifest URL.

## Tips

- Each addon defines its own catalog shape — some have richer filters than others
- Catalog items may use different IDs than TMDB; playback goes through the addon's stream API
