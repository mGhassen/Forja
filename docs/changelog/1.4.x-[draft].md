# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.44 (`v1.4.44`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

### Sources
- **Fix:** VidNest movie/TV from Forja Sources hops sibling mirrors when the first CDN fails instead of stopping on a dead MovieBox link.
- **Fix:** Player Sources → Forja shows the same provider chips as details when you're playing from Videasy, VidLink, or other movie/TV plugins — they no longer collapse to the small drama-only subset.
- **Fix:** Forja provider chips in Sources appear immediately on open — cached plugin lists no longer wait for a full bundled script reinstall every app launch.
- **Fix:** Movie, anime, drama, IPTV, and Forja Sports Sources panels no longer cache empty fetches or dead URL probes — reopening retries failed scrapers and channels instead of sticking on a miss for 30 minutes.

- **Fix:** Live IPTV only shows the **Buffering…** banner when the picture is actually stalled — reconnect and source-switch messages still appear as before.
- **Fix:** Live IPTV plays through CDN reconnects when demuxer cache still has cushion — overlap is stripped at the proxy instead of flushing mpv and freezing the picture.
- **Fix:** Forja Live and other MediaKit HLS streams no longer false-reopen after ~8s when the playhead stays at 0 while video is still playing.
- **Change:** Live Matches **All**, **Streamed**, and **Forja Live** resolve every catalog mirror when you open a card, merge playable streams into one picker (sorted by viewers), and hide dead Streamed listings with no API rows.
- **Fix:** **Engine** stream resolve never opens the embed WebView — GOAT/`/fetch` → `/hls-proxy` → IPTV player only; on miss it toasts and stays in Forja.
- **Fix:** PPV **embed.st** in **Engine** mode resolves with native GOAT `/fetch` (same as Streamed) instead of headless sniff after the API miss.
- **Fix:** Live Matches **Forja Live** no longer opens the **Forja Sports** Xtream picker while engine plugins are still loading — ESPN schedule waits for catalogs, and play stays on plugin sources only.
- **Fix:** Live Sports tab no longer crashes on macOS when Forja Live catalog plugins load — scrapes run in Rust QuickJS off the UI thread instead of shared flutter_js on the main isolate.
- **Fix:** WatchFooty Forja Live catalog no longer dumps 1500+ stale football rows into the grid — only live and near-term kickoffs load.
- **Fix:** Live Matches timeline only time-buckets live and near-now events; everything else loads lazily below as you scroll.
- **Fix:** IPTV and live sports on Windows play with sound again — MediaKit restores audio output after player exit, and Sniff embeds unmute on load instead of staying on autoplay mute.
- **Fix:** Streamed live sources (delta, echo, …) open again when [streamed.pk](https://streamed.pk/docs) lists a match but `/api/stream/…` returns no rows — Forja falls back to embed.st stream #1 so Engine GOAT resolve and Sniff embed can still run.
- **Fix:** Streamed **Engine** resolve runs natively in Dart (embed.st `/fetch` + GOAT unlock) instead of flutter_js — fixes `TextEncoder` crashes and stale cached `live-streamed.js`.
- **Fix:** Streamed / PPV **Engine** playback uses `/hls-proxy` into the IPTV player again (direct m3u8 regressed CDN playback); no WebView sniff or embed-player fallback in Engine mode.
- **Fix:** Streamed **Engine** GOAT unlock works again on desktop — `lock.wasm` is bundled from `assets/providers/live/goat/vendor/` (was missing from the asset manifest).
- **Fix:** Streamed / PPV **Engine** `/hls-proxy` keeps embed.st Referer/Origin from GOAT resolve — forcing streamed.pk made `strmd.st` return 403 and MediaKit failed to open.
- **Fix:** Streamed **Engine** **delta** and **echo** sources play again — per-source CDN headers and direct `strmd.st` open (admin stays on `/hls-proxy`).
- **Remove:** Dead Forja Live plugins NTV, SportyHunter, and Strims24 — upstream APIs no longer available.
- **Add:** Settings → Forja Sports **Stream resolve** — **Sniff** (embed player, default) or **Engine** (Forja plugins → native player); per-plugin enable toggles under **Live Forja plugins**.
- **Fix:** Forja Live catalogs (ESPN, TimStreams, Streamic, StreamFree, WatchFooty) each fetch in native Rust — playback cancel no longer aborts every schedule job at once, and ESPN is back in the provider strip.
- **Fix:** Live Matches **Engine** **ESPN** catalog shows today’s schedule again — catalog rows survive ESPN merge and NFL / NCAA Football land on the American Football chip.
- **Fix:** Live Matches **Forja Live** shows the play icon on streamed.pk motor sports and other Rust-catalog rows — playability no longer requires a matching engine catalog plugin row when the event already has source refs.

### Sources
- **Fix:** Anime **Sources** respects the details **SUB** / **DUB** toggle — Forja and Nuvio rows filter to the selected audio instead of listing both.
- **Fix:** Anime Forja source rows no longer repeat the provider name (e.g. Megaplay · Megaplay) — embed server labels show once under the plugin chip.

### UI
- **Fix:** Live Matches timeline view toggle shows again on desktop — grid/timeline button sits to the right of Refresh (leanback TV stays cards-only).
- **Fix:** Back from hub details no longer leaves the wrong shell tab highlighted in the nav rail — the tab you opened from (e.g. Asian Drama) stays selected, enlarged, and accented; focus returns to the page instead of another rail item showing a label.
- **Fix:** Anime and Asian Drama heroes show TMDB title logos when a match exists — same logo treatment as Home, not plain text only.
- **Fix:** Anime and Asian Drama hero carousel swipes like Home — title, backdrop, and metadata move together on drag; desktop mouse swipes are no longer blocked by the TV gallery focus layer.
- **Fix:** Anime hub catalogs load again — AniList was returning HTTP 403 on bare API requests.
- **Fix:** Nav rail labels no longer clip when Windows text size is increased — label slots follow system text scaling.
- **Fix:** Sources language flags on Windows show styled **EN** / **DE** badges instead of broken emoji letters.

### TV
- **Fix:** Asian Drama and Anime **Sources** on Android TV use the same frosted side panel as Movies, not the centered player dialog.
- **Fix:** Live Matches on desktop no longer opens the TV **Sources** panel for Forja Live / Streamed cards — **Engine** mode resolves through plugins again; **Sniff** uses the embed player as before.
- **Change:** Live Matches channel **Sources** panel shows clearer progress (Searching Forja Sports / Stremio, skeleton rows while loading, better empty state) instead of “sniffing the remote”.
- **Change:** Forja Live provider chips show the same loading dots as movie Sources — no separate center spinner while plugins load.
- **Fix:** Desktop mouse hover works again on flat menus and sheets (Live Matches servers/streams, settings dialogs, player menus) — D-pad focus no longer steals hover chrome.
- **Fix:** Forja Live **Engine** playback (TimStreams, Streamic, …) no longer 404s on the HLS proxy — CDN headers use the embed host instead of the catalog site.
- **Fix:** StreamFree **Engine** resolve no longer 403s on the HLS proxy — signed `_e` / `_n` / `_t` query tokens from the embed page are appended to the playlist URL.
- **Fix:** Forja Live cards no longer show a provider badge — same event from multiple catalogs merges to one card; tap loads streams from every matching live plugin.
- **Fix:** ESPN schedule (Forja Sports + Forja Live catalog) loads again — ESPN was blocking the old browser User-Agent and returned zero games.
- **Add:** ESPN soccer leagues — Serie A, Bundesliga, Ligue 1, Champions League, Europa League, Eredivisie, Primeira Liga, and Liga MX — each gets its own sport chip (not one lumped “Soccer” bucket).
- **Add:** Forja Sports channel lists (match picker and in-player **Source** menu) probe live status on hover/focus after a short dwell — same green/red alive hints as IPTV Live.
- **Fix:** Forja Sports can match IPTV channels for non-team events (F1, golf, tennis, …) using event title keywords instead of requiring home/away teams.
- **Change:** Forja Sports channel picker shows name-matched channels as soon as they land, then adds EPG-refined matches — no longer waits for the full resolve.
- **Fix:** Forja Sports IPTV matching no longer floods results with unrelated soccer channels — team names match as phrases (not generic tokens like “city”/“united”), titles parse into home/away when ESPN fields are missing, and loose single-keyword sport matching is removed.
- **Fix:** Forja Sports channel matching uses event title, sport chip, channel name, Xtream folder name, then short EPG — no hardcoded GP/sport alias tables; empty results are not cached for 30 minutes.
- **Fix:** Forja Sports no longer lists hundreds of unrelated football channels for wrestling and other PPV events — year-only title tokens and blind EPG scans are dropped, and wrestling maps to Combat portal folders.
- **Fix:** Stremio sport playback no longer spins the IPTV TS continuity proxy — each live source type (Forja Sports Xtream, Stremio, engine plugins) uses its own player profile.
- **Fix:** Forja Sports Xtream playback on desktop no longer loops HTTP 407 on the continuity proxy — upstream fetches bypass the system HTTP proxy (same direct path as libmpv).
- **Add:** Forja Sports in-player programme guide — when **IPTV programme guide (EPG)** is on, the native player shows the same floating NOW / NEXT card as IPTV Live (LIVE badge, progress, description, upcoming rows).
- **Fix:** Disabling **Enable Forja Sports** in Settings hides the Forja Sports server in Live Matches — it no longer reappears after opening a match or syncing your portal.

### Live & IPTV
- **Fix:** Live Matches **Engine** IPTV player shows the source switcher when the stream picker had multiple mirrors — every resolved row loads in the player, not only the one you tapped.
- **Add:** On desktop, hover an IPTV category or channel list and type letters to jump by name — repeat a letter for the next match, or type a short prefix (e.g. USA, FRA) for longer matches; the in-player channel guide uses the same shortcut on group and channel lists.
- **Fix:** Live Matches sport chips no longer throw "FocusNode was used after being disposed" when you switch tabs or catalogs finish loading in the background.
- **Add:** IPTV channel guide shows programme info beside the list — on desktop, hover a channel for one second; on Android TV, press **Right** on a focused channel (**←** / **Back** dismisses). Press **OK** twice to close the guide after tuning.
- **Fix:** Closing the IPTV channel guide with **Back** on Android TV leaves player chrome visible — **Back** again hides chrome, then exits the player (no auto-hide timer when the guide closes).

### Player
- **Fix:** Subtitle menu no longer highlights **Off** and a language at the same time — only one selection shows when subtitles are disabled.
- **Fix:** Switching audio tracks in the player no longer goes silent — MediaKit re-syncs output and the playhead after you pick a different track.
- **Change:** Movie Forja auto-play opens on the first working plugin instead of waiting for three.
- **Fix:** Movie seek on remote streams (Videasy and similar HLS) no longer triggers a reconnect remount while the player is still buffering — only a silent freeze after buffer clears; failed remount clears the stuck **Reconnecting…** banner.
- **Fix:** Desktop movie and trailer players restore the original chrome layout — current/total time sits beside the seek bar again and volume stays on the left transport cluster.
- **Fix:** IPTV player on desktop shows volume, fullscreen, and Picture-in-Picture again — they were hidden because desktop D-pad focus was treated as leanback TV.
- **Fix:** IPTV and live sport players on desktop show chrome, Back hover, and button hover again when you move the mouse — D-pad focus no longer treats the desktop as leanback-only.
