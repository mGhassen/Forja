# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.0 (`v1.4.0`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### TV
- **Change:** Desktop (macOS / Windows / Linux) supports arrow-key D-pad focus like Android TV, without dropping mouse hover in the shell, player menus, or dialogs (Ken Burns stays on desktop).
- **Fix:** On Android TV Sources, D-pad **→** from search reaches Filters; opening Filters moves focus into the panel, and Back returns to the Filters button before closing Sources.

### Live & IPTV
- **Fix:** Live IPTV on MediaKit plays through CDN socket closes via a local continuity proxy — reconnects skip overlapping seconds and drop stale buffers so the channel does not replay.
- **Fix:** Opening a Live Matches card on Android TV no longer kills the app while matching Forja Sports channels (EPG lookups capped; Stremio waits its turn).
- **Change:** Live Matches server and Settings category renamed from My IPTV / My IPTV sports to **Forja Sports**.
- **Change:** On Android TV, Live Matches **Servers** offers **All**, **Stremio**, and **Forja Sports** (PPV / Streamed / MutStreams stay off TV). Opening a match from All only lists **Forja Sports** and **Stremio** sources — no PPV / Streamed rows.
- **Change:** Forja Sports opens a right-side channel panel (like movie Sources) that fills as matches land — no more waiting on a bottom sheet.

### Player
- **Add:** On desktop, click the video to play/pause (double-click still toggles fullscreen).
- **Change:** Content warnings show three intensity squares (yellow / orange / red) instead of Mild / Moderate / Severe text.
- **Fix:** Desktop player **Sources** / **Episodes** / **Source** stay the right-side panel (same as details) — they no longer open as the Android TV centered dialog when desktop uses TV arrow-key focus.
- **Fix:** On Android TV, remote **Back** while player chrome is up hides the controls first — it no longer leaves the player on the same press.

### UI
- **Fix:** Stream loading no longer shows one provider in the headline and a different one underneath while several Forja servers check in parallel.
- **Change:** Upcoming Asian Drama details show a **Coming soon** notice (with premiere date when known) instead of Play / Sources.
- **Fix:** Desktop catalog pins (My List bookmark) show again — arrow-key focus no longer hides them like Android TV.
- **Remove:** Asian Drama cards no longer show KissKh “Unlock All Ep” promo labels on posters or details.
- **Change:** Details info card lists the title as **Name** first (movies/TV, Anime, Asian Drama).
- **Fix:** Opening media details no longer waits on slow or dead Stremio addon manifests before showing the page.
- **Fix:** Long hero titles on Home, Asian Drama, Anime, and media details shrink and wrap up to 3 lines instead of getting clipped.
- **Fix:** Anime tab opens faster — hero and Trending paint after the first AniList response; other rails fill in after; TMDB backdrops swap in without blocking.
- **Fix:** Closing a player on desktop no longer snaps the window back to the launch size — your windowed size, place, and maximize state stay put (and are remembered next launch). Leaving player fullscreen from a non-maximized window restores that previous size, not a full-screen frame.

### Sources
- **Fix:** Forja Auto Play uses JS extract only — it no longer URL-sniffs links (sniff stays Webstreaming-only) and no longer freezes after the first empty plugin batch.
- **Change:** Green **Play** (Forja Auto) races up to 3 plugins/streams; if open fails it hops to the next, then tells you to open **Sources** if all three die.
- **Add:** Sources → Forja **PlayIMDb** scraper (movies / TV via TMDB id).
- **Fix:** Forja scrapers treat any non-`movie` type (TV / drama / anime) as episodic — PlayIMDb, VidLink, and the rest no longer fall through the movie path on Asian Drama / Anime.
- **Change:** Sources rows show the provider and stream name on two lines (server on top, stream below) instead of one truncated `Provider · Stream` label.
- **Change:** Settings → Sources → Forja plugins (Built-in) uses **Movie & TV** / **Anime** / **Drama** tabs instead of stacking every group under the pack.
- **Fix:** 2Embed / MultiEmbed skip dead xpass mirrors (pinecrest NXDOMAIN, hanging goldenmeadow) and open `tik`/`vip.1x2.space` first.
- **Fix:** Desktop Sources panel no longer leaves a huge empty band above the Forja / Torrents / Stremio / Nuvio tabs.
- **Fix:** After Forja auto Play, results land in Sources (same session cache / list as chip extract) — reopening the panel shows what loading already found without re-running those plugins.
- **Fix:** Player Sources Filters (quality / language / tech / size) actually filter Forja, Stremio, and Nuvio rows — not only Torrents.
- **Fix:** Playing a stream no longer crashes when Forja scrapers were still running (macOS JavaScriptCore) — Play stops Forja extracts without aborting magnet resolve or spawning parallel UI-thread JS forks.
- **Fix:** Opening Sources in the player after details no longer re-runs Forja extractors when results are still in the session cache.
- **Change:** Forja / Nuvio provider chips match kind tabs — hover loading `…` for ✕ cancel; desktop refresh icon appears only on chip hover and re-runs that chip only.
- **Remove:** Cineby is no longer a Sources → Forja scraper (Videasy covers the same STREAMCRYPTO network).
- **Fix:** Sources opened from Asian Drama / Anime details no longer stay stuck over other tabs after switching the navbar.
- **Fix:** Anime catalog Sources (white link Play) pass AniList / MAL into Forja plugins instead of rematching from TMDB.
- **Fix:** Anime Forja scrapers keep AniList episode context (no longer coerced to movie ep1) — Miruro / VidNest Anime / Megaplay resolve again.
- **Fix:** AnimePahe Forja chip treats `anime` as episodic (uses MAL + episode) instead of the movie/TMDB path that always returned empty.
- **Change:** Sources → Forja chips soft-group by Movie / TV / Anime / Drama — other categories stay available under Filters → Category; chip selection is remembered per panel (movie ≠ anime ≠ drama). Asian Drama Forja shows **KissKh** plus Videasy, VidLink, VixSrc, VidNest, VidRock, VidSrc.sbs, 2Embed, and MultiEmbed by default.
- **Remove:** Sources → Forja **OnlyKDrama** scraper (Cloudflare-blocked; removed).
- **Change:** Play sources list **Forja** first; fresh installs only enable Forja (torrent / Stremio / Nuvio / Webstreaming off). **Webstreaming** (sniffing extractors) is admin-only.
- **Fix:** Sources → Forja parallel scrapers run in Rust QuickJS off the UI thread — multi-chip resolve no longer freezes or kills the app under load.
- **Fix:** Sources → Forja scrapers (including Videasy) keep resolving when several chips run at once — finishing peers no longer cancel each other’s HTTP.
- **Fix:** Anime and Asian Drama green **Play** honor **Webstreaming** like movies — VidLink sniff and KissKh third-party embed sniff only run when that play source is on.
- **Add:** Asian Drama green **Play** runs Forja Auto when Forja + Auto are on and Webstreaming is off (races drama plugins; KissKH native path otherwise).
- **Add:** Anime green **Play** runs Forja Auto the same way (races anime plugins; Megaplay / VidNest / Miruro path otherwise).
- **Fix:** Asian Drama Sources → Forja **KissKh** uses the show’s KissKh episode id (same as green Play) instead of rediscovering via TMDB title search that returned nothing.
- **Fix:** Sources → Forja **KissKh** Episode resolve mints consumet `kkey` in rust-js (`ctx.crypto.kisskhKkey`) so the Episode API returns JSON instead of the SPA shell.
- **Fix:** Sources → Forja rust-js scrapers get CryptoJS AES/HMAC, nested hop mirrors, CineJoy scrypt PoW, and cheerio HTML parsing without falling back to UI-thread JS.
- **Fix:** When a Forja rust-js scraper falls through to `ctx.host`, sniff runs on Dart without re-running the whole plugin on flutter_js.
