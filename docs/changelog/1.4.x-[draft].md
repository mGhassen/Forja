# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.128 (`v1.4.128`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### TV
- **Fix:** From the top Search icon on Home / Anime / Asian Drama, D-pad Down lands on the hero gallery (Left/Right change slides) instead of jumping to View details.
- **Fix:** From the hero gallery (backdrop) on Home / Anime / Asian Drama, D-pad Down lands on View details.
- **Fix:** On Home, D-pad Down from View details goes Featured This Month → Popular (and Up reverses — no longer skips Featured).

### Features
- **Add:** Search filter lens (tune icon) — Films/Series, minimum score scrub, and year-range timeline; active filters dock as clearable ghost tokens. Typed operators still work (`>=8`, `films`, `2020-2025`).

### UI
- **Add:** Anime and Asian Drama hubs get a Home-style top menu — **Search**, **Films**, **Series**, and **Categories** as text tabs (search is first, not a corner icon).
- **Change:** Home top menu puts **Search** first as text (same style as Films / TV Shows / Categories), not a trailing icon.
- **Change:** Home, Anime, and Asian Drama hub heroes keep title and action buttons fixed — only the backdrop and gradients slide.
- **Fix:** Sources shows every enabled Torrents / Stremio / Nuvio / Forja tab and Forja provider chips as soon as you open the panel — no staggered load after the title is open.
- **Fix:** Anime and Asian Drama search on desktop is ready to type as soon as it opens (same as movies Search — no Enter first).
- **Fix:** Anime details episode list appears immediately from the catalog episode count — no longer stuck on skeletons waiting for AniList thumbs / TMDB.
- **Fix:** Anime hub catalog rails load in parallel with Trending (no longer empty until Trending finishes).
- **Fix:** Asian Drama hub paints Spotlight / Latest first, then fills the other rails — no full-page skeleton for the entire KissKH home fetch.
- **Fix:** Anime hub no longer drops D-pad focus when TMDB hero backdrops load in.
- **Fix:** Asian Drama hub matches Anime/Home focus behavior — no delayed Play steal after TMDB synopsis; synopsis enrich stays in the hero subtree.

### Live & IPTV
- **Fix:** Live Sports sport chips follow the time window — **Live** only lists sports that are airing (or 24/7), not every sport in the loaded schedule.
- **Fix:** Android TV Forja Live Streamed sources play after engine unlock — Exo no longer hits `strmd.st` directly (503); playback uses the same WebView CDN proxy handoff as the embed player.
- **Change:** Live Sports loading dialogs show the current step (unlocking source, preparing playback, checking sources, …) instead of one stuck **Resolving stream…** label.
- **Change:** Settings → **Forja Sports** is available to every account (not admin-only) when Live Matches and IPTV tabs are on.
- **Fix:** Switching Live Sports between **Forja Live** and **Forja Sports** keeps the match list — no catalog reload (only **Stremio** still loads its own schedule).
- **Fix:** Live Sports player **Source** menu marks the stream that is playing (**Playing** + check, scrolls it into view, TV autofocus) for Forja Live engine and Stremio — not only Forja Sports Xtream channels.
- **Fix:** Android TV IPTV MediaKit live no longer micro-freezes every few seconds on CDN reconnect — plays through the buffer instead of hard-pausing.
- **Fix:** Android TV IPTV channel guide stays open when you change channel (no flash away/back; second OK still closes).
- **Fix:** IPTV category reorder (hold OK / drag) no longer crashes the catalog sidebar.

### Sources
- **Fix:** Anime / Asian Drama **Sources** reuses the same ~30-minute Forja/Nuvio session cache as movies — reopening the panel or toggling Forja chips no longer reloads after TMDB match or empty scrapers (kind/chip **reload** still retries).

### Player
- **Fix:** After switching episodes in the player, Back returns to details — not the previous episode.
- **Fix:** Next / previous episode stops the current stream immediately so it does not keep playing under the loader or alongside the new episode.
### Player
- **Fix:** Trailers open at HD (adaptive ≤1080p) instead of stuck muxed 360p; Quality switching uses the same ladder, with muxed only as a silent-audio fallback. Age-restricted YouTube trailers fall back to the in-app embed (same as before native) so they play without a YouTube sign-in.
- **Change:** Trailer stream resolve warms when details trailers appear, and captions load only when you open Subtitles — faster first frame.
- **Fix:** Sources panel only highlights the resumable or currently playing row — not every source when a title has resume progress.
- **Fix:** Opening Sources while something is playing no longer locks Forja / Nuvio chips to that one provider — **All** and your multi-select stay usable (player and details).
- **Fix:** Anime and Asian Drama green **Play** use the same Forja Auto loading as movies (Sources → Forja pool, first working server wins, reuse session cache — not the old extract-all-then-probe race).
- **Fix:** Sources list no longer jumps back to the playing card every time results update while you are scrolling.
- **Fix:** Next / previous episode (and Episodes picks) on a Forja stream re-run the same Auto loading as green **Play** for movies, TV, Anime, and Asian Drama.
- **Fix:** Anime hub **Resume** / Continue Watching uses the same Forja Auto green **Play** path when Auto is on (no separate old host resolve).
- **Change:** Loading screen status shows steps (finding / checking / probing / opening) — server names stay in the layers list only.

### TV
- **Fix:** Player chrome auto-hides again after idle on Android TV — controls no longer stay up forever when focus sits on Back, the seek bar, or other chrome buttons.
- **Fix:** Home / Anime / Asian Drama hero D-pad: left from My List pin returns to View details, and down reaches the catalog again; selecting Asian Drama from the nav rail lands on View details once hero cards are ready (retries instead of leaving focus on the rail).
- **Fix:** On Android TV Live Sports, after Refresh the remote focus stays on Refresh instead of dropping.
- **Fix:** On Android TV Live Sports, switching **Forja Live** ↔ **Forja Sports** (or another server) keeps D-pad focus on the server button — same as Catalog and time.
- **Fix:** IPTV portal panel: D-pad up from header actions lands on the Portals chip (not Sort).
