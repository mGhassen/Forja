# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.232 (`v1.4.232`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Features
- **Add:** Web Profile settings → **Forja plugins** (pack manifest URLs sync with the app, menu before Stremio addons).
- **Change:** Web Profile settings save immediately on edit — no Save changes button.

### UI
- **Add:** Settings → Sources → Nuvio and Forja pack rows have a switch to enable or disable that pack (Forja keeps per-plugin toggles when you turn the pack back on).
- **Change:** Settings → Forja Sports **Catalog** uses the same expandable pack rows as **Live plugins** (name, path, version, expand for toggles).
- **Change:** Settings → Sources → Forja pack rows show the manifest URL under the pack name.
- **Change:** Settings → Sources → Jackett and Prowlarr show only for admin accounts.
- **Change:** Android TV Settings shows **Sources** (torrents, Stremio, Nuvio, Forja) when those play sources are on — WebStreamr, Debrid, Lists, and Data & backup stay hidden.
- **Change:** Settings → Sources → Forja lists every installed pack (Providers, Live, Catalog, community) with Live / Catalog tabs — not Providers-only — and sits first on the Sources page.
- **Change:** Settings → Forja Sports is empty until Live or Catalog plugins are installed (setup stays under Sources → Forja).
- **Fix:** Cloud / web account settings sync no longer flash-reloads the Settings page or steal focus when nothing local changed.
- **Change:** Settings → Forja plugins shows installed packs immediately; network refresh runs in the background.

### Player
- **Add:** Seek bar shows colored zones for intro/recap (blue), credits (seafoam), and next-episode preview or near-end (amber) when segment data is available.
- **Fix:** Details white Play opens Sources immediately again — Torrents / Stremio / Nuvio stay usable while Forja plugins install; only the Forja tab shows loading.
- **Fix:** DahmerMovies resolves via `st.111477.xyz` stream links (direct play) instead of scraping `a.111477` file URLs that hit Cloudflare.
- **Remove:** Sources → Forja no longer shows a duplicate **111477** chip next to DahmerMovies (same script).

### Live & IPTV
- **Fix:** IPTV live recovery upgrades to **Auto** for installs still on Stable / old stall default (Classic unchanged) — stall is managed per source without picking a mode each time.
- **Fix:** Auto on Stalker no longer reconnects like stall was on — healthy demuxer cache holds when stall reopen is off (playhead often stays at 0).
- **Fix:** Reopening IPTV from the nav restores the last category (including Favorites / Already watched) and scrolls/focuses the last played channel without autoplay.
