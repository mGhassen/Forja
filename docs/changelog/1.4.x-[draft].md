# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.81 (`v1.4.81`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Player
- **Fix:** Forja green Play uses the same Sources → Forja provider pool (not a second extractor) and plays the first working stream, then cancels the rest.

### Sources
- **Fix:** After green Play from a Forja plugin, Sources opens on the Forja tab with that plugin selected and the playing row highlighted (including proxied CDN URLs).
- **Fix:** Sources panel remembers your tab, provider chips, and filters when you close and reopen it (details and player).
- **Fix:** MovieBlast and NetMirror Forja providers return streams again — MovieBlast resolves titles from TMDB when missing, NetMirror accepts live `otp` player responses and refreshed detect hosts.
- **Fix:** MovieBlast Forja rows open instead of toasting “file isn’t available” — signed CDN links skip the flaky pre-play HEAD check (same as Nuvio).
- **Fix:** NetMirror Forja playback no longer hits the “Too Many Requests / STOP Abuse” screen — uses the same net27 embed API as D3adly Nuvio (with videodownloader Referer on MovieBox CDN), fewer NewTV calls as fallback, and no extra CDN probe before open.
- **Fix:** 1Shows Forja provider works again after their download decrypt key rotated.
- **Fix:** DahmerMovies / 111477 listings show streams again — Cloudflare beacon script no longer treated as a rate-limit block.
- **Fix:** 111477 playback auto-solves the CDN “Download Locked” math captcha (force-release) so a second session can open the file.
- **Fix:** VidRock and Vidzee Forja streams on the 1shows CDN play again — poison ad playlists are filtered, Astra expands through streamrk, in-player source switches use the HLS strip proxy, and playback matches WebStreamr.
- **Add:** 1Shows as a Forja stream provider (HubCloud / direct links from the 1Shows catalog).
- **Change:** Forja Sources cards show the same meta chips as Torrents (quality, size, MKV/MP4, codec, Atmos/HDR, BluRay/WEB-DL) when plugins return a release label — clean title, no emoji rows.
- **Fix:** 4KHDHub / HubCloud Forja providers return streams again — follow `/drive/` entry pages to PixelServer and 10Gbps links instead of dropping them.
- **Fix:** HDHub4u Forja TV episodes return HubCloud streams again — episode rows parse correctly, HubCloud link scrape no longer depends on broken cheerio selectors, and engine-js provides a `URL` polyfill (`URL is not defined` was wiping extracts).
- **Fix:** Hexa Forja provider returns streams via the enc-dec crypto path again instead of deferring to a host fallback Sources never runs.
- **Fix:** HDHub4u Forja search works again — uses the live pingora Typesense endpoint (old glass search host was 404).
- **Fix:** Castle Forja TV shows return streams again — large catalog IDs are kept as strings so details and episode lookup no longer fail after AES decrypt.
- **Fix:** Hexa Forja provider returns streams again — decrypted `sources` rows are parsed correctly instead of deferring to a missing host sniff.
- **Fix:** Tapping a Forja stream shows the loading screen while the file is checked, and a toast if that file is gone (no more blank wait).
- **Remove:** Dead Forja Sources providers (Goated, DooFlix, Peachify, BingeBox, UFlix, ShowBox, CineVibe, MyCima) — APIs or embeds are down, revoked, or unusable without config.
### UI
- **Change:** Nav tab **Live Matches** is now labeled **Live Sports**.
- **Fix:** Desktop Search accepts keyboard input immediately when you open the tab — no Enter/OK step like Android TV.
- **Fix:** Sources panel **Torrents** rows highlight on hover again (same as Forja / Stremio / Nuvio).

### TV
- **Fix:** Android TV Exo (IPTV and movies) no longer lets the screensaver / Ambient Mode start while video is playing.
- **Fix:** Settings → Forja Sports league chips on Android TV scroll through the last sport and keep the bottom of the page visible while D-pad browsing.
- **Fix:** Android TV player puts D-pad focus back on **Play** when chrome is up and focus was lost (idle hide / empty focus).
- **Fix:** Android TV Home (and hub) hero keeps D-pad focus when flipping slides — no more dead focus after gallery left/right.

### Live & IPTV
- **Fix:** IPTV category sidebar keeps a single focus highlight on any ↑/↓ pace — snap chrome, muted open-group mark, and no 2-step hold skip.
- **Fix:** IPTV **Portals** panel mouse/trackpad scroll no longer jumps back to the top (or the playing portal) when status probes refresh the list.
- **Fix:** Live Matches **server** / **Catalog** / **schedule window** top-bar buttons highlight on hover and D-pad focus again (same chrome as IPTV Portals).
- **Fix:** Live Matches **Servers** lists Forja Sports / Stremio immediately when available — no flash of Forja Live alone while prefs load.
- **Fix:** Live Matches live cards always show the play button and open the stream picker — empty events say **No streams available** in the panel instead of a **Not yet available** badge with no play control.
- **Change:** Live Matches sport category circles are centered (same as Anime / Home mood rows).
- **Change:** Settings → Forja Sports **Catalog** defaults to **Streamed**, **PPV**, and **StreamFree** only (TimStreams, WatchFooty, Streamic, ESPN stay available but off until you enable them).
- **Add:** IPTV Live category reorder shows a growing green circle while you hold (from the press point on desktop, row center on Android TV) before drag / float starts.
- **Change:** Live Matches **Forja Sports** uses the same **Catalog** JS schedule as **Forja Live** / **All** (TimStreams, StreamFree, ESPN, … via the Catalog button + Settings toggles) — then matches channels on your Xtream portal.
- **Change:** Forja Sports channel picker rows match the movie **Sources** panel — flat cards, left live/dead check bar on hover/focus, and **T1–T4** as meta chips (no solid tier pill / chevron).
- **Change:** Live Matches stream resolve defaults to **Engine** (native player). **Settings → Forja Sports** is admin-only. **Forja Sports** is on by default with all leagues matched.
- **Change:** Live Matches top bar shows a neutral **server** button labeled with the active source (**Forja Live** / **Forja Sports** / **Stremio**), a matching **Catalog** button with the active catalog name, and a **schedule window** button — no green fill, no Engine/IPTV mode pill, and no catalog chip row.
- **Add:** Live Matches **schedule window** button next to **Catalog** (**Live** / **1h** / **3h** / **6h** / **All**, default **1h**) — catalogs load only events in that window (**Live** = airing + 24/7 only); widening re-fetches.
- **Remove:** Live Matches **Servers** no longer lists PPV, Streamed, or MutStreams — only **Forja Live**, plus **Forja Sports** / **Stremio** when those are enabled (a saved pick for a hidden row returns to Forja Live).
- **Change:** Live Matches **Servers** shows **Stremio** only when an installed addon is assigned to Live and exposes sport catalogs.
- **Fix:** Live Matches on Android TV lists the same **Servers** as desktop; disabling **Forja Sports** or removing Live sport addons hides those rows and returns you to **Forja Live** (no IPTV **Portals** bar).
- **Fix:** Live Matches **Catalog** picker (All / TimStreams / ESPN / …) is D-pad reachable from the top bar on Android TV — **↓** from Catalog reaches sport chips and match cards.
- **Fix:** Live Matches **Forja Live** catalogs (ESPN, TimStreams, Streamic, StreamFree, WatchFooty) load through native Rust again — the 1.4.81 EngineJS path skipped them and left catalogs empty on desktop.
- **Fix:** Live Matches **Engine** resolve (TimStreams, Streamed, PPV) falls back to flutter_js when EngineJS returns no streams — restores `ctx.live` unlock/sniff bridges the Rust runtime never had.
- **Fix:** Desktop IPTV catalog shows category **pin** and hover highlight again; portal rows reveal **favorite / copy / edit / delete** on hover (D-pad hybrid no longer treated as leanback TV).
- **Fix:** Long-press EPG on live channel cards works on desktop again.
- **Fix:** Channel guide hover EPG peek, search recent-row hover fill, Settings nav/provider **drag handles**, and portal form platform-tab hover work on desktop again (same leanback vs mouse gate).
- **Fix:** IPTV portal form fields stay editable with the mouse on desktop (browse-until-OK is leanback-only).
- **Fix:** Android TV IPTV **Portals** panel no longer traps D-pad ↓ while scrape is loading or yanks focus when new portals arrive during ↑/↓ browse.
- **Fix:** In-player channel guide EPG peek sits beside the rail (not stacked over live video) and stays vertically centered — hiding it no longer freezes Android TV / the emulator, and it no longer tracks the hovered row or covers the channel list.
- **Fix:** In-player channel guide keeps the open category’s channels while you hover another group — hover only highlights; click opens. Title stays on the open category.
- **Fix:** IPTV catalog on desktop keeps the open category’s channels while hovering another group (no empty “Press OK to open” pane).
- **Fix:** Android TV IPTV MediaKit live shows **Buffering…** and refills when the cache runs dry instead of freezing with no banner; **Reload** stays on MediaKit (no silent switch to ExoPlayer).

### Player
- **Change:** Player **Sources** button shows the active source name next to the link icon (same row as Audio / Subtitles).
- **Fix:** Resuming deep into HLS (Videasy and similar) no longer triggers a “Reconnecting…” remount while segments are still loading — resume seeks skip the stall watchdog for ~25s and deep seeks wait up to ~45s before remount.
- **Fix:** Watch history no longer rewrites the same timestamp every few seconds during pause, lifecycle blur, or post-seek remount.
- **Fix:** Post-seek scrub on remote HLS remounts at the seek time when playback stays stuck; a failed remount reopens the source instead of stopping playback.
- **Fix:** Resume and in-player server / quality switches keep your place on MediaKit HLS (open at the seek time instead of restarting at 0:00).
- **Change:** Android TV player **Sources** / **Episodes** / **Source** use the same right-side panel as desktop (no centered leanback dialog).
- **Fix:** Trailer **Quality** menu scrolls when many resolutions are available instead of overflowing the panel.
- **Fix:** Trailer **Quality** switches YouTube resolution again (googlevideo no longer gets a self-Referer that returned HTTP 403 on reopen).
- **Fix:** Android TV **Sources** panel keeps D-pad ↓ reachable while results load and no longer auto-jumps focus when the first stream appears.
- **Fix:** Player **Sources** panel opens again — list no longer crashes on a negative margin.
