# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.153 (`v1.4.153`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Player
- **Change:** **Forja Auto** is on by default — green Play races Forja plugins when Webstreaming is off (turn Auto off in Settings → Playback to use Sources only).
- **Fix:** Anime / Asian Drama player **Sources** reuses the same Forja session cache as green Play (and keeps loading unfinished plugins) — no more empty “No matching sources” after Auto.
- **Fix:** Cancelling Forja scrapes mid-play (source switch / probe fail) no longer crash the macOS app by restarting scrapes on the UI JavaScript engine.
- **Fix:** Tapping a Sources row blocks further taps until the player (or loading screen) takes over — no accidental clicks during the start lag.
- **Fix:** Starting a source no longer re-reads Debrid settings from storage on every tap (cached; skipped entirely when Debrid is off).

### Sources
- **Change:** Sources **All** only highlights All (still loads every selected provider) — tap one chip to filter to it; multi-select without All stays the same.
- **Add:** KissKH mirrors `kisskh.is` and `kisskh.id` under Asian Drama server reliability.
- **Fix:** KissKh under Sources → Forja tries all KissKH mirrors when one host is down.
- **Fix:** KissKh no longer returns empty when the episode payload puts third-party embeds in a string instead of a list.

### UI
- **Change:** Home discovery rails open on one TMDB page and load a second page only when you scroll near the end of that row.
- **Change:** Asian Drama **Popular** is today’s TMDB Asian TV (not KissKH Top Rating / Hollywood) — tap opens normal movie/TV details.
- **Fix:** Asian Drama hub **Films** / **Series** / country refill the existing Latest · Trending · … rails from KissKH explore (2–3 sequential list calls + memo; no Anime row under Films/Series; no one-off filter row).
- **Fix:** Asian Drama country Categories match KissKH regions (South Korea / Chinese / Japan / …); **Indonesia** added; **United States** removed.
- **Fix:** Anime hub **Films** / **Series** / Categories hide the duplicate **Trending** rail and keep **Top Rated** (hero uses Top Rated under those filters).

### TV
- **Fix:** Live Matches sport categories on Android TV — ↑ from a category returns to the Servers button (including after choosing Stremio).
- **Fix:** Catalog rows (Anime, Home, …) keep D-pad right on the last card — no jump into the next row.

### Live & IPTV
- **Fix:** Stalker live channels no longer go through the Xtream TS continuity proxy (expired create_link tokens no longer loop Failed to open / unrecognized format).
- **Fix:** Flaky live IPTV channels that drop mid-stream reconnect or show offline instead of crashing the macOS app.
- **Fix:** Stalker / live TS channels no longer soft-reopen every few seconds while the picture is already playing.
- **Fix:** Dead Stalker channels refresh their play link on reconnect; after repeated failures they show offline and turn red instead of looping forever.
- **Fix:** Edit Portal pre-fills Portal name with the same title shown on the portals card (account name when you never set a custom label).
- **Fix:** Live channel hover/focus status no longer marks playable streams red (especially Stalker/HLS) — the probe matches a normal play open instead of a Range sniff that many CDNs reject.
- **Change:** IPTV catalog loading shows a center ticker for the open shelf (channels / movies / series) with step text instead of a bare spinner.
- **Fix:** Hover/status probe no longer replaces a known IPTV end date with **Ends: Unknown** (keeps the date and marks it with `*` when login did not confirm).
- **Fix:** Unreachable Xtream portals show a short “could not reach portal” message instead of a raw request URL (which could include username/password).
- **Fix:** Opening the IPTV Portals panel pulls newly assigned cloud portals without reloading portals you already have (or the active catalog).
- **Change:** IPTV **Reopen on buffer stall** and **IPTV match display refresh** are on by default and visible only to admin accounts.
- **Change:** Live Matches schedule chip opens **Status** (Airing / Upcoming / Airing + upcoming) and **Horizon** (1h–24h) in one sheet — Airing keeps stream-less catalog lives.
- **Fix:** WatchFooty catalogs all sports with posters; Engine unlocks sportsembed to HLS with CDN probe + direct `wfty.st` playback (no fake LIVE from the 6h kickoff heuristic).
- **Add:** Forja Sports matches and plays channels from Stalker portals (EPG via MAG; stream link created when you pick a channel).
- **Add:** Programme guide (EPG) on Stalker portals — NOW/NEXT on cards, long-press sheet, in-player guide, and Live EPG grid when the portal provides listings.

### Features
- **Change:** **Crash reporting** and **Product analytics** are on by default and visible to everyone under Settings → About → Privacy (plain-language privacy copy; not admin-only).
- **Change:** Product analytics (when on) links usage to your signed-in account without using your email, plus app version and device basics.
- **Fix:** Simkl background sync only pulls what changed (and skips for a while after a sync) instead of re-importing the whole watching list into Continue Watching every time.
- **Fix:** Continue Watching play follows Settings → Playback like details green Play — Webstreaming off means no sniff; Forja Auto runs when enabled.
- **Fix:** Continue Watching from Home opens that title’s details before play — Back from the player returns to details, not Home.
