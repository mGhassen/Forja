# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.232 (`v1.4.232`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Features
- **Add:** Home, Anime, Asian Drama, and Arabic now come from the new **ForjaHQ Hubs** plugin pack — rows, moods, and ranked lists are defined by the pack instead of being baked into the app.
- **Change:** Hub tabs use the shared cinematic hero, Continue Watching, and pack-backed Search (Anime / Asian Drama / Arabic top bar).
- **Change:** Home / Anime / Asian Drama / Arabic nav entries come from the Hubs pack (`nav` specs) — labels, accents, and tab bodies follow the pack.
- **Remove:** Legacy Home / Anime / Asian Drama / Arabic browse screens — hub tabs always use Catalog Shell from the Hubs pack.
- **Change:** Hub Films / Series / Categories menus refetch Catalog Shell rails from the Hubs pack (not a dead chrome toggle).
- **Change:** Home, Anime, Asian Drama, and Arabic each install from their own ForjaHQ pack URL (four hub manifests — one per tab).
- **Change:** ForjaHQ pack URLs are required at build time — Providers, Live, Catalog, Home, Anime, Asian Drama, and Arabic.
- **Add:** Arabic is selectable again in the navigation bar (rows stay empty until an Arabic source ships).
- **Add:** Web Profile settings → **Forja plugins** (pack manifest URLs sync with the app, menu before Stremio addons).
- **Change:** Web Profile settings save immediately on edit — no Save changes button.

### UI
- **Fix:** Anime hub shows the cinematic hero and catalog rails again (AniList rows were crashing on a missing kit helper).
- **Change:** Hub TMDB backdrops come from the pack via shared `ctx.host.tmdb.match` (not a hard-coded Anime tab enrich in the shell).
- **Change:** Hub plugin on/off (Sources → Forja) is separate from Features show/hide — every hub with `nav` stays in Features even when the plugin is disabled.
- **Change:** Home / Anime / Asian Drama hub row order and widgets match the pre–Catalog Shell hubs again (hero bleed, **What's your mood?** / **Pick your vibe**, Continue Watching, Because you watched, Trakt rails, genre rows, HomeMovieCard / numbered Popular & Top 10).
- **Fix:** Stremio / ForjaHQ addon rows no longer blink when a hub pack plugin id collides with a Providers extract (Asian Drama hub is `kisskh-hub`).
- **Add:** Settings → Sources → Forja pack tabs include **Hubs** for Home / Anime / Asian Drama / Arabic catalog plugins (separate from Live **Catalog**).
- **Add:** Settings → Sources → Nuvio and Forja pack rows have a switch to enable or disable that pack (Forja keeps per-plugin toggles when you turn the pack back on).
- **Change:** Settings → Forja Sports **Catalog** uses the same expandable pack rows as **Live plugins** (name, path, version, expand for toggles).
- **Change:** Settings → Sources → Forja pack rows show the manifest URL under the pack name.
- **Change:** Settings → Sources → Jackett and Prowlarr show only for admin accounts.
- **Change:** Android TV Settings shows **Sources** (torrents, Stremio, Nuvio, Forja) when those play sources are on — WebStreamr, Debrid, Lists, and Data & backup stay hidden.
- **Change:** Settings → Sources → Forja lists every installed pack (Providers, Live, Catalog, community) with Live / Catalog tabs — not Providers-only — and sits first on the Sources page.
- **Change:** Settings → Forja Sports is empty until Live or Catalog plugins are installed (setup stays under Sources → Forja).
- **Fix:** Cloud / web account settings sync no longer flash-reloads the Settings page or steal focus when nothing local changed.
- **Change:** Settings → Forja plugins shows installed packs immediately; network refresh runs in the background.

### Player
- **Add:** Seek bar shows colored zones for intro/recap (blue), credits (seafoam), and next-episode preview or near-end (amber) when segment data is available.
- **Fix:** Details white Play opens Sources immediately again — Torrents / Stremio / Nuvio stay usable while Forja plugins install; only the Forja tab shows loading.
- **Fix:** DahmerMovies resolves via `st.111477.xyz` stream links (direct play) instead of scraping `a.111477` file URLs that hit Cloudflare.
- **Remove:** Sources → Forja no longer shows a duplicate **111477** chip next to DahmerMovies (same script).

### Live & IPTV
- **Fix:** Live Matches merges the same fixture when one catalog says `Away at Home` and another says `Home vs Away` (PPV ↔ Streamed reverse titles).
- **Add:** Live Matches cards and stream pickers show viewer counts from catalogs that report them (PPV, StreamFree, TimStreams); cards use the same red-dot badge as PPV, merged cards sum catalogs, and the stream picker header sums every listed stream.
- **Change:** Live Matches plugin labels, catalog Referers, and native unlock paths come from plugin pack config — not a hardcoded list of site plugin ids.
- **Fix:** WatchFooty stream picker lists every unlockable source (delta/echo/sigma/…), not only the first two.
- **Fix:** TimStreams Engine resolve unlocks embed pages to HLS instead of toasting “no playable stream” on every tap.
- **Fix:** StreamFree Live Matches cards show match backdrops again (thumbnails were relative and resolved against the wrong host).
- **Fix:** IPTV live recovery upgrades to **Auto** for installs still on Stable / old stall default (Classic unchanged) — stall is managed per source without picking a mode each time.
- **Fix:** Auto on Stalker no longer reconnects like stall was on — healthy demuxer cache holds when stall reopen is off (playhead often stays at 0).
- **Fix:** Reopening IPTV from the nav restores the last category (including Favorites / Already watched) and scrolls/focuses the last played channel without autoplay.
