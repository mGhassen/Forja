# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.0 (`v1.4.0`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### TV
- **Fix:** On Android TV Sources, D-pad **→** from search reaches Filters; opening Filters moves focus into the panel, and Back returns to the Filters button before closing Sources.

### Live & IPTV
- **Change:** Live Matches server and Settings category renamed from My IPTV / My IPTV sports to **Forja Sports**.
- **Change:** On Android TV, Live Matches **Servers** offers **All**, **Stremio**, and **Forja Sports** (PPV / Streamed / MutStreams stay off TV). Opening a match from All only lists **Forja Sports** and **Stremio** sources — no PPV / Streamed rows.

### Player
- **Fix:** On Android TV, remote **Back** while player chrome is up hides the controls first — it no longer leaves the player on the same press.

### Sources
- **Remove:** Cineby is no longer a Sources → Forja scraper (Videasy covers the same STREAMCRYPTO network).
- **Fix:** Sources opened from Asian Drama / Anime details no longer stay stuck over other tabs after switching the navbar.
- **Fix:** Anime catalog Sources (white link Play) pass AniList / MAL into Forja plugins instead of rematching from TMDB.
- **Fix:** Anime Forja scrapers keep AniList episode context (no longer coerced to movie ep1) — Miruro / VidNest Anime / Megaplay resolve again.
- **Fix:** AnimePahe Forja chip treats `anime` as episodic (uses MAL + episode) instead of the movie/TMDB path that always returned empty.
- **Change:** Sources → Forja chips soft-group by Movie / TV / Anime / Drama — other categories stay available under Filters → Category; chip selection is remembered per panel (movie ≠ anime ≠ drama).
- **Change:** Play sources list **Forja** first; fresh installs only enable Forja (torrent / Stremio / Nuvio / Webstreaming off). **Webstreaming** (sniffing extractors) is admin-only.
- **Fix:** Sources → Forja parallel scrapers run in Rust QuickJS off the UI thread — multi-chip resolve no longer freezes or kills the app under load.
- **Fix:** Anime and Asian Drama green **Play** honor **Webstreaming** like movies — VidLink sniff and KissKh third-party embed sniff only run when that play source is on.
