**Status:** draft

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Features
- **Change:** Live Sports is a catalog hub pack — nav and a generic `live_schedule` list layout come from ForjaHQ Live Sports. Host top bar keeps **Catalog**, **Schedule**, **Refresh**, and **Portals** (no Forja Live / Forja Sports / Stremio mode chip). Streams open on match detail under **Providers** / **Live TV**.

- **Fix:** Stremio search rows open as native addon catalog items (opaque id + addon URL) instead of being forced through TMDB/IMDB lookup; Sources uses the catalog addon that returned the hit.

### Sources
- **Fix:** Anime and Asian Drama Sources → Torrents find releases again — packs set `torrentEp` so search uses `Title 05` (not `SxxExx`), plus TMDB IMDb when enrich matched (Torrentio + Nyaa).
