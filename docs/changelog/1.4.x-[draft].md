# 1.4.x — Atarin

**Status:** draft  
**Since release:** 1.4.189 (`v1.4.189`)

User-facing changes for the next **1.4.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.4.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### UI
- **Fix:** Escape on desktop closes the current screen (player, details, and so on) instead of quitting the app.
- **Fix:** Anime hub no longer reloads the catalog when you pull down to scroll.
- **Fix:** Asian Drama episode lists show KissKH episode numbers (including episode 0) instead of renumbering from 1.

### Features
- **Fix:** Asian Drama Continue Watching posters load again when history stored a TMDB image path instead of a full URL.
- **Fix:** Anime and Asian Drama Continue Watching now updates the correct episode and watch time when Forja Engine Auto is your playback path.
- **Fix:** Continue Watching stays on the tab you watched — Home no longer shows or resumes Asian Drama or Anime rows that belong on those hub tabs.

### Player
- **Fix:** In-stream (embedded) subtitles show on open again — auto-select waits for mpv to finish probing tracks instead of only picking online subs.
- **Change:** **Max stream quality** defaults to **4K** (top ladder) instead of Auto’s soft mid-high ceiling.
- **Fix:** Forja Auto loading no longer shows a stuck **5 ACTIVE** count — cached servers probe one at a time and the footer only shows checked/up totals.
- **Fix:** Anime and Asian Drama auto-pick provider, Wyzie, or Levrx subtitles again on open; SubtitleCat/Mysubs stay manual-only to avoid wrong-title matches.
- **Fix:** Asian Drama player episode list shows posters, TMDB synopsis/runtime, and switches episodes again on Forja Engine Auto.
- **Fix:** Asian Drama episode thumbnails in the player list show the drama poster (or TMDB still) instead of blank tiles when KissKH has no per-episode art.
- **Fix:** Mobile playback saves Continue Watching progress every 15 seconds while playing, not only on pause or exit.
- **Fix:** Forja Engine resume reuses your last plugin and saved stream URL, then seeks to where you left off instead of racing from scratch at 0:00.
- **Fix:** Switching servers in the player (e.g. Videasy → VidLink) keeps your playhead instead of restarting at 0:00.
- **Change:** Post-seek reconnect shows **Reconnecting…** after a few seconds of stall and remounts sooner on deep seeks instead of a long dead buffer first.

### Live & IPTV
- **Change:** Android TV IPTV live on MediaKit uses leaner memory for HD/FHD (height- and bitrate-aware cache) while keeping the full buffer window for 4K.
- **Fix:** Frozen live picture with a full demuxer cache on Android TV MediaKit shows Buffering and recovers (one snap, then player recreate if needed) instead of sitting on the last frame.
- **Change:** IPTV live recovery settings drop old version labels; **Reopen on buffer stall** is available to everyone when Stable is selected (clearer copy, no admin gate).

### Sources
- **Fix:** Continue Watching on source cards keeps the progress bar without lighting the whole row as selected — that fill is only the stream that’s playing.
- **Fix:** Stream source cards no longer show impossible file-size badges (e.g. **4 KB** from bad scraper bytes or **4K** misparsed as kilobytes).
- **Fix:** VidSrc.sbs nested Videasy (4K / STREAMCRYPTO) mirrors play again on peakstorm CDNs — playback keeps the player.videasy.to Referer instead of vidsrc.sbs.
- **Fix:** Peakstorm HLS opens the sibling master playlist at play time (engine rows, cache, remount) — seek and resume no longer stall on demuxed child URLs.
- **Fix:** Sources panel highlights the correct Forja row after post-seek reconnect (VidSrc.sbs no longer loses the green bar to VidLink when both share the same CDN URL).
- **Fix:** Manual HLS quality changes on peakstorm/Videasy CDNs (VidRock, VidLink, etc.) keep the selected variant instead of silently reopening the master playlist and stalling.
- **Change:** ForjaHQ mirror registry for MoviesMod, HDHub4u, 4KHDHub, UHDMovies, and MoviesDrive is hosted in the official plugin pack instead of a third-party repo.
- **Fix:** 4KHDHub search skips documentaries, tries title/year fallbacks, and picks the best card match instead of the first hit.
- **Fix:** Forja Engine HTTP providers no longer fall back to WebView sniffing when a scrape misses — the chip you pick is the path that runs.
- **Fix:** AnimePahe searches by title (xenmods-style) instead of requiring MAL id, uses release pagination + links API, and keeps the CF proxy fallback.
