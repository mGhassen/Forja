# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.289 (`v1.3.289`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Player
- **Fix:** Local torrent keeps disk use under a size you set in Settings (default 2 GB on desktop, 1 GB on phone and TV). The title playing now is never deleted; oldest idle downloads are removed, and closing or switching a torrent deletes that download.

### UI
- **Change:** Home, Anime, and Asian Drama heroes drop the green Play button. The info action now reads **View details**.
- **Fix:** Anime, Asian Drama, and IPTV details keep the current page and layer TMDB in over time (backdrop, then logo/meta, then extra rows) instead of swapping the whole screen.
- **Change:** Sources panel rows, provider chips, and filter chips use the same hover fill as the rest of the app.
- **Fix:** Clicking the active My List status (Watching, Completed, …) removes the title instead of leaving it stuck.
- **Fix:** Intel Macs no longer glitch player subtitles, chrome, catalog cards, or text.
- **Change:** The profile LAN mark is a server dot (green/red). On desktop a bold vertical bar after the dot shows waiting, paired, idle, or playing. Android TV and other clients are the dot only.

### TV
- **Change:** Android TV torrent pair dialog puts **Open LAN** first; **Cancel** is text under it. **Open LAN** goes to Settings → LAN (category rail + pane).
- **Change:** Android TV remote power now quits Forja. Turning the TV back on opens the launcher, not a leftover session.
- **Change:** In the player, remote Back hides the controls if they are showing; Back again leaves. The Back icon still leaves immediately.
- **Fix:** After leaving the player or canceling stream loading on Android TV, D-pad focus returns to Play.
- **Fix:** On Android TV, remote Back in the torrent Sources panel closes the panel (Filters first if open) instead of leaving details or the player.
- **Fix:** Opening Sources on Android TV after leaving the player keeps D-pad in the panel.

### Sources
- **Add:** Sources tabs show an animated **…** while that category is still loading torrents or streams.
- **Fix:** Sources keeps your scroll position and hover when more rows arrive; it does not jump back to the top.
- **Change:** Torrents **All** highlights every enabled indexer chip, same as Nuvio All.
- **Add:** First time you turn on Direct torrent, Stremio, or Nuvio, Forja asks you to confirm you are aware of P2P terms. Playback then shows a clickable “You are aware of P2P streaming” notice above Play sources, with a check.
- **Change:** Android TV lists Direct torrent, Stremio, and Nuvio without pairing. Direct HTTP plays on the TV; magnets ask you to pair a desktop (or show that the desktop is offline). Paired P2P still runs on the desktop, not the TV.
- **Fix:** Sources → Nuvio with All selected keeps loading the rest of the scrapers instead of stopping after the first batch until you reload.
- **Change:** Torrents and Stremio in Sources show rows as each provider or addon returns, instead of waiting for every addon to finish.
- **Fix:** Nuvio hides HubCloud / 4kHdHub links when Google Drive has already exhausted that file’s download quota.
