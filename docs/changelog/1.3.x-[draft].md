# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.66 (`v1.3.66`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Live & IPTV
- **Change:** Live Matches on Android default to MediaKit (libmpv) instead of ExoPlayer — switch to Exo from the in-player Player menu if you prefer.
- **Fix:** On Android TV, IPTV Stream stats keeps D-pad focus on Close — chrome auto-hide no longer steals it after a few seconds.
- **Fix:** On Android TV, remote Back while IPTV Stream stats is open closes the stats panel only — it no longer also leaves the player back to the catalog.
- **Fix:** Streamed live matches on Android open again — the playlist is no longer blocked behind a failed cookie re-fetch that abandoned the stream.
- **Fix:** On Android TV, entering the Portals list focuses the active portal (or the first when none is selected).
- **Fix:** On Android TV, scrolling the Portals list with the D-pad is smoother — rows no longer probe health or expand action rails on every focus step.
- **Fix:** On Android TV, **→** on a portal row reaches favorite, then copy, edit, and delete again (nested row actions were blocked).
- **Fix:** On Android TV, IPTV category and channel lists (catalog and in-player guide) keep the focused row fully visible while scrolling, use denser channel rows with undistorted logos, and scroll without the old hitch.

### Player
- **Fix:** VixSrc and similar extensionless HLS playlist URLs play in ExoPlayer on Android again (MediaKit already worked).
- **Fix:** When a stream dies while you are already watching, playback stops with Retry (same server) instead of silently switching to another server.
- **Fix:** Android TV ExoPlayer no longer crashes and exits when auto-selecting preferred subtitles on streams with sideloaded tracks.
- **Fix:** On Android TV, D-pad left/right while player controls are visible move between buttons only — seeking stays on the progress bar (or when controls are hidden).
- **Fix:** On physical Android TV, ExoPlayer no longer stays audio-only with a black picture when SurfaceView fails to paint — it remounts on TextureView and continues playback.
- **Fix:** Leaving Forja for another app (for example Netflix on Android TV) pauses playback so audio no longer continues in the background; returning resumes if it was playing.
- **Change:** Player menus and overlays on Android TV move focus by on-screen position (nearest neighbor), not a single next/previous line.
- **Fix:** On Android TV, a stale “Playback failed” line no longer stays under the title after you pick another stream — stream status stays in the center overlay only.

### TV
- **Change:** On Android TV, D-pad on every tab, Settings, details, and Who’s watching moves focus spatially (↑/↓/←/→ to the nearest control) instead of walking a one-line next/previous chain.
- **Fix:** On Android TV, D-pad on ExoPlayer and MediaKit movie chrome moves off the Back button again (↓ to the progress bar, → to Player when shown).
- **Fix:** On Android TV, Cancel on the stream loading screen returns to the title details page instead of showing another loading screen.
- **Fix:** On Android TV, D-pad on the player transport row (Play, ±10s, sources) moves between controls again instead of sticking on Play.
- **Fix:** Nav rail icons stay on one vertical baseline when a label is shown (focused tab / profile) — they no longer sit higher or lower than unlabeled neighbors.
- **Fix:** Leaving a fullscreen player no longer rebuilds the left nav rail — it stays mounted while hidden during playback.
- **Fix:** On Android TV, episode cards in Home, Anime, and Asian Drama details arm on card OK (D-pad focus alone does not change the armed episode); the green play control on the armed card plays it, defaulting to episode 1 or your resume episode on open.
- **Fix:** On Android TV, focusing a catalog row near the bottom of Home, Anime, or Asian Drama scrolls it up with breathing room below (including the focus ring) instead of clipping it at the screen edge.

### UI
- **Fix:** Mobile bottom navigation labels no longer clip with a layout overflow stripe on Android.

### Features
- **Fix:** macOS installers no longer require Ventura 13.5 — Catalina 10.15+ works again (Intel included); passkeys stay unavailable on older macOS instead of blocking the whole app.
- **Fix:** While Forja is open, new app updates are checked in the background and shown when available (not only on cold start).
