### Live & IPTV

- **Fix:** Live channels no longer drop into "Reconnecting…" while they are recovering on their own. A brief upstream hiccup used to force a reconnect after 8 seconds even though the stream was still downloading, which threw away the buffer and started the stall over; the player now waits as long as data is still arriving.
- **Fix:** Live channel buffering is back to the settings that worked before the recent IPTV changes.
- **Fix:** Reload in the IPTV player responds again on live channels (it stopped working in 1.3.141), and now reconnects a stalled stream instead of only refreshing the buffer.
- **Fix:** Picking a stream for a live match now works with the remote — the source list opens as a focusable player menu instead of an unreachable sheet.
- **Change:** The player has a single source switcher in the bottom bar; the duplicate chip in the title bar is gone.
- **Fix:** On Android TV, switching the IPTV player from MediaKit to ExoPlayer no longer plays sound over a black picture with the controls stuck behind it.
