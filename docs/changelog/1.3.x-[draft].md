# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.148 (`v1.3.148`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### TV

- **Fix:** On Android TV, the movie player's bottom bar no longer traps the D-pad on the source button — right/left now walks the whole row (source, episodes, audio, subtitles, quality, settings) and up returns to the progress bar.
- **Fix:** Movies no longer judder on Android TV. Forja now asks the TV to switch to a refresh rate that matches the film's frame rate, so 24 fps content stops stuttering on a 60 Hz screen. The set returns to its usual mode when you leave the player.
- **Change:** On Android TV, skipping in a movie snaps to the nearest keyframe just before your target, so ±10s on the remote responds right away instead of stalling.

### Player

- **Fix:** On Android, seeking backwards in a movie no longer re-downloads footage you already watched — recent playback is kept in a bounded on-device cache and replays from storage.
- **Change:** Movies and series on Android buffer deeper and hold a short rewind window, so a brief network dip is less likely to interrupt playback.

### Live & IPTV

- **Fix:** Live channels stop dropping into "Reconnecting…" during a normal buffer refill. The player now checks whether the stream is still downloading before it decides the connection is dead, so a slow patch rides through instead of restarting — and the restart no longer throws away the buffer that was about to recover. This now works on both playback engines; the previous attempt only covered MediaKit and did nothing on ExoPlayer.
- **Fix:** On Android TV, IPTV on ExoPlayer no longer plays sound over a black picture with the controls stuck behind it — both on a fresh open and after switching from MediaKit in the Player menu.
- **Fix:** Live channels on ExoPlayer play more smoothly on Android TV. Forja now matches the TV's refresh rate to the channel's frame rate, so 50 and 25 fps channels stop juddering on a 60 Hz screen, and video decoding no longer competes with playback on older TVs.
