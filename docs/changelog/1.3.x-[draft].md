# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.9 (`v1.3.9`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Player
- **Fix:** Remote Back closes open player menus and panels before leaving the player (including IPTV and Settings drill-ins).
- **Change:** On Android TV, press Back twice to leave a player (movie, anime, Asian Drama, IPTV). The first Back shows controls; the second exits.
- **Change:** On Android TV, when player controls are hidden, D-pad **↑** focuses Back and **↓** focuses Play (hardware volume keys still control volume).
- **Fix:** Episodes search on Android TV (MediaKit and Exo) — **OK** / Done focuses the first result instead of playing it; **↑/↓** move through episodes; **OK** on a row plays it.

### UI
- **Change:** Download page shows platform icons in the list and detail pane; Windows and Mac each get their own “Stuck opening?” card next to that platform’s download.
- **Change:** Download buttons name the CPU architecture when the build has one (e.g. macOS Apple Silicon), even if only one file is available.

### TV
- **Change:** Android TV home banner shows the Forja wordmark instead of the F monogram.
- **Change:** Android TV no longer shows Direct torrent, Stremio, or Nuvio — even for admin accounts (Webstreaming only).
- **Change:** Android TV players no longer show a fullscreen button (IPTV and Live Matches).
- **Fix:** Android TV trailer player (and details hero trailer) no longer opens as a white screen — YouTube embeds keep hardware acceleration.
- **Fix:** Switching movies to MediaKit on Android TV shows video again (was sound with a black picture).
- **Fix:** Details page titles on Android TV no longer look doubled or soft — plain white text instead of the chromatic offset layers.

### Live & IPTV
- **Fix:** Android IPTV Player menu can switch ExoPlayer ↔ MediaKit (remembered in Settings); on TV, MediaKit shows video again.
- **Change:** Android TV live IPTV drops the soft 720p/bitrate cap so channels look sharper; keeps a live buffer a few seconds behind the edge.
- **Remove:** IPTV player no longer shows a volume button (use hardware / system volume).
- **Fix:** IPTV player search on Android TV — **OK** on the search field focuses the first result instead of opening it; **↑/↓** move through results; **OK** on a result opens the channel.
- **Change:** IPTV channel guide and search overlays use a flat translucent panel (no live blur) so browsing stays smoother on older Android TV boxes.
- **Fix:** IPTV catalog on Android TV — each category starts channel focus at the first tile; leaving and re-entering the same category still restores your place.
- **Fix:** Leaving the IPTV player on Android TV restores focus on the channel you were watching; **Back** steps channel → category → nav rail.
- **Fix:** IPTV catalog search on Android TV — **OK** opens the search field and keyboard; **Done** focuses the first matching channel (or the field in browse mode when empty); the **X** close control is D-pad focusable; closing with **X**, **Back**, or Escape returns focus to the **Search** button.
- **Fix:** IPTV Live / Movies / Series shelf sits flush with the category column on Android TV (no false hamburger inset on narrow windows).
- **Fix:** IPTV sort menu and other TV dialogs no longer scale on focus; D-pad no longer double-steps through menu rows (shared linear-menu + button focus paths).
- **Fix:** IPTV Portals panel on Android TV — D-pad **↓** from portal row actions (favorite / copy / edit / delete) moves to the next portal instead of getting stuck; header **↓** reliably reaches the list.
