# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.155 (`v1.3.155`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### UI
- **Change:** Series stream loading shows the selected episode (`S02E05`) under the status line — including webstreaming, torrent, and Stremio.

### Sources
- **Add:** Built-in torrent search providers you can toggle in Settings — Knaben, Pirate Bay, UIndex, Torrents CSV, Nyaa, YTS, SolidTorrents, TheRARBG, and Torrentio (when IMDb is available). Each result shows which provider found it.
- **Change:** Sources → Torrents shows **All** plus a chip for each enabled torrent provider (and Jackett / Prowlarr when configured), instead of a single Forja chip.

### Features
- **Change:** The download page picks the installer for your CPU (Apple Silicon vs Intel on Mac) instead of always offering Apple Silicon first.
- **Add:** Android TV download shows a Downloader code next to each APK so you can install Forja from the Downloader app without typing the URL.
- **Add:** Asian Drama details show cast, crew, trailers, and similar titles from TMDB when the KissKH title matches — plus genres, rating, and richer production facts.

### Player
- **Change:** Desktop picture-in-picture hover chrome matches system PiP — Expand, Minimize, Close, ±15s, play/pause, and a scrubber (VOD).
- **Fix:** Asian Drama (KissKH) streams that stuck BUFFERING on PNG-disguised HLS segments (`videotradercdn` `.png`) now open through the PNG-strip proxy, and prefer ≤1080p when the ladder includes 4K.
- **Change:** Trailers play as a native video stream (fit to screen) instead of a zoomed YouTube embed.
- **Change:** Trailer **More videos** card: center play (green on hover); only the ←/→ chevrons change trailer.

### Live & IPTV
- **Change:** On Android TV IPTV Live, double-OK on a category focuses its pin (OK toggles; Back/← returns), and holding OK ~2s lifts the row to reorder with ↑/↓.
- **Fix:** Opening IPTV with a saved portal shows a spinner while the catalog loads instead of briefly flashing Reload and a fake load error.
- **Fix:** Live IPTV only reconnects when the buffer is actually empty. If the stream still has cache or is downloading, the app leaves it alone instead of forcing "Reconnecting…" on a working channel.
- **Fix:** Android TV IPTV Exo chrome D-pad reaches the top-right **Player** menu again — ↑ from Search / Guide / Source lands on Player, → from Back claims it, and controls stay up for 10s while you navigate.
- **Fix:** Opening IPTV catalog search on Android TV shows the input and keeps only the active shelf tab (e.g. Live) — Movies/Series no longer cover the field.
