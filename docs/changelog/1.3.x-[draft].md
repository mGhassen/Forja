### Player
- **Add:** Settings → Playback → Auto picture-in-picture (macOS/Windows, off by default) — Space / virtual-desktop switch enters PiP while playing; manual PiP still works anytime.
- **Add:** Settings → Playback → Play in background (off by default) — keep movies, series, and IPTV playing when Forja leaves the foreground.
- **Change:** Desktop picture-in-picture is smaller and rounded, docks bottom-right on enter, free-drags with no corner snap, and shows play/pause on hover (macOS ignores Magnet/Rectangle during PiP).
- **Fix:** Desktop picture-in-picture no longer crashes when entering or leaving PiP (including Space-switch auto-PiP on IPTV).
- **Fix:** With Auto picture-in-picture on, switching Space while playing no longer pauses — PiP takes over without a playback hitch.
- **Fix:** Switching Space with Auto PiP off no longer leaves Forja floating on every Space (always-on-top leak).

### Sources
- **Fix:** Cloud sync no longer probes Stremio or Nuvio addon URLs in the background (including while using IPTV).
- **Fix:** Cancel on Details Play loading stays dismissed — it no longer flashes back with CANCEL when cache miss hands off to server search.

### Live & IPTV
- **Fix:** IPTV catalog no longer stays a black screen after desktop picture-in-picture (or a stuck PiP flag).
- **Fix:** Live Matches embeds on macOS no longer crash when entering or leaving fullscreen.
- **Fix:** Live IPTV no longer freezes on the first frame then jumps — the initial buffer fill is not treated as an underrun.
- **Fix:** Live IPTV buffer stalls rejoin the live edge quickly — no silent ~15s rewind and no multi-second frozen reconnect.
- **Fix:** Live IPTV no longer flips to software decode after a brief live-edge snap (UHD / VideoToolbox).
- **Fix:** On Android TV, live Exo/MediaKit no longer sits frozen ~30s then force-closes — the watchdog no longer treats live position=0 as “no first frame”.
- **Fix:** On Android TV, switching the IPTV player then pressing reload no longer force-closes the app.
- **Fix:** On Android TV, opening a live channel with MediaKit no longer force-closes the app.
- **Add:** Portals panel rows show a muted Xtream / M3U / Stalker badge before the server URL.
- **Fix:** Adding an M3U portal from a local file picker no longer fails with a fake login error.
- **Fix:** Multiple M3U playlists can be added — uniqueness is by playlist URL, and a portal name is required. Large playlists (e.g. iptv-org index) get a longer verify timeout.
- **Fix:** Opening a Stalker portal no longer flashes HTTP 502/520 on flaky gateways — transient errors retry silently before the catalog loads.
- **Fix:** On Android TV, holding ↑ through a long IPTV category list no longer makes group rows jump or misalign.
- **Fix:** Live channel health borders re-check after about two minutes instead of sticking for the whole session.
- **Fix:** On Android TV, Portals panel rows check status after two seconds of focus (so D-pad scrolling stays smooth).
- **Fix:** On Android TV, focusing a channel in the in-player guide checks its live status (green/red dot).
