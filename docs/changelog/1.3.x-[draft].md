### Features
- **Fix:** Android TV search history only saves when you press OK — not every letter while typing.

### UI
- **Change:** Server reliability lives under Settings → Sources (phone / desktop).
- **Fix:** Android TV Settings detail lists (Playback and others) use vertical D-pad prev/next and scroll so every row stays on screen.

### Player
- **Fix:** Android TV trailer player responds to D-pad on More videos (←/→ pick, OK play, ↑ Back) and remote Back / Exit like the main player.
- **Fix:** Android TV IPTV 4K on MediaKit restored to the pre-v1.3.81 path (display refresh sync, MediaCodec only — no mid-open UHD retune / software fallback that force-closed the app).
- **Change:** Play in background is on by default on desktop and off on phone/Android TV — leaving Forja on the TV pauses playback but keeps the app warm for a quick resume.

### Live & IPTV
- **Change:** Add-portal dice fills a random name for Xtream and Stalker too (not only M3U).
- **Change:** Android TV category reorder holds OK for 1s, keeps a sticky brighter-green lift (no floating card) until you drop, and uses → for the pin (OK opens channels; pin OK pins without scrolling).
- **Add:** Android TV shelf chips reveal Reload after holding OK for 1s — → focuses it, and moving to another shelf hides it.
- **Change:** On Android TV, holding ↑/↓ through Portals, categories, channels, and the in-player guide speeds up the further you hold.
- **Fix:** IPTV stream stats no longer show multi-hour “Buffered ahead” / Cache values from live PTS jumps — absurd demuxer readings are ignored so Stable recovery does not treat a dead feed as healthy.

### TV
- **Change:** On Android TV, holding ↑/↓ through Sources and Settings lists also accelerates scrolling.
- **Fix:** Opening a portal on Android TV focuses the first portal category — not Favorites or Already watched.
- **Change:** Android TV Settings hides Sources, WebStreamr, Lists, and Data & backup (lean hub: Profile, Playback, Connected services, Features, About).
