### Features
- **Change:** Desktop sign-in matches Android TV: logo welcome, then a code or QR to approve on the web (`/connect`), or Continue as guest. Email, passkey, and Web login are not on that screen. Click the QR to open the link page; it counts down 5s then links, and closes the tab 5s after success.
- **Add:** Anime and Asian Drama details have the same My List **+** as movies (Plan to Watch / Watching / On Hold / Completed / Dropped). Playing a new or planned title moves it to Watching. Simkl follows anime by AniList id, and dramas when TMDB matches.
- **Fix:** Simkl sync pulls completed movies, TV, and anime history (not only plan-to-watch), and in-progress titles into continue watching. List buckets also mirror onto local My List.
- **Add:** Connecting Simkl or tapping Sync Now asks how to sync lists: Keep local, Use Simkl, Merge, or No sync. Back / No sync does nothing.
- **Fix:** Trashing resume progress on details also clears that title from Simkl Completed.
- **Change:** On desktop, hover Home in the nav for ~1s to open the streaming-service panel (was ~500ms).
- **Add:** Anime details fill empty AniList fields from TMDB — title logo, synopsis, genres, rating, facts, and cast / crew / trailers / More Like This. Asian Drama details also show a TMDB title logo when matched.

### Player
- **Add:** Content warnings overlay at the start of a movie or episode (nudity, violence, and other IMDb parents-guide ratings). Turn it off in Settings → Playback or the in-player Settings menu.

### Live & IPTV
- **Change:** IPTV movie and series details use the same TMDB title logo as Home.
- **Change:** IPTV player channel guide sits flush against the left edge.
- **Change:** Live Matches embed chrome sits below the window traffic lights (same inset as the film player); after load the title bar drops and Back / Mute / source badge float over the video.
- **Fix:** IPTV player opens full-window like movies; shell underlay is masked during the slide so the catalog does not sit visible underneath.
- **Fix:** Opening an IPTV channel no longer flashes a setState-during-build error over the player.

### TV
- **Change:** On Android TV, holding ←/→ on the player progress bar speeds up (10s → 20s → 30s → 50s) and shows `>` / `>>` / `>>>` / `x>` above the thumb.
- **Change:** The update screen stays stacked (header top-center, notes, Install). What’s new has the version list on the left and uses more of the screen so notes don’t wrap as tightly. On Android TV the gap above Install is tighter. ↑ from Install, OK to enter: ↑↓ versions, → notes to scroll, OK to leave. No box around the notes.
- **Fix:** What’s new version list on Android TV keeps the focused version fully on screen when you move ↑↓.
- **Fix:** My List on Android TV starts on Films. D-pad moves Films / TV Shows / Anime → status tabs → posters.
- **Remove:** My List status pin on poster cards on Android TV (change status from details / hero instead).

### UI
- **Fix:** Hero My List pin sits in the center of its circle.
- **Fix:** Anime and Asian Drama hub heroes sit above the first catalog row when the title wraps to two lines, instead of crowding the top of the screen.
- **Fix:** The update screen headline “A new version is ready” stays on one line on desktop.
- **Fix:** Search result cards show FILM or TV next to the year, same as Home. Desktop / TV mix movies and shows by relevance instead of listing every film first.
- **Change:** Trakt and MDBlist in Settings → Connected services are admin-only. Everyone else sees Simkl.
- **Change:** My List is a poster grid (Films / TV Shows / Anime + status tabs). Posters match Home: colored status bookmark, score badge, `year • FILM` / `TV` / `ANIME`. Simkl-only rows on a status tab show that tab’s pin (not an empty bookmark).
- **Fix:** Opening a Trakt or MDBlist list from Settings no longer shows a transparent page — solid background and poster grid.
- **Remove:** Download button on the details hero (Sources still opens from the white Play / Resume).
- **Change:** Home / Anime / Asian Drama posters and details use the floating My List status menu; pin colors per status.
- **Change:** Anime catalog posters drop the top-left format chip. Bottom meta matches Home (`year • FILM` / `OVA` / …); series stay `year • N eps`.
- **Fix:** In-app updates only offer a newer build for your CPU (macOS Intel / Android TV 32-bit no longer see an arm64-only release as available).
