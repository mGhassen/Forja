# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.247 (`v1.3.247`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Player
- **Fix:** Trailers play with sound again (muxed stream when available; otherwise separate audio is attached after open).
- **Fix:** Subtitles menu header no longer shows a crushed “Subtitles” title — Off / File / Search stay on one row.
- **Fix:** VSEmbed in Sources no longer lists Videasy’s Yoru/Cypher/Breach streams.
- **Fix:** Picking a stream in Sources keeps the other mirrors for that server (list no longer collapses to one).
- **Fix:** Sources no longer shows another provider’s streams under the wrong server (e.g. Vidnest rows under VidSrc).
- **Fix:** Back from the player no longer flashes the stream-loading screen before details.
- **Change:** Leaving a movie/trailer player no longer hides and re-shows the nav rail — it stays mounted under the player like the screen you came from (IPTV overlay still hides the rail for full-width video).

### Live & IPTV
- **Fix:** On Android TV, changing IPTV source or channel remounts the player so video comes back without switching engines.
- **Fix:** On Android TV, pinning an IPTV category focuses that group and scrolls the category rail to it.
- **Fix:** On Android TV, ↑/↓ through IPTV categories keeps a single focus highlight (no ghost / double hover).
- **Fix:** Deleting a portal in the Portals panel dims it with stripes and clears it right away — cloud sync no longer blocks the UI.

### TV
- **Fix:** Android TV home-row banner fills the full rectangle (no gray bars around a square Forja icon) on launchers that ignored the old layered banner.
- **Fix:** On Android TV, the update screen takes remote focus on Install (or Continue while downloading) so D-pad no longer drives the page underneath.
- **Fix:** On Android TV player chrome, D-pad ←/→ on the progress bar move focus to Play / the right controls — scrub only after OK arms the thumb.
- **Fix:** On Android TV Sources (servers), checking a server keeps focus on that row instead of jumping to Close, and focused rows use a clearer green highlight.
