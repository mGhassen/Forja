# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.86 (`v1.3.86`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Sources
- **Fix:** Asian Drama signs KissKH stream keys in the engine and opens streams in about a second — no more waiting on a hidden browser page (desktop and Android TV).
- **Change:** WebStreamr, Nuvio, stream proxy, and torrent engines start after the splash finishes — not during the splash animation.

### Features
- **Fix:** macOS installer DMG keeps its drag-to-Applications layout (matrix background, large icons) instead of opening as a plain white Finder window.

### UI
- **Change:** Continue watching cards on Home, Anime, and Asian Drama show a neutral play button on card hover — it turns green and heartbeats only when you hover the play control.
- **Fix:** Desktop trackpad swipe-back uses a browser-style left-edge arrow that only goes previous when fully filled — Sources panel, Nuvio addon chips, and catalog rows no longer steal Back while you scroll them.
- **Fix:** Cold start shows the logo splash immediately — update check and cloud sync (including IPTV portals) no longer leave a black window first.
- **Fix:** When Profile & account cannot load (or is still loading) your cloud profile, **Sign out** stays available — no spinner-only dead end when the network is down.
- **Remove:** Home no longer shows Stremio addon catalog rails (Sources / Search / Live Matches still use Stremio).

### Player
- **Fix:** On Android TV, Home / movies / series ExoPlayer shows video again (was sound with a black picture) — VOD uses TextureView instead of SurfaceView.
- **Fix:** HLS servers like VixSrc no longer show a red failed Source row with a stuck `0:00` seek bar after video already starts — duration is allowed to arrive after playback confirms.
- **Fix:** On Android TV, switching ExoPlayer ↔ MediaKit from the **Player** menu (movies, series, anime, drama, IPTV, Live) no longer force-closes the app.

### Live & IPTV
- **Fix:** Live Matches embeds (including MutStreams) start with sound on — no more stuck **CLICK UNMUTE STREAM** overlay after open.
- **Fix:** On Android TV, Live Matches **Stremio** (Highfly) no longer loops on Reconnecting — Exo treats leaf CDN playlists as HLS and sends the catalog Referer.
- **Fix:** Live Matches **Stremio** schedules (Highfly and similar) sort by kickoff time — card grid and timeline follow the match clock instead of title order.
- **Add:** Live Matches **Stremio** server plays sport Stremio addons (e.g. Highfly) as HLS in the native player.
- **Add:** Settings → Sources lets you assign each Stremio addon to **Sources**, **Live Matches**, or both.

### TV
- **Fix:** On Android TV, D-pad browsing the shell and catalog no longer stutters from 200ms focus scale/color animations — focus chrome snaps instantly.
- **Fix:** Android TV **Link this TV** no longer spins forever on **Preparing a code…** when the network is down — it shows an error with Retry / Continue as guest.
