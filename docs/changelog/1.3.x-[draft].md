### Features
- **Add:** Search, Anime search, and Asian Drama search keep your last 5 queries above up to 16 varied recommendations (not the same short trending list); while searching, matching titles replace recommendations under recent.
- **Change:** Home, Anime, and Asian Drama heroes rotate random TMDB backdrops for the current title (no separate Images row on Asian Drama details).
- **Fix:** Asian Drama TMDB matching ignores KissKH year/HD tags so more titles get Characters and similar titles.
- **Add:** Asian Drama episode cards use TMDB stills when the title matches.
- **Remove:** Search is hidden from the nav and Settings → Features (Home search icon and Cmd/Ctrl+F still open it).

### Live & IPTV
- **Add:** Settings → Playback → **IPTV live recovery** — Stable (buffer-aware, default, same as 1.3.170) or Classic (stall timers, like 1.3.114). Applies the next time you open the player.
