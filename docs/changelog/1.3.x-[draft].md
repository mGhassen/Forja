# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.319 (`v1.3.319`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### UI
- **Fix:** My List drops a card immediately when you clear its status (tap Watching again, etc.) — it no longer sticks until Simkl refreshes.
- **Change:** Sources provider chips show the same animated … as the category tab while that indexer, scraper, or plugin is still checking.
- **Fix:** Home service filter matches the brand, not a single TMDB id — Max includes HBO / HBO Max (new series like Lanterns show up), and other chips include their same-service SKUs.
- **Fix:** Featured This Month on a streaming service is no longer a single poster — new-this-month titles stay first, then the row fills from popular on that service.

### Player
- **Change:** Player menus match Subtitles — idle rows stay uncolored, the selected row uses a green tint and a check, and hover/focus is a green tint instead of a solid green block.
- **Fix:** Player Sources panel has the same top and right inset as details — tabs and chips no longer sit flush against the edge.
- **Fix:** Player Sources count badge no longer clips at the top-right — the header meta now sits fully inside the panel.
- **Fix:** Switching stream or quality in the player (Videasy Source rows, Nuvio/Stremio Sources, torrent magnets, HLS Quality) no longer sticks on Checking or does nothing after a failed or mid-play stream.
- **Fix:** On Android TV, pausing then waking the set from sleep no longer leaves a green video frame — the picture stays black until you press play.
- **Fix:** Seeking forward/back (±10s or scrub) no longer freezes forever when a stream stalls — Forja reconnects that same stream at the seek point (including MediaKit freezes with no BUFFERING spinner). If that stream stays dead, Auto tries the next one.
- **Fix:** Pause no longer keeps rewriting Continue Watching or pinging Simkl/Trakt. Progress still saves while you watch, when you pause, and when you leave.
- **Fix:** On Android (MediaKit), movies wait for a short buffer before starting and pause to refill instead of stuttering when the stream underruns. The seek bar gray shows how far is cached ahead.
- **Fix:** Starting a new stream attempt now clears stale failure rows from the checking overlay, so buffering no longer shows the previous `Failed to stream` message.

### Live & IPTV
- **Add:** Live Matches **My IPTV** — today’s ESPN schedule matched to channels on your Xtream portal (Settings → Data & backup → My IPTV sports). No self-hosted addon required.
- **Change:** IPTV portal share codes are 8 characters (`XXXX-XXXX`) again. Copy shows the code on the row; paste it in Add portal. Codes expire after 7 days.
- **Fix:** IPTV catalog scrape picks up Spanish panel tables, host-then-user/pass dump sheets, Atlas MAC-checker lines, and Hit Hunter / panel-MAC notes that used to stop after the first card.
- **Fix:** On Android TV, changing channel in the IPTV player guide shows “Switching to …” with the channel name (not the portal name).
- **Fix:** On Android TV, D-pad Down on the last IPTV channel row stays there — it no longer jumps back to the category list.
- **Fix:** On Android TV, D-pad ↑/↓ in the Portals list only highlights the focused row (green fill) — it no longer flashes desktop hover (star / white fill) on rows you scroll past.

### Sources
- **Fix:** Leaving title details or cancelling while Nuvio or Forja Sources is still checking no longer crashes on macOS (JavaScriptCore use-after-dispose during cancel).
- **Fix:** 4KHDHub HubCloud rows no longer hand the player a `/drive/` admin page — only FSL, PixelServer, R2, and workers.dev links are returned.
- **Fix:** Forja anime plugins (AnimePahe, HiAnime, Anikoto, …) resolve MAL and AniList ids once on the host from your TMDB title — Home search anime no longer returns empty while KickAssAnime works.
- **Add:** MKissa in Sources **Forja** — MAL/AniList lookup, `mkissa.to` watch warm-up, and `api.mkissa.net` client-crypto GraphQL (`aaReq`) for sub/dub episode sources (embed hops when needed).
- **Add:** CineJoy in Sources **Forja** — TMDB title lookup, `api.shegu.st` scrypt challenge, and enc-dec decrypt on `cinejoy.to` (replaces dead `cinejoy.is` generic scrape).
- **Add:** AnimeHeaven, AniDao, AniWaves, and Miruro in Sources **Forja**.
- **Fix:** Forja KissKh uses kisskh.co and tries the episode API without kkey first. AnimePahe hits animepahe.pw / kwik.si (proxy still fallback). Senshi, Anikoto, HiAnime, and ReAnime pick up current upstream scrape/referer logic.
- **Add:** Sources **Forja** tab — bundled HTTP plugins (Videasy, Cineby, Goated, VidLink, VixSrc, DooFlix, YFlix, VidNest, VidNest Anime, VidRock AES, VidFast EncDec, VidSrc.sbs, Cinesrc, Hexa, VidCore, MeowTV, Peachify, VidSync, VidUp, MovieBox, MovieBlast, StreamFlix, AnimeX, AniZone, NetMirror, Castle, XPrime, DVDPlay, 4KHDHub, HDHub4u, MoviesMod, UHDMovies, AllMovieLand, MoviesDrive, CinemaCity, DahmerMovies, Kurage, ShowBox, CineVibe, MalluMV, AnimePahe, ReAnime, AniBD, Senshi, AnimeHeaven, AniDao, AniWaves, Miruro, AnimeDunya, AniNeko, AnimeGG, AniDbApp, Anikoto, AnimeNoSub, MKissa, CineJoy, BingeBox, PrimeSrc, UFlix, MyFlixer, MoviesAPI, HiAnime, KickAssAnime, 2DHive, MultiEmbed, template embeds, WebStreamr, remaining EncDec catalogs, KissKh) plus paste-an-`engine.json` packs in Settings. Doodstream / VOE / Filemoon / MixDrop / FlixCloud / Hydrax-style file hosts resolve as internal hops, not chips. MyCima stays off. Separate from green Play and from Nuvio.
- **Change:** DooFlix and YFlix are on in the Forja pack.
- **Fix:** Forja Videasy rows play with the player.videasy.to Referer — they no longer fail open on peakstorm CDNs.
- **Fix:** Forja Vidlink MovieBox rows request HEVC DASH (same `X-Playback-Environment` as vidlink.pro) and play with CloudFront cookies — the old progressive mooncase MP4s were already expired from the API.
- **Fix:** Forja Vixsrc resolves via the site JSON API and embed page — the old HTML scrape only saw the Next.js loading shell.
- **Change:** Forja Vixsrc lists 1080p / 720p / 480p rows from the master playlist and attaches English Wyzie subtitles when available.
- **Add:** STREAMCRYPTO decrypt (Videasy and VidSrc.sbs 4K) can use native Dart instead of a headless WebView — admin Playback setting, WebView stays the default.
- **Change:** Forja packs and plugins load only when you open the **Forja** tab (not on details page load).
- **Change:** Forja source rows use the show title/episode and list real qualities (720p / 1080p) from playlists — same card as Nuvio, without fake AAC / Original Audio.
- **Change:** Forja HTTP plugins read API hosts and mirror lists from each plugin's pack config — remote provider JSON can overlay `engine.<pluginId>` without reinstalling the pack.
- **Change:** Forja **All** and any set of selected plugins run up to 10 at once (5 on TV), show rows as they land, and start the next as slots free. Tapping another plugin chip adds it to the in-flight search instead of stopping the others.
- **Change:** Nuvio **All** and selected scrapers keep up to 10 in flight (5 on TV). Tapping another scraper chip adds it to the search instead of cancelling.
- **Fix:** On Android TV, Sources keeps a top inset so kind tabs are not flush to the panel edge.
- **Fix:** Forja VidRock lists servers from vidrock.ru again — the old encrypted-id API was dead, so it fell into a sniff that timed out with no rows.
- **Fix:** Forja VidFast lists the HLS playlist it already sniffed — it no longer dumps empty after 30s while the player was still pulling segments.
- **Fix:** Forja Vidzee uses `core.vidzee.wtf/streams` with plaintext `e=0` (old `/api/server` is a dead SPA shell).
- **Fix:** Forja 2Embed and 111477 run real HTTP scrapers (`multiembed.js` / `dahmermovies.js`) instead of empty embed/host wrappers.
- **Fix:** Forja VidSrc.sbs parses `CFG.servers` with balanced brackets (no false cut on `[Multi-Lang]`) and resolves Pro Multi via the nxsha AES API when the embed list is empty.
- **Change:** Sources → Forja can now run JS/API-only without host sniff fallback, so it is easier to see which Forja plugins really work on their own.
- **Change:** Sources category **reload** (tab … icon or hold **OK** on TV) keeps the rows already listed and re-checks providers in the background — new or updated sources append; existing ones refresh when their fetch finishes.
- **Fix:** Forja/Nuvio **All** no longer shows stale session-cache rows from other plugins while the first batch is still loading — a full All walk starts clean and rows appear only as the current search finishes each provider.
- **Fix:** Tapping a Forja or Nuvio provider chip for the first time now starts the search immediately — stale fetched markers from cache or a prior All run no longer skip it.
- **Fix:** Tab reload and multi-chip Forja/Nuvio selection now show every selected provider as loading while its fetch is pending, and reload re-runs the full parallel pool (up to 10) for all selected chips — not just the one in flight.
- **Fix:** Forja HDHub4u and 4KHDHub now match Nuvio/WebStreamr — IMDB Typesense lookup, live MBG domains, hubdrive/gadgetsweb extraction, and updated 4KHDHub search layout.
