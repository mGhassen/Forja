# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.289 (`v1.3.289`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Player
- **Fix:** Local torrent keeps disk use under a size you set in Settings (default 2 GB on desktop, 1 GB on phone and TV). The title playing now is never deleted; oldest idle downloads are removed, and closing or switching a torrent deletes that download.
- **Fix:** On Android TV (and phone) ExoPlayer, torrent / Stremio / Nuvio playback shows the link **Sources** button on the player bar — same panel as MediaKit.
- **Fix:** Android TV no longer force-closes when you switch MediaKit → ExoPlayer from the Player menu.

### UI
- **Change:** Home, Anime, and Asian Drama heroes drop the green Play button. The info action now reads **View details**.
- **Fix:** Anime, Asian Drama, and IPTV details keep the current page and layer TMDB in over time (backdrop, then logo/meta, then extra rows) instead of swapping the whole screen.
- **Change:** Sources addon chips highlight green on hover (D-pad focus on Android TV) even when selected or All is on. Not a solid fill.
- **Change:** Sources result rows use the shell hover fill (same as selected chips), not green.
- **Change:** Sources drops the title and close X. The result count sits on the right of the Torrents / Stremio / Nuvio tab line.
- **Fix:** Clicking the active My List status (Watching, Completed, …) removes the title instead of leaving it stuck.
- **Fix:** Intel Macs no longer glitch player subtitles, chrome, catalog cards, or text.
- **Change:** The profile LAN mark is a server dot (green/red). On desktop a bold vertical bar after the dot shows waiting, paired, idle, or playing. Android TV and other clients are the dot only.

### TV
- **Change:** Android TV torrent pair dialog puts **Open LAN** first; **Cancel** is text under it. **Open LAN** goes to Settings → LAN (category rail + pane).
- **Change:** Android TV remote power now quits Forja. Turning the TV back on opens the launcher, not a leftover session.
- **Change:** In the player, remote Back hides the controls if they are showing; Back again leaves. The Back icon still leaves immediately.
- **Fix:** After leaving the player or canceling stream loading on Android TV, D-pad focus returns to Play.
- **Fix:** On Android TV, remote Back closes the player torrent Sources panel (Filters first if open) and the pair-desktop dialog — it does not leave playback.
- **Fix:** Opening Sources on Android TV after leaving the player keeps D-pad in the panel.
- **Fix:** On Android TV, closing Sources on details with Back returns D-pad to Play.
- **Add:** On Android TV, hold **OK** for 1 second on the selected Torrents / Stremio / Nuvio tab to reload that category.

### Live & IPTV
- **Change:** IPTV portal share is a local `F1.` token only. Copy puts it on the clipboard; paste the full token in Add portal. Old 8-character codes no longer work.
- **Fix:** Live channel cards show the current programme when the long-press guide has EPG, including overnight slots.

### Sources
- **Add:** Sources tabs show an animated **…** while that category is still loading; hover it for **X** to cancel.
- **Fix:** Sources keeps your scroll position and hover when more rows arrive; it does not jump back to the top.
- **Change:** Sources loads only the selected Torrents indexer or Stremio addon. Nuvio **All** loads selected scrapers in groups of 5. Tap a chip to load that one — the previous search **stops**, and tapping it again continues. Torrents **All** searches every enabled indexer; tap **All** again to clear.
- **Fix:** Tapping Nuvio **All** when it is already selected clears every scraper and stops the load — same as Torrents.
- **Change:** Torrents **All** highlights every enabled indexer chip, same as Nuvio All.
- **Add:** First time you turn on Direct torrent, Stremio, or Nuvio, Forja asks you to confirm you are aware of P2P terms and recommends a VPN. Playback then shows a clickable “You are aware of P2P streaming” notice above Play sources, with a check.
- **Change:** Android TV lists Direct torrent, Stremio, and Nuvio without pairing. Direct HTTP plays on the TV; magnets ask you to pair a desktop (or show that the desktop is offline). Paired P2P still runs on the desktop, not the TV.
- **Fix:** On Android TV, picking another torrent (or Stremio magnet) in the player asks you to pair a desktop if you have not — it does not start loading on the TV. Already paired and online plays as before.
- **Change:** Opening Nuvio with **All** selected loads those scrapers in groups of 5 until every selected one has been tried. Tap a scraper chip to load just that one.
- **Fix:** Nuvio All no longer stops after the first scraper. Later scrapers (Cineby and the rest) load without tapping each badge.
- **Add:** Settings → Sources → Nuvio **Select All by default**. On (the default) opens Nuvio with every enabled scraper selected. Off starts with none — pick chips in the panel.
- **Fix:** Nuvio hides HubCloud / 4kHdHub links when Google Drive has already exhausted that file’s download quota.
- **Fix:** Nuvio scrapers that decrypt AES payloads (Castle and similar) now return streams.
