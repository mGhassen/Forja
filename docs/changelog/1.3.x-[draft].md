# 1.3.x — Elblat

**Status:** draft  
**Since release:** 1.3.319 (`v1.3.319`)

User-facing changes for the next **1.3.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.3.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### UI
- **Fix:** My List drops a card immediately when you clear its status (tap Watching again, etc.) — it no longer sticks until Simkl refreshes.
- **Change:** Sources provider chips show the same animated … as the category tab while that indexer, scraper, or plugin is still checking.
- **Fix:** Home service filter matches the brand, not a single TMDB id — Max includes HBO / HBO Max (new series like Lanterns show up), and other chips include their same-service SKUs.
- **Fix:** Featured This Month on a streaming service is no longer a single poster — new-this-month titles stay first, then the row fills from popular on that service.

### Player
- **Fix:** Space (and TV play/pause) toggles playback without popping the control chrome — paused hero still shows. Works in the movie player and Live Matches / IPTV (desktop Space was a no-op / beep there).
- **Add:** With Webstreaming off, check **Auto** on the Forja play-source row — green Play races enabled Forja plugins, probes each stream, and opens the first that works (Sources still works for manual pick).
- **Fix:** Leaving the player while content warnings are animating in no longer crashes (ticker disposed with the overlay).
- **Change:** Player menus match Subtitles — idle rows stay uncolored, the selected row uses a green tint and a check, and hover/focus is a green tint instead of a solid green block.
- **Fix:** Player Sources panel has the same top and right inset as details — tabs and chips no longer sit flush against the edge.
- **Fix:** Player Sources count badge no longer clips at the top-right — the header meta now sits fully inside the panel.
- **Fix:** Switching stream or quality in the player (Videasy Source rows, Nuvio/Stremio Sources, torrent magnets, HLS Quality) no longer sticks on Checking or does nothing after a failed or mid-play stream.
- **Fix:** On Android TV, pausing then waking the set from sleep no longer leaves a green video frame — the picture stays black until you press play.
- **Fix:** Seeking forward/back (±10s or scrub) no longer freezes forever when a stream stalls — Forja reconnects that same stream at the seek point (including MediaKit freezes with no BUFFERING spinner). If that stream stays dead, Auto tries the next one.
- **Fix:** Pause no longer keeps rewriting Continue Watching or pinging Simkl/Trakt. Progress still saves while you watch, when you pause, and when you leave.
- **Fix:** On Android (MediaKit), movies wait for a short buffer before starting and pause to refill instead of stuttering when the stream underruns. The seek bar gray shows how far is cached ahead.
- **Fix:** Starting a new stream attempt now clears stale failure rows from the checking overlay, so buffering no longer shows the previous `Failed to stream` message.

### Live & IPTV
- **Change:** Live Matches remembers the Servers selection across app restarts.
- **Change:** My IPTV keeps matched channels for a match for 30 minutes — re-opening the same card skips a second portal search.
- **Remove:** CDN Live from Live Matches Servers (and from All) — schedule/streams no longer come from cdn-live.tv.
- **Change:** My IPTV Source picker is wider; rows show portal channel logos, channel callsign as the title, category under it, and T1–T4 on the right — not a cramped Xtream dump.
- **Fix:** My IPTV player header shows the match + kickoff time first; the IPTV channel stays on the subtitle (and updates when you switch Source). Skips dead sources on TCP/open failure instead of buffering the same URL for many retries.
- **Fix:** My IPTV parses `Team A at Team B` / `@` titles (NFL-style) so those cards can match channels — not only `vs`.
- **Change:** My IPTV opens a channel picker sheet (matched IPTV channels) before the player — same idea as Streamed.
- **Change:** My IPTV merges today’s ESPN scoreboard with the All catalog — shared games use ESPN team names for matching; ESPN-only games still show as cards.
- **Add:** Live Matches **My IPTV** — All catalog ∪ ESPN; open a match to play ranked channels from your Xtream portal. No self-hosted addon required.
- **Remove:** IPTV folder picker from Settings → My IPTV sports — matching always uses all live channels on the portal.
- **Add:** On Live Matches → My IPTV, the IPTV **Portals** control (top-right) opens the real portal panel — same as IPTV.
- **Change:** My IPTV defaults to the portal currently selected in IPTV until you override it.
- **Remove:** Xtream portal picker from Settings → My IPTV sports — portal is only chosen in Live Matches / IPTV Portals.
- **Change:** IPTV portal share codes are 8 characters (`XXXX-XXXX`) again. Copy shows the code on the row; paste it in Add portal. Codes expire after 7 days.
- **Fix:** IPTV catalog scrape picks up Spanish panel tables, host-then-user/pass dump sheets, Atlas MAC-checker lines, and Hit Hunter / panel-MAC notes that used to stop after the first card.
- **Fix:** On Android TV, changing channel in the IPTV player guide shows “Switching to …” with the channel name (not the portal name).
- **Fix:** On Android TV, D-pad Down on the last IPTV channel row stays there — it no longer jumps back to the category list.
- **Fix:** On Android TV, D-pad ↑/↓ in the Portals list only highlights the focused row (green fill) — it no longer flashes desktop hover (star / white fill) on rows you scroll past.

- **Fix:** Forja MeowTV uses working DCloud / IPcloud servers and opens `1shows` streams with the `meowtv.ru` Referer (no CDN self-Referer).
- **Fix:** Deselecting all Forja/Nuvio chips stops the tab spinner — reselecting a chip starts a fresh search instead of joining a dead in-flight job.
- **Fix:** Opening Sources in the player reuses Forja/Nuvio results already loaded on details (All chip included) — it no longer wipes the list and restarts the search.
- **Fix:** Forja YFlix uses `solarmovie.fi` (and EncDec mirrors) — dead `1moviesz.to` / `yflix.to` hosts returned no rows.
- **Fix:** Leaving title details or cancelling while Nuvio or Forja Sources is still checking no longer crashes on macOS (JavaScriptCore use-after-dispose during cancel).

- **Fix:** Forja anime plugins (AnimePahe, HiAnime, Anikoto, …) resolve MAL and AniList ids once on the host from your TMDB title — Home search anime no longer returns empty while KickAssAnime works.

- **Add:** AnimeHeaven, AniDao, AniWaves, and Miruro in Sources **Forja**.

Doodstream / VOE / Filemoon / MixDrop / FlixCloud / Hydrax-style file hosts resolve as internal hops, not chips. MyCima stays off. Separate from green Play and from Nuvio.
