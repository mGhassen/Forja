### Player
- **Fix:** Remote Back closes open player menus and panels before leaving the player (including IPTV and Settings drill-ins).
- **Change:** On Android TV, press Back twice to leave a player (movie, anime, Asian Drama, IPTV). The first Back shows controls; the second exits.
- **Change:** On Android TV, when player controls are hidden, D-pad **↑** focuses Back and **↓** focuses Play (hardware volume keys still control volume).

### UI
- **Change:** Download page shows platform icons in the list and detail pane; Windows and Mac each get their own “Stuck opening?” card next to that platform’s download.
- **Change:** Download buttons name the CPU architecture when the build has one (e.g. macOS Apple Silicon), even if only one file is available.

### TV
- **Change:** Android TV home banner shows the Forja wordmark instead of the F monogram.
- **Change:** Android TV no longer shows Direct torrent, Stremio, or Nuvio — even for admin accounts (Webstreaming only).
- **Change:** Android TV players no longer show a fullscreen button (IPTV and Live Matches).
- **Fix:** Android TV trailer player (and details hero trailer) no longer opens as a white screen — YouTube embeds keep hardware acceleration.
- **Fix:** Switching movies to MediaKit on Android TV shows video again (was sound with a black picture).
- **Fix:** Details page titles on Android TV no longer look doubled or soft — plain white text instead of the chromatic offset layers.

### Live & IPTV
- **Fix:** Android IPTV Player menu can switch ExoPlayer ↔ MediaKit (remembered in Settings); on TV, MediaKit shows video again.
- **Change:** Android TV live IPTV drops the soft 720p/bitrate cap so channels look sharper; keeps a live buffer a few seconds behind the edge.
- **Remove:** IPTV player no longer shows a volume button (use hardware / system volume).
