### Features
- **Fix:** Website PostHog analytics uses the official TanStack Start provider and picks up Vercel `POSTHOG_API_KEY` / `VITE_POSTHOG_KEY` at build time (redeploy required).

### Live & IPTV
- **Change:** On Android TV, scrolling IPTV categories no longer loads channel logos — press OK (or Right) on a group to open its channels.
- **Fix:** Live Matches on Android / Android TV opens Streamed (and other WebView embeds) in the native IPTV player after sniffing the HLS URL — System WebView cannot play `embed.st` in-page (CORS + host lock “Remove sandbox attributes…”).

### UI
- **Change:** Switching profiles no longer waits for home-feed and engine warm to finish — the avatar splash dismisses like the intro splash, and IPTV portals only sync when that profile has IPTV.
- **Fix:** Account settings on the web (Playback, Features, Stremio, Nuvio) keep your edits instead of snapping toggles and fields back before you can save.
- **Fix:** Asian Drama hub and explore cards use wide 16:9 frames so KissKH landscape covers are no longer zoomed and cropped in portrait posters.
- **Change:** App launcher icons (Android / Android TV, iOS, macOS, Windows, Linux) show the green Forja wordmark instead of the F monogram.

### TV
- **Change:** Android TV Apps row and home banner both use the green Forja wordmark (square icon and wide banner).
- **Fix:** Android TV Settings no longer shows Sources, Debrid, or Direct torrent / Stremio / Nuvio (including when those prefs are on from another device).
- **Fix:** On details, focusing a trailer draws the white ring on the thumbnail only — not a box around the title.
- **Add:** Trailer player on Android TV shows the top-right **Player** control (open in YouTube), matching the movie player.
- **Change:** Android TV trailer chrome auto-hides after idle (and on remote Back); volume and center play/skip controls are removed — use the bottom row and hardware volume.
