# 1.2.357 — Dabaghin

**Status:** released  
**Version:** 1.2.357 (`v1.2.357` — Dabaghin)

---

### Player
- **Fix:** Sources Stremio tab reloads installed stream addons so plugin chips are not empty after install, and the Filters control stays available while results load.
- **Change:** Hovering the Sources category reload icon spins the refresh glyph; plugin chips no longer scale/clip into the chrome gaps.
- **Fix:** Anime no longer re-extracts the same pinned server after a dead stream — Auto walks other providers instead.

### Sources
- **Add:** Hover a torrent row in Sources to copy its magnet link.
- **Fix:** Anime episode lists no longer collapse long series (e.g. Naruto) into a single movie/OVA stub titled “Full”.
- **Fix:** Anime HLS reachability rejects playlists whose media segments are PNG ads (nekostream / vivibebe / ibyteimg), so Sources don’t go green then fail on open.

### UI
- **Fix:** On desktop, mouse wheel over catalog rows no longer eats scroll-up — page up/down works at row edges, and the wheel still pans the row left/right when it can move.

### Live & IPTV
- **Fix:** Deal portals from the catalog pool show up again after spending a credit (portal credentials failed to load).
- **Fix:** A failed Deal pull no longer wipes your local portal list and leaves an empty IPTV screen.
- **Change:** Deal runs immediately like Scrape (no region dialog) — spends 1 credit for up to 5 pool portals.
- **Change:** Deal is a real lottery — less-dealt and recently checked portals win more often, and packs prefer different hosts.

### Features
- **Add:** Admin Scrape → Automation lets you change the catalog schedule (presets, UTC time, or cron) instead of a fixed 06:00 daily run.
- **Change:** Admin scrape Start/Stop updates the run list immediately (live refresh while a job is running).
- **Change:** Admin console layout — clearer nav, live scrape status chips, and tighter pages across Dashboard, Pool, Scrape, Accounts, and Providers.
- **Change:** Admin → Accounts — credits −/+ and Find Portals switch live in the row (no separate Actions column).
- **Add:** Admin can view each account’s IPTV portals and assign/unassign from Accounts or Pool (optional credit burn).
- **Change:** Admin → Pool lists every portal (not only scrape inventory), with an Inventory filter (All / Deal pool / Not in pool); scrape start/stop lives on Scrape only.
- **Change:** Admin → Providers is a sectioned editor (templates, APIs, WebStreamr, anime, CDN rules) with JSON as an advanced fallback.
- **Add:** Admin shows pool/scrape stats on every page (alive/dead/credits/runs) plus full funnel columns (deep refs, L2 ok/fail, duration) on Dashboard and Scrape.
- **Add:** Settings → Playback → **Nuvio** play source (same pattern as Stremio). Off hides Nuvio addons settings and the Sources Nuvio tab.
- **Add:** Web portal Profile settings — Nuvio play source toggle, Simple resolve, and Nuvio addons page (syncs with the app).
- **Add:** Web Account → Connections — see every signed-in browser and Forja app session (where, since, last active) and revoke one or all.
- **Change:** Simple resolve (experimental) is on by default, and the toggle is admin-only in app and web settings.
- **Fix:** Desktop Web login no longer shows the email/password form when you are already signed in on the portal — it connects straight back to Forja.
