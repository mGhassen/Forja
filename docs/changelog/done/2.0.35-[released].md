# 2.0.35 — Serrajin

**Status:** released  
**Version:** 2.0.35 (`v2.0.35` — Serrajin)

---

### Player

- **Add:** Auto next episode toggle in the player settings gear menu under Auto selection.
- **Change:** With auto next episode on, the Next Episode button appears on its own near the end with a 10-second countdown, then plays the next episode. Hovering or moving focus onto the button pauses the countdown. The X inside the button stops it. On TV the button takes D-pad focus and → reaches the X.
- **Fix:** Auto next episode, auto skip intro, and content warnings changed in the player now show the same value in Settings and sync to your account.
- **Fix:** Continue Watching now tries the saved provider first instead of re-checking all providers from scratch.
- **Fix:** Clicking the remove or info button on a Continue Watching card no longer also plays the item.
