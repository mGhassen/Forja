# 1.2.281 — Dabaghin

**Status:** released  
**Version:** 1.2.281 (`v1.2.281` — Dabaghin)

---

### Live & IPTV
- **Fix:** Streamed Live Matches include the site’s live feed (not only the schedule), so Popular Live events like ACA are no longer missing, and long popular events stay playable.
- **Fix:** PPV Live Matches surface **Live now** events (Open, Tour de France, ATP, …) first by viewer count, keep them playable while viewers remain, and show the live audience on each card.
- **Change:** Find Portals / Scrape is off by default and only appears when your Forja account has the IPTV scrape feature enabled.

### Features
- **Remove:** Shell announcement banner (cloud announcements are no longer used).
- **Change:** Update checks use GitHub Releases only.
- **Change:** Desktop profile switching uses a Netflix-style Who’s watching page (choose / manage / add / edit), then a dedicated splash while that profile’s settings load — not a settings dropdown.
- **Fix:** After switching profiles, the app opens that profile’s starred default tab instead of returning to the screen you left.
- **Fix:** Signing out of a Forja account on desktop returns to the sign-in screen instead of leaving the app open as if you were still signed in.
- **Add:** Web account signup at `/signup` with Cloudflare Turnstile captcha, plus captcha on `/login` when configured.
- **Change:** Web settings separate Profile (synced IPTV / playback / navigation / Stremio) from Account (email, log out, delete), and Back returns to Who's watching.
- **Remove:** Provider order from web remote settings — try-order stays on-device in the app only.
- **Add:** Web **Profile → Navigation** edits synced shell tabs and the default menu (same fields as Settings → Navigation in the app).
- **Change:** Log out sits under Account in the settings left nav (red), not as a header control.
- **Change:** Settings profile switcher is larger, with a clear avatar and name.
- **Change:** Web IPTV settings use a compact portal list (no cards, no M3U section, no CSV import).
- **Add:** Desktop **Web login** opens the portal in your browser and signs the app in when you finish there.
- **Fix:** Desktop Web login stays on one browser tab after sign-in (no second localhost page).
- **Add:** Desktop email sign-in shows Cloudflare Turnstile when Auth captcha is configured (same as the web portal).
- **Fix:** Local Web login reaches the portal on `127.0.0.1:3000` (dev server was IPv6-only and looked down from the app).
- **Remove:** In-app account creation — create a Forja account on the web instead.
- **Change:** Cloud sync stores a smaller settings blob — no M3U channel lists, My List, or provider order; default provider orders are not uploaded. Playback prefs (torrent / Stremio / web) and navigation sync in full. IPTV portals use a separate assignment table with your portal name per profile.
- **Change:** New accounts no longer get an automatic Profile 1 — you create your first profile (name + avatar), and default settings attach to that profile.

### Sources
- **Fix:** Anime Miruro servers unlock Cloudflare via the in-app browser pipe again (prefers miruro.tv, falls back across mirrors) instead of failing with send errors while the website still works in a normal browser.

### Player
- **Change:** Source panel uses embed sniff by default; the Embed checkbox is hidden.
- **Fix:** Scrubbing or seeking backward from the end no longer snaps the progress bar back to finished (including after a dead-server early EOF).

### UI
- **Fix:** Settings → Providers no longer crashes when a Stremio addon has no icon (common for addons synced from the web).
- **Fix:** Web login and signup captcha shows its full border (left edge was clipped).
- **Fix:** Desktop sign-in captcha no longer shows a wide black bar behind the Cloudflare check.
- **Change:** Desktop sign-in screen is a full-bleed cinematic layout with email sign-in, Web login, and guest continue (no signup).
- **Fix:** Web login and signup are edge-to-edge — full-width header and story panel, no floating inset frame.
- **Fix:** Who’s watching back control sits under the window traffic lights instead of beside them.
- **Fix:** Desktop Web login no longer locks the sign-in screen — Cancel web login or Continue without an account if the browser does not open.
- **Change:** Shell navigation menu icons are larger.
- **Change:** Settings → Profile & account shows a Watching now stage and clear sync / sign-out sections instead of a sparse button row.
- **Remove:** Household profile strip and Who’s watching / Manage profiles rows from Settings → Profile & account (switch or manage via Watching now or the rail avatar).
