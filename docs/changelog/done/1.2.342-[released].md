**Status:** released

### UI
- **Fix:** The update dialog shows What’s new for each version since yours (from the release CDN), not an empty “No release notes” screen.

### Features
- **Change:** Desktop Web login gives the app its own session — the browser portal stays signed in.

### Live & IPTV
- **Add:** Admin Scrape can turn the daily catalog cron on or off.
- **Change:** Catalog pool lives on the same IPTV portals table (`catalog_pool`) — no separate candidates table.
- **Add:** Live catalog categories can be drag-reordered (per portal; Playlist Order).
- **Fix:** Channel search lists only categories that contain matching channels; clearing search keeps a category you picked or played from, otherwise restores the one you had before.
- **Add:** IPTV player remembers volume on this device.
- **Change:** Adding a portal shows only a loading state — form fields hide until it finishes.
