# 1.2.298 — Dabaghin

**Status:** released  
**Version:** 1.2.298 (`v1.2.298` — Dabaghin)

---

### Player
- **Fix:** Player no longer stacks “Finding servers…” on top of the stream-failed message.

### Features
- **Add:** Sign in with a passkey on the web portal and on Forja for macOS and Windows; manage passkeys under Account settings.
- **Add:** Forgot password on the web — email a reset link, stay on “we sent you an email”, open the link to set a new password, then sign in.
- **Change:** The update dialog lists changelogs for every release since your installed version, not only the latest.
- **Change:** App and website downloads install Forja from Forja’s own storage instead of GitHub.

### UI
- **Fix:** Sign-in, sign-up, and password-reset pages use the same floating glass navbar as the rest of the site.
- **Change:** Soft Liquid Glass on the site navbar and auth cards; each marketing page has its own ambient light recipe (footer no longer has a separate glow).
- **Change:** Landing TV mock uses cinematic landscape open-film stills (and horizontal Featured cards) instead of title/credits frames.
- **Fix:** macOS release DMG opens again (App Sandbox off; free ad-hoc codesign, no paid Apple signing).
