# 1.3.33 — Elblat

**Status:** released  
**Version:** 1.3.33 (`v1.3.33` — Elblat)

---

### Features
- **Add:** Website product analytics via PostHog when the portal is configured (anonymous pageviews + masked session replay; no account email).

### Player
- **Change:** On Android TV, remote **Back** focuses the player **Back** control first (shows chrome if needed); press **Back** again to leave. IPTV and movie / anime / Asian Drama share this.

### UI
- **Fix:** Leaving a title’s details while Sources is still fetching no longer crashes.

### TV
- **Fix:** Anime details on Android TV focuses **Play** / **Resume** when the page opens (and after **←** to the nav rail then **→**), including while episodes are still loading.
- **Fix:** Android TV Settings → Features — **OK** / **→** from the category rail reaches the tab list (async load no longer leaves D-pad stuck).

### Live & IPTV
- **Fix:** Live Matches embeds on Android TV no longer die on “Remove sandbox attributes on the iframe tag” — nested player frames are unblocked in addition to top-level load.
- **Fix:** Switching the IPTV built-in player on Android TV no longer crashes the app.
- **Change:** IPTV player channel guide on Android TV is a full-height left rail (flush top-to-bottom); desktop keeps a smaller floating overlay. Opening it focuses and scrolls to the playing category and channel.
- **Fix:** IPTV player channel guide and search highlight hover / D-pad focus in brand green (was gray).
