# 2.0.204 — Serrajin

**Status:** released  
**Version:** 2.0.204 (`v2.0.204` — Serrajin)

---

### Accounts

- **Add:** My List Open with… splits Match (white Simkl logo) and Open with (link icon) as side-by-side icons — Match links a TMDB title for Simkl without changing the open hub; cards show the logo when linked or with a red cross when not.
- **Add:** Settings → Simkl — **How should lists sync?** dropdown (Keep local / Use Simkl / Merge / No sync) is saved; **Sync Now** runs it with no dialog; **Auto sync lists on My List** uses the same saved mode when you open My List.
- **Fix:** Android TV / desktop Sign in QR and connect URL always use the public portal (`www.forjahq.xyz`) in release builds — never the staging host.

### Player

- **Fix:** Skip intro, recap and credits keep working as the timestamp service retires its old API.
- **Fix:** Switching Sources mid-play loads that source’s own subtitles (e.g. Asian Drama KissKh) instead of leaving only scraped Wyzie / Levrx rows from the first race winner.

### UI

- **Change:** My List **Open with…** closes with an X instead of Cancel.
- **Fix:** After you pick a profile, Home warms under the avatar splash before the shell opens — no freeze on first TV/desktop launch while rails load.
- **Fix:** Continue Watching keeps a show on the rail when you start the next episode — no waiting for 2% once that series is already started.

### Sources

- **Fix:** Provider caption tracks show in the player subtitle menu for VidLink, RiveStream, PeeStream, Frame, Hexa, AnimeKai, HiAnime, and Anikoto (when the source returns them).
- **Fix:** Aflem / Brstej catalog and streams work again — entry via brstej.com (follows redirect to the live host), hex show ids, and `video.php` episode pages.
- **Fix:** Aflem details show the real plot, genres, year/runtime, and episode synopsis from the Brstej page (not only the short SEO blurb).
- **Add:** Aflem series details pull cast photos/names and facts (country, premiere, original title) when Brstej publishes them.

### Live & IPTV

- **Fix:** PPV Live Sports unlocks again (new player host) and lists each language / broadcast as its own source.
- **Fix:** BZH-Sport Live Sports pulls schedule and streams from volkamax.club.
- **Fix:** Adding an IPTV portal no longer reshuffles the rest of the Portals list — new ones go on top (after favorites); everyone else keeps their place.
- **Fix:** Live Sports **Open matches in → Side panel** stays selected (no longer snaps back to Detail page after you change it).
- **Fix:** Live Sports Providers on Android TV show the first streams as they arrive instead of freezing the UI while every pack finishes.

### Player

- **Fix:** ExoPlayer on Android TV paints through Flutter’s video texture (same path MediaKit uses) so Asian Drama and movies no longer show a mottled / speckled picture on boxes like Xiaomi Android 14.

### TV

- **Fix:** Android TV Settings → Forja Packs — D-pad Up/Down from a pack’s details chevron moves focus (holding Down no longer freezes the page).
- **Fix:** Android TV My List Open with… — D-pad Up from hub chips reaches Match / Open with; Down returns to chips or search.
- **Add:** Android TV My List Open with… — status pin leftmost (before Match), hero-style expand labels on focus, D-pad status dropdown — cards hide the overlay pin.
- **Change:** My List Open with… chrome (Match / pin / labels) comes from the My List pack — host only mounts pack `openBind` props.
- **Fix:** Android TV Live Sports / IPTV — D-pad Up/Down from the progress bar reaches Back and Play again (no longer stuck on the seek row).
- **Fix:** Android TV Settings — Left / Back from a settings page returns to the category menu first (no jump to the profile nav icon).
- **Add:** Android TV details — hold OK (or MENU) on an episode to mark it watched; short OK still selects, second short OK still plays.

### Settings

- **Change:** Settings → Forja Packs shows **Official packs** again (opens the ForjaHQ checklist) instead of the Community Packs web card.
- **Fix:** Turning off **Direct torrent** no longer turns off **Nuvio** — each Addons switch is independent.
- **Fix:** Android TV **Discover on Wi‑Fi** (Settings → LAN) finds the desktop again — multicast stay open for the full scan.
- **Fix:** IPTV and Live Sports shelf tabs invert (white fill, accent label) when the selected tab is focused or hovered — focus is visible again.
