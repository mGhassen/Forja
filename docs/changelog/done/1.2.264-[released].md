# 1.2.264 — Dabaghin

**Status:** released  
**Version:** 1.2.264 (`v1.2.264` — Dabaghin)

### UI
- **Fix:** Quick-hovering the desktop rail profile no longer flashes a different avatar.
- **Fix:** Shell tabs no longer go dead (no hover, no clicks) after visiting a later tab — IPTV and other mid-list pages stay interactive.
- **Fix:** Enabling or reordering a tab in Settings → Navigation no longer reloads Settings back to Playback.
- **Change:** Settings and player toggles share one Forja switch style (brand-green track).
- **Change:** Fresh installs enable Search, Home, Asian Drama, Anime, IPTV, Live Matches, and My List in that order; Home remains the startup tab.
- **Change:** Public web uses abstract brand backdrops only - no film/series artwork or TMDB stills.
- **Remove:** Discover, Similar, Media Downloader, Magnet, Audiobooks, Books, Music, Comics, Manga, Jellyfin, Anime Arabic, and Arabic are temporarily hidden from the shell and Navigation settings (code kept).
- **Change:** Site nav labels are Streaming Player and Live Player (routes unchanged).
- **Change:** Public web login copy leads with the player story (one player, your sources, every screen).
- **Remove:** Fake “now playing / your night” widget on the login page.
- **Change:** Site footer is a full brand close - headline, Download CTA, Explore/Legal links - instead of a thin link strip.
- **Change:** Site top nav is a floating command bar (logo · Home/IPTV · Log in + Get Forja), with a full-screen mobile menu.
- **Change:** Download page swaps the old Android TV / account blurb for a three-step “download to play” strip.
- **Change:** Public web uses the normal pointer on links/buttons with clear hover and press feedback (custom cursor removed).
- **Change:** Public web sections animate in on scroll; cards and CTAs lift/zoom on hover (respects reduced motion).
- **Fix:** Splash retries flaky TMDB requests and falls back to Popular for the hero when Trending fails once.
- **Change:** Splash shows the current boot step above the version, closes at 8 seconds even if catalog services are still loading, and toasts when that happens.
- **Change:** IPTV portal rows show connection seats (`used/max`) under the server URL in blue/gray; the top-bar portal control is wider, uses a health status dot, and expands left on hover/focus to show seats.
- **Add:** Optional announcement banner at the top of the shell (from Forja cloud announcements).
- **Change:** The desktop rail’s pinned Settings control now keeps a larger-than-icon profile avatar even while idle, shows the profile name, uses the same artwork as the web picker (or Guest), and reveals its colors on hover/selection.
- **Change:** Every desktop rail destination is gray while idle and reveals its own distinct accent color when hovered or selected, including the active underline.
- **Add:** Movie and series details show TMDB watch-provider logos (Netflix, Disney+, etc.) under the year/runtime line when TMDB lists them for your region.
- **Change:** Sources Torrents / Stremio / Nuvio controls are underline tabs with hover motion instead of pill buttons.
- **Change:** On series details (movies/TV, Anime, Asian Drama, Anime Arabic), tapping an episode card selects it; the card play button plays or resumes that episode.
- **Change:** Series details episode rails show skeleton cards while loading instead of a spinner.
- **Fix:** Episode card center taps select again when the play button is hidden — an invisible play control no longer steals the click.
- **Change:** Card play buttons float upward and their play icons pulse slowly when the card is hovered or focused.
- **Change:** Home catalogs and streaming-provider availability follow the device country again, with the United States as the fallback.

### Player
- **Change:** Movie, Anime, and Asian Drama loading screens show plain-language resolve failures on the same cinematic page (title + short tip + Try again / Close) instead of technical copy or fleeting toasts.
- **Fix:** Switching to a Nuvio or Stremio link in Sources no longer stays on audio-only / black picture — the player waits for a real video frame (and retries software decode once) before confirming playback.
- **Fix:** Windows direct streaming (movies, anime, Asian drama) no longer spins through every server when GPU decode stalls — the player retries once with software decode before failing over.
- **Fix:** Sources loads only the open kind (Torrents / Stremio / Nuvio); switching away cancels the previous kind, and reload is only on the selected chip.
- **Fix:** TV next/previous episode lookup no longer crashes the player when TMDB is briefly unreachable.
- **Fix:** Local torrent playback no longer freezes on a black screen when mpv reports buffer before any video frame — the player waits for real video (or fails cleanly) instead of false-confirming open.
- **Fix:** Playing a Torrents-tab magnet from media details no longer silently dismisses the loading overlay — Sources closes after loading is shown, resolve failures toast, and cancel/dispose no longer race the magnet job.
- **Fix:** Opening Sources (Stremio / torrents) or other player menus no longer sticks the progress thumb to the mouse cursor.
- **Fix:** Anime and Asian Drama Source / Episodes menus no longer magnetize the progress thumb (same scrub cancel as movie Sources).
- **Fix:** Torrent episodes no longer jump to “finished” / auto-next on early EOF, and Continue Watching / Play no longer resumes into the credits after a false finish — replay starts from the beginning.
- **Fix:** After an episode or film ends, the progress bar still scrubs and replay works — the player stays on the last frame instead of locking seeks.
- **Fix:** The progress bar no longer flashes full/empty while Forja is still trying the next stream link before playback really starts.
- **Fix:** Anime next episode no longer leaves a black player — Forja closes the current player and opens the next episode cleanly.
- **Fix:** End-of-episode progress stays at the end (and next episode works) when the stream finishes after a real watch — keep-open no longer looks like an abortive stop.
- **Fix:** Replaying an anime episode from a dead saved stream no longer sticks on one failed server with an empty Source list — Forja drops that cache and re-searches servers like movie Play.
- **Fix:** Anime Play races multiple servers and checks stream links before opening — a dead CDN no longer leaves a single failed stream with no failover.
- **Fix:** Anime dead-cache recovery no longer pretends Auto is pinned after a failed re-search, and no longer overwrites your preferred server from a brief failed open.
- **Fix:** Anime Resume / Continue Watching restarts from the beginning when an episode was already finished (≥90%), instead of seeking into the credits.
- **Fix:** Anime and Asian Drama no longer tear down the loading route under the player on open — Source taps and dead-cache reload keep working for the whole session.
- **Fix:** Leaving the player while scrubbing no longer crashes (seek preview / pointer route after dispose).
- **Fix:** Early torrent EOF no longer flips to auto-next after ~45 seconds of sitting at the end — only a real mid-episode watch counts as finished.
- **Fix:** Leaving a stuck player no longer cancels a new Local Torrent Engine start (magnet resolve was aborted as “cancelled”).
- **Fix:** Watch history no longer spams skip logs / work while a torrent is still opening (pos/dur still zero).
- **Fix:** Switching torrents or Stremio magnets in the player keeps the current video playing with a bottom-right loading card, and only opens a fresh player once the new stream is ready — no more freeze while the magnet checks.
- **Fix:** Opening Sources while playing a Stremio/Torrentio magnet opens the Torrents tab and highlights that magnet — not the Stremio tab.
- **Fix:** Player Sources scrolls to the playing torrent or Stremio stream and opens the matching Stremio addon when that stream is active.
- **Fix:** Choosing Nuvio (or Stremio) in player Sources no longer snaps back to Torrents after load when a magnet is already playing.
- **Fix:** Player failure messages no longer overlap, and the title stays centered regardless of the controls on either side.

### Sources
- **Fix:** Failed server/stream checks (−2) actually lower that provider’s score instead of leaving the total unchanged.
- **Fix:** Leaving a title or switching tabs while servers are still checking (movies/TV, Anime, Asian Drama) stops the search — it no longer keeps probing in the background (Cancel was not required).
- **Fix:** Asian Drama episodes that still show a countdown (not unlocked yet) again show **Not available yet** with a clear unlock tip instead of a generic “no stream” error.
- **Change:** Sources shows provider chips (Forja / Jackett / Prowlarr, Stremio addons, Nuvio scrapers) under the Torrents / Stremio / Nuvio tabs — not inside Filters.
- **Fix:** Slow magnets no longer die at 8 seconds while other torrent apps still find peers — the local engine waits up to 90s for metadata.
- **Fix:** Local torrent startup validates cached metadata before falling back to DHT/trackers, listens for incoming peers, and waits for enough stream bytes — healthy magnets no longer time out empty as easily.
- **Fix:** Asian Drama uses one KissKH host without mirror preflight or failover requests; other mirrors are shown On hold in Playback settings to avoid shared-IP rate-limit bans.
- **Fix:** After KissKH rate-limits Play, Forja no longer reloads the episode page a second time — it cools down and asks you to wait.
- **Fix:** Opening Asian Drama no longer fans out KissKH details for posters; hero synopsis is filled from TMDB when a title matches (KissKH synopsis enrich kept but off).
- **Fix:** When Torrentio (or another Stremio addon) fails, Sources no longer stays blank on that provider — it opens the first addon that returned streams (YTS, etc.).
- **Fix:** Sources no longer shows a stuck Filters “1” badge just because a Stremio/Torrents provider is selected, and a failed addon’s error no longer hides streams from other addons.
