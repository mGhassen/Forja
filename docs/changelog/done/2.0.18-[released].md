# 2.0.18 — Serrajin

**Status:** released  
**Version:** 2.0.18 (`v2.0.18` — Serrajin)

---

### Player
- **Fix:** Films that already include subtitles no longer flash a free-plan line from an online subtitle before the stream’s own track appears.

### Features
- **Fix:** My List status tabs open from the list saved on the device. Switching Plan to Watch, Watching, and the other buckets no longer waits on a fresh download of every title.

### TV
- **Fix:** On Android TV, D-pad down in the IPTV channel catalog moves to the next row. The focused channel stays put until it reaches the edge of the screen.
- **Fix:** Subtitle Settings on Android TV matches the size of the other player menus.
- **Fix:** Portal loading stripes and download stripes shrink with the rest of the TV layout.
