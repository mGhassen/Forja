# 1.3.66 — Elblat

**Status:** released  
**Version:** 1.3.66 (`v1.3.66` — Elblat)

---

### Features
- **Change:** macOS installer DMG opens as a dark drag-to-Applications window with large icons (not a plain white Finder view).
- **Fix:** Website PostHog analytics uses the official TanStack Start provider and picks up Vercel `POSTHOG_API_KEY` / `VITE_POSTHOG_KEY` at build time (redeploy required).
- **Fix:** Account → Connections hides expired and duplicate sign-ins — mint leftovers and same-device repeats no longer show with Revoke.
- **Fix:** A failed cloud settings pull (e.g. Android TV cold start) no longer reseeds platform defaults and uploads them over your Features / navigation; playback edits and profile switches also no longer rewrite cloud nav from a stale device cache (including dropping Home / Search).

### Player
- **Change:** ExoPlayer Subtitles menu turns off on one tap of **Off**, adds a tune button for appearance settings next to Close, and tightens title/close spacing.
- **Fix:** Built-in ExoPlayer and MediaKit start at full volume (100%) instead of quieter defaults — Exo no longer maps “100” to about two-thirds of max.
- **Change:** HLS Auto start bitrate follows **Settings → Max stream quality** (Auto keeps a mid-high soft ceiling for a faster first frame; 4K uses the top rung). Same soft cap applies to ExoPlayer VOD.
- **Fix:** On Android TV, switching anime / movies / drama from MediaKit to ExoPlayer no longer shows a zoomed, cropped frame — the app fully releases MediaKit before Exo starts so the picture letterboxes correctly.

### Live & IPTV
- **Fix:** On Android TV, leaving the IPTV player after switching to MediaKit (Player menu) no longer freezes and force-closes the app — and switching back to MediaKit / reopening still plays video.
- **Change:** IPTV player on Android TV (ExoPlayer) no longer shows the bottom progress bar — transport controls stay; VOD still seeks with ←/→ when chrome is hidden.
- **Fix:** Opening an IPTV channel on Android TV no longer crashes before playback starts (player boot waits for the route after the first frame).
- **Fix:** On Android TV, when a live IPTV stream briefly shows Reconnecting and then recovers, the reconnect banner dismisses instead of staying on screen.
- **Fix:** On Android TV, IPTV ExoPlayer uses a SurfaceView (hybrid composition) so live channels stay fluid instead of soft / low-FPS TextureView; MediaKit matches the display refresh for smoother live. Leanback **emulators** keep TextureView so IPTV is not audio-only with a blank / covered screen.
- **Add:** Settings → Playback → **IPTV live max quality** — Auto keeps full portal quality; optional 1080p / 720p / 480p only if you choose them (never forced).
- **Fix:** Desktop and phone IPTV player chrome again show the volume / mute control (hover expands the slider) — Android TV still uses hardware volume only.
- **Fix:** Live Matches embeds on desktop unmute after load and show a Mute control next to the source badge when the site stays silent.
- **Fix:** Sync no longer replaces your full IPTV portal list with a short local cache — cloud stays master (server refuses shrink unless you delete portals on purpose).
- **Change:** IPTV Movies and Series no longer run a stream status check on hover or focus — only Live channels still show the green/red health indicator.
- **Change:** On Android TV, scrolling IPTV categories (catalog and in-player guide) shows “Press OK to open” instead of loading channel logos — OK or Right opens the group.
- **Change:** In the IPTV player channel guide on desktop, hovering a category only highlights it — it no longer scrolls the list or switches channels; click to open the group.
- **Change:** On desktop, the IPTV player channel guide stretches to the bottom of the screen (full height under the window chrome).
- **Fix:** Live Matches on Android / Android TV hands Streamed and PPV embeds to the native IPTV player after sniffing HLS, with **separate** techniques per source (PPV: top-level embedindia + proxy probe; Streamed: Exo plays a local playlist while the embed WebView quietly fetches the real CDN segments — avoiding the block that hit a normal download). Failed probes toast and return to the match list. The **Player** control appears after handoff. Streamed no longer stays on the red “Remove sandbox attributes…” WebView lock, and no longer buffers then Reconnecting when the CDN child playlist is fetched.
- **Fix:** Live Matches PPV (`embedindia`) on Android / Android TV no longer stalls on “Opening stream…” when the site waits for a play tap — Forja starts JW muted, taps the player center, and reads the playlist from JW when the cover is up.
- **Fix:** Live Matches ● LIVE badges and play buttons treat any active PPV viewer count as live (until a few hours past the scheduled end), including early lobbies and wrong device clocks — cards with audience numbers stay tappable on Android TV.
- **Fix:** IPTV player search results show taller channel logos so they are easier to read on Android TV.

### UI
- **Fix:** Switching profiles no longer crashes when IPTV was open earlier in the session (tab teardown no longer touches Riverpod after dispose).
- **Fix:** Choosing a side-nav tab (desktop click or TV OK) pulls cloud Features/settings so new tabs like My List show up without waiting for focus/resume — not on a background timer.
- **Fix:** The side nav no longer briefly shows every Features tab when the window regains focus or the shell reloads — it waits for your saved tab list.
- **Fix:** Website Account → Features no longer flashes every tab checked while your saved list loads.
- **Change:** Switching profiles no longer waits for home-feed and engine warm to finish — the avatar splash dismisses like the intro splash, and IPTV portals only sync when that profile has IPTV.
- **Fix:** Account settings on the web (Playback, Features, Stremio, Nuvio) keep your edits instead of snapping toggles and fields back before you can save.
- **Fix:** Asian Drama hub and explore cards use wide 16:9 frames so KissKH landscape covers are no longer zoomed and cropped in portrait posters.
- **Change:** App launcher icons (Android / Android TV, iOS, macOS, Windows, Linux) show the green Forja wordmark instead of the F monogram.

### TV
- **Fix:** On Android TV, Live Matches → Exo no longer leaves the remote dead — the underlay embed WebView stops eating D-pad, and ←/→ moves Play / Replay / top **Player** again.
- **Fix:** Android TV **Sign in** can create a link code again (no longer fails immediately with “TV device link create failed”).
- **Fix:** On Android TV, player chrome no longer traps D-pad on **Play** — ←/→/↑/↓ move across transport and top-bar controls again (Exo, IPTV, film).
- **Fix:** On Android TV IPTV (including Live Matches after native handoff), D-pad → from **Back** reaches the top-right **Player** button (and ← returns) — focus no longer dies across the title gap.
- **Change:** Settings → Features on Android TV matches desktop — **OK** on the star sets the default menu, and **↑/↓** reorder tabs (visibility still toggles with **OK** on the tab name).
- **Fix:** Back from the IPTV player on Android TV focuses and scrolls to the channel you were watching in the catalog (not the first tile).
- **Fix:** IPTV player on Android TV regains D-pad like the movie player — focus lands on Play, remote arrows move chrome, and the Exo surface no longer eats keys.
- **Fix:** On Android TV, film stream loading again focuses Cancel and the server list so D-pad can cancel or pick a provider.
- **Change:** On Android TV, opening details, search overlays, and players cuts straight in (no slide animation) so weak sets do not stutter while the new screen loads.
- **Change:** Opening any fullscreen player clears poster/image memory and unloads other shell tabs (keeps the screen under the player); Android TV also keeps fewer tabs mounted while browsing (max three).
- **Change:** On Android TV, the in-player **Player** menu (movies, series, anime, drama, IPTV) lists only ExoPlayer and MediaKit — external apps are hidden; ExoPlayer is the default engine.
- **Fix:** After the side nav loads its tab list, D-pad ↑/↓ no longer skips items (stable focus per tab + retry focus once tabs appear).
- **Fix:** Android TV (and other restored sessions) pull cloud profile settings on cold start — nav, IPTV, playback, and other synced prefs no longer stay on a stale local cache until you leave and reopen the app.
- **Change:** Android TV Apps row and home banner both use the green Forja wordmark (square icon and wide banner).
- **Fix:** Android TV Settings no longer shows Sources, Debrid, or Direct torrent / Stremio / Nuvio (including when those prefs are on from another device).
- **Fix:** On details, focusing a trailer draws the white ring on the thumbnail only — not a box around the title.
- **Add:** Trailer player on Android TV shows the top-right **Player** control (open in YouTube), matching the movie player.
- **Change:** Android TV trailer chrome auto-hides after idle (and on remote Back); volume and center play/skip controls are removed — use the bottom row and hardware volume.
- **Fix:** On Android TV, D-pad ←/→ seek the timeline (±10s) when player controls are hidden or the progress bar is focused — they no longer jump to Play or Sources.
- **Change:** Home on Android TV uses a shared focus-graph layout so catalog rows, mood chips, and Stremio **Show All** stay in one D-pad path (each Stremio rail keeps its own vertical slot).
- **Change:** Anime and Asian Drama hubs on Android TV use the same focus-graph recipes as Home (catalog rows, continue watching, and Anime vibe chips).
- **Change:** Search on Android TV uses the shared focus-graph grid for results (and the trending helpers list), so D-pad stays on one path with Home/hubs.
- **Change:** Player menus, Sources, Episodes, and related dialogs on Android TV share one overlay focus host (Back/Esc dismiss, linear D-pad inside the panel).
- **Change:** Live Matches and IPTV on Android TV use the same focus-graph recipes as Home (sport/CDN chips, card grids, IPTV category and stream rows).
- **Change:** My List, Settings hub, hub search, and media details on Android TV use the shared focus-graph layout (poster grid, category rail, cast/trailers/play rows).
- **Change:** Live Matches embed chrome and Who’s watching on Android TV use the same focus-graph / overlay recipes as the rest of the TV shell.
- **Change:** IPTV portals, channel grids, M3U lists, and player chrome on Android TV register through the shared catalog-row recipes (search field chrome stays on its sync path).
- **Change:** On Android TV, Back on the side nav twice (within about two seconds) leaves the app; the remote Exit button also needs two presses to quit — Back elsewhere still only navigates.
