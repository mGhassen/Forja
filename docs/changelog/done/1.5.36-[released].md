# 1.5.36 — Berka

**Status:** released  
**Version:** 1.5.36 (`v1.5.36` — Berka)

---

### Features
- **Add:** Shahid hub and stream provider — browse Shahid catalog; sign in under Settings → Connected services; Android plays Widevine titles with ExoPlayer.

### Sources
- **Fix:** Shahid hub catalog loads again (top charts + search) after Shahid’s old filter API started returning 400.
- **Fix:** Shahid home rails show titles again (feed item shape + rail id param matched the kit host).
- **Add:** Packs can add their own Connected services Login / Logout (session auth) without hardcoding the service in the app.

### Player
- **Add:** Android ExoPlayer Widevine license support for streams that include a DRM license URL.

### UI
- **Fix:** Asian Drama **More Like This** opens TMDB details instead of failing KissKH with a TMDB id.
- **Fix:** After sign-in, packs wait for profile splash before downloading; the shell no longer freezes on a Features sync storm.
- **Fix:** Logging out no longer forces a full plugin re-download for the same profile — scripts already on disk are reused.
- **Fix:** Features tab on/off and order sync to the cloud again after logout (pending packs no longer strip the push).
- **Fix:** Local plugin checkouts (like an unpublished Shahid pack) stay installed across logout; packs only load after a profile is launched (guest counts as a local profile); pack install state is stored per profile so soft-pull no longer wipes and re-downloads.

### Live & IPTV
- **Fix:** Live Sports Source picker on desktop sits a little above the seekbar again (same gap as Audio).
