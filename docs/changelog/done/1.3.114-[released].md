# 1.3.114 — Elblat

**Status:** released  
**Version:** 1.3.114 (`v1.3.114` — Elblat)

---

### Sources
- **Fix:** Asian Drama signs KissKH stream keys in the engine and opens streams in about a second — no more waiting on a hidden browser page (desktop and Android TV).
- **Fix:** Details Sources Stremio addon chips stick when tapped — empty addons no longer silently snap back to one with results.
- **Change:** WebStreamr, Nuvio, stream proxy, and torrent engines start after the splash finishes — not during the splash animation.

### Features
- **Fix:** macOS installer DMG keeps its drag-to-Applications layout (matrix background, large icons) instead of opening as a plain white Finder window.

### UI
- **Change:** Continue watching cards on Home, Anime, and Asian Drama, and IPTV catalog channel tiles, show a neutral play button on card hover — it turns green and heartbeats only when you hover the play control.
- **Fix:** Desktop trackpad swipe-back uses a browser-style left-edge arrow that only goes previous when fully filled — Sources panel, Nuvio addon chips, and catalog rows no longer steal Back while you scroll them.
- **Fix:** Cold start shows the logo splash immediately — update check and cloud sync (including IPTV portals) no longer leave a black window first.
- **Fix:** When Profile & account cannot load (or is still loading) your cloud profile, **Sign out** stays available — no spinner-only dead end when the network is down.
- **Remove:** Home no longer shows Stremio addon catalog rails (Sources / Search / Live Matches still use Stremio).

### Player
- **Fix:** On Android TV, Home / movies / series ExoPlayer shows video again (was sound with a black picture) — VOD uses TextureView instead of SurfaceView.
- **Fix:** HLS servers like VixSrc no longer show a red failed Source row with a stuck `0:00` seek bar after video already starts — duration is allowed to arrive after playback confirms.
- **Fix:** On Android TV, switching ExoPlayer ↔ MediaKit from the **Player** menu (movies, series, anime, drama, IPTV, Live) no longer force-closes the app.

### Live & IPTV
- **Add:** IPTV Portals add dialog lets you choose **Xtream**, **M3U**, or **Stalker** — M3U playlists and Stalker MAC portals live in the same catalog and sync with your profile.
- **Change:** M3U playlists are no longer a separate side screen — add them as portals (URL); Live shelf only for M3U.
- **Fix:** Portal catalog load failure shows a single centered error + **Reload** (no duplicate top banner). On **Android TV**, D-pad **↑** from **Reload** reaches the portal chip and **←** reaches **Favorites** / category rows when present.
- **Fix:** PPV live embeds on desktop stay inside the catalog wrapper — they no longer jump to embedindia and die on a host-lock error page (ad click hosts like gotrackier still cancelled).
- **Fix:** Opening Live Matches no longer throws when the tab remounts (catalog load waits until Riverpod is ready).
- **Fix:** Live Matches embeds (including MutStreams) start with sound on — no more stuck **CLICK UNMUTE STREAM** overlay after open.
- **Fix:** On Android TV, Live Matches **Stremio** (Highfly) no longer loops on Reconnecting — Exo treats leaf CDN playlists as HLS and sends the catalog Referer.
- **Fix:** Live Matches **Stremio** schedules (Highfly and similar) sort by kickoff time — card grid and timeline follow the match clock instead of title order.
- **Add:** Live Matches **Stremio** server plays sport Stremio addons (e.g. Highfly) as HLS in the native player.
- **Add:** Settings → Sources lets you assign each Stremio addon to **Sources**, **Live Matches**, or both.
- **Fix:** On Android TV, D-pad through a long **Portals** list no longer stutters (full lazy list, no 20-row page append, no double scroll jump per press).
- **Fix:** Catalog scrape keeps stalker and M3U hits, stores full **type** / **outputs**, fills expiry / max connections / timezone / region from cards and tables; Claude LLM extract is **opt-in only** (`IPTV_LLM_EXTRACT=1`) and never fails a scrape when credits/API are down.
- **Fix:** Catalog scrape reads bare `.m3u` / `.m3u8` playlist URLs (and `Playlist:` / `M3U:` labels) as M3U portals with username `__m3u__` — including links found inside `#EXTM3U` notes (playlist files only, not every channel stream).
- **Fix:** Catalog scrape reads `MAC Addr:` stalker cards (one row per MAC + Exp date) and Turkish-style `user pass … (Bitiş: dd/mm/yyyy)` sheets under `Portal:`.
- **Fix:** Catalog scrape reads stalker dumps that start with a `/c/` portal URL then bare MAC lines (`00:1A:79:… [Total:…] [Month DD, YYYY…]`), and maps `US/CA/UK/Other` channel counts into region tags + primary.
- **Add:** Stalker Add Portal has a **Generate MAC** button (MAG OUI) — no need to already have a MAC before trying a portal.
- **Add:** M3U Add Portal can pick a local `.m3u`/`.m3u8` file instead of pasting a link.
- **Change:** Stalker portals try the common middleware paths (`portal.php`, `server/load.php`, `stalker_portal/server/load.php`) automatically and reuse one handshake session across Live/Movies/Series/create_link calls, instead of guessing one path and re-authenticating every request.
- **Change:** Stalker Movies/Series catalogs page the portal's ordered list several pages at a time instead of one at a time, so large catalogs sync faster.
- **Fix:** Stalker `create_link` no longer returns a dead link on Xtream-UI-style portal emulations that need the channel's stream/extension parameters forwarded from the cmd URL.
- **Fix:** M3U links that actually return an Enigma2/Gigablue set-top-box bouquet show a clear error instead of "no channels found"; large playlists download to disk before parsing instead of holding the whole file in memory.

### TV
- **Fix:** On Android TV, D-pad browsing the shell and catalog no longer stutters from 200ms focus scale/color animations — focus chrome snaps instantly.
- **Fix:** Android TV **Link this TV** no longer spins forever on **Preparing a code…** when the network is down — it shows an error with Retry / Continue as guest.
