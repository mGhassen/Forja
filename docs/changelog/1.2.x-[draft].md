User-facing changes for the next **1.2.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.2.x-[draft].md` starts.

### Player
- **Fix:** Playing a Stremio or Nuvio stream shows the Sources (torrent/Stremio/Nuvio) panel instead of a one-item `stremio_direct` server picker.
- **Add:** Player Sources includes the **Nuvio** tab with scraper filter chips, matching media details.
- **Change:** Sources **All** includes Nuvio alongside torrents and Stremio, and the panel opens on **All** when more than one kind is enabled (still scrolls to the playing row).
- **Fix:** Reloading a server in the Source panel after Play from cache re-fetches streams instead of silently reusing the cached links.
- **Change:** Sources (details and player) loads only the open category, keeps results for about 30 minutes, and adds a reload on each Torrents / Stremio / Nuvio chip. Closing the panel stops any still-running category fetch.
- **Fix:** Stremio/Torrentio magnets are no longer opened as a local file (which failed with “file name too long”); picking a torrent in Sources fails quietly in the status list instead of crashing the player.

### UI
- **Fix:** Closing the app on Windows no longer freezes on the window — quit hides immediately and finishes teardown without hanging on media shutdown.
- **Fix:** The update screen fills the window height — header and Install stay pinned while only the changelog scrolls, and the logo/spacing shrink on shorter windows.

### Live & IPTV
- **Fix:** Opening an IPTV channel no longer throws a framework error about rebuilding during build.
- **Change:** Live Matches timeline zoom now uses a compact 4-tab control (Day / 12h / 6h / 3h), adding a tighter 3-hour view.
- **Fix:** Switching sport categories on the Live Matches timeline keeps the playhead on now instead of jumping to unrelated dates.
- **Change:** Opening the IPTV portals panel scrolls straight to the active portal; scraping, share-code add, and manual add scroll the list to each newly found or added server.
- **Add:** Settings → Data & backup includes **IPTV portal cache** to clear live-channel health checks and channel scan results without removing portals.

### Sources
- **Fix:** Green Play no longer reopens Stremio when a previous Stremio Direct session polluted the webstreaming resume cache — it only reuses real web extractors.
- **Change:** Sources → Nuvio searches all scrapers at once and shows each scraper as a toggleable filter chip (no All-in-One drill-down).
- **Fix:** Closing Sources (or leaving a title) stops Nuvio scrapers — they no longer keep fetching after the panel is gone.
- **Change:** Asian Drama first checks KissKH mirror URLs in parallel (dead hosts show DOWN immediately), then opens a browser only for healthy mirrors — listed in Settings → Playback and the player Sources panel.

### Features
- **Change:** Settings, sources, addons, and related preferences now persist in the app settings file across restarts; API keys and login tokens stay in secure device storage.

### TV
- **Change:** Opening the app on Android TV focuses the Home nav rail item first (not the hero Play button).
