### Live & IPTV
- **Change:** The IPTV player progress bar now shows only the current time (the total-time label was removed) with more room for the timestamp.

### UI
- **Change:** The update screen is wider, keeps the Install and Skip buttons pinned at the bottom while the changelog scrolls, and shows each change with a colored Add/Change/Fix/Remove tag.

### Features
- **Change:** Desktop updates can continue downloading in the background with a sticky progress toast (hidden in video players), show an Install notification when ready, and reuse an installer already downloaded; macOS and Windows ask before launching the installer and closing Forja.
- **Fix:** macOS update downloads no longer fail with a sandbox permission error when saving the DMG.
- **Fix:** Clearing downloaded updates also resets the in-app update state so the next check downloads again instead of showing Install immediately.
