### UI
- **Change:** Public web uses abstract brand backdrops only — no film/series artwork or TMDB stills.
- **Change:** Site nav labels are Streaming Player and Live Player (routes unchanged).
- **Change:** Public web copy frames Forja as a streaming media player (playback, playlists you connect) — not a free movie/series catalog pitch.
- **Change:** Site footer is a full brand close — headline, Download CTA, Explore/Legal links — instead of a thin link strip.
- **Change:** Site top nav is a floating command bar (logo · Home/IPTV · Log in + Get Forja), with a full-screen mobile menu.
- **Change:** Download page swaps the old Android TV / account blurb for a three-step “download to play” strip.
- **Change:** Public web uses the normal pointer on links/buttons with clear hover and press feedback (custom cursor removed).
- **Change:** Public web sections animate in on scroll; cards and CTAs lift/zoom on hover (respects reduced motion).
- **Fix:** Splash retries flaky TMDB requests and falls back to Popular for the hero when Trending fails once.
- **Change:** Splash shows the current boot step above the version, closes at 8 seconds even if catalog services are still loading, and toasts when that happens.
- **Change:** IPTV portal rows show connection seats (`used/max`) under the server URL in blue/gray; the top-bar portal control is wider, uses a health status dot, and expands left on hover/focus to show seats.
- **Add:** Optional announcement banner at the top of the shell (from Forja cloud announcements).
- **Add:** Movie and series details show TMDB watch-provider logos (Netflix, Disney+, etc.) under the year/runtime line when TMDB lists them for your region.
- **Change:** Sources Torrents / Stremio / Nuvio controls are underline tabs with hover motion instead of pill buttons.
- **Change:** On TV series details, tapping an episode card selects it; the card play button plays or resumes that episode.

### Player
- **Fix:** Windows direct streaming (movies, anime, Asian drama) no longer spins through every server when GPU decode stalls — the player retries once with software decode before failing over.
- **Fix:** Sources loads only the open kind (Torrents / Stremio / Nuvio); switching away cancels the previous kind, and reload is only on the selected chip.
- **Fix:** TV next/previous episode lookup no longer crashes the player when TMDB is briefly unreachable.
- **Fix:** Local torrent playback no longer freezes on a black screen when mpv reports buffer before any video frame — the player waits for real video (or fails cleanly) instead of false-confirming open.
- **Fix:** Playing a Torrents-tab magnet from media details no longer silently dismisses the loading overlay — Sources closes after loading is shown, resolve failures toast, and cancel/dispose no longer race the magnet job.
- **Fix:** Opening Sources (Stremio / torrents) or other player menus no longer sticks the progress thumb to the mouse cursor.
- **Fix:** Torrent episodes no longer jump to “finished” / auto-next on early EOF, and Continue Watching / Play no longer resumes into the credits after a false finish — replay starts from the beginning.
- **Fix:** Leaving the player while scrubbing no longer crashes (seek preview / pointer route after dispose).
- **Fix:** Early torrent EOF no longer flips to auto-next after ~45 seconds of sitting at the end — only a real mid-episode watch counts as finished.
- **Fix:** Leaving a stuck player no longer cancels a new Local Torrent Engine start (magnet resolve was aborted as “cancelled”).
- **Fix:** Watch history no longer spams skip logs / work while a torrent is still opening (pos/dur still zero).
- **Fix:** Switching torrents in the player shows the loading card and opens a fresh stream from the start — no more freeze on in-place stop/reopen.
- **Fix:** Opening Sources while playing a Stremio/Torrentio magnet opens the Torrents tab and highlights that magnet — not the Stremio tab.
- **Fix:** Player Sources scrolls to the playing torrent or Stremio stream and opens the matching Stremio addon when that stream is active.
- **Fix:** Choosing Nuvio (or Stremio) in player Sources no longer snaps back to Torrents after load when a magnet is already playing.

### Sources
- **Fix:** Slow magnets no longer die at 8 seconds while other torrent apps still find peers — the local engine waits up to a minute for metadata.

### Live & IPTV
- **Change:** IPTV page shows the real player control desk and catalog UI; platform download lists live only on `/download`.
- **Change:** IPTV sections each sell one idea (player powers, on-screen controls, shelves, portals) with a single Download CTA.
- **Change:** IPTV player hides audio and subtitle controls and shows the channel logo at the bottom-left above playback progress.
