# 1.2.x — Dabaghin

**Status:** draft  
**Since release:** 1.2.406 (`v1.2.406`)

User-facing changes for the next **1.2.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.2.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Features
- **Fix:** Anime tab opens faster — hero shows AniList art right away (TMDB backdrops fill in after), and trending rails share one catalog fetch instead of three.
- **Add:** Anime details link AniList seasons (PREQUEL/SEQUEL, including through film bridges like Youjo Senki S1→Movie→S2) and show **Related** franchise titles with badges (Side Story, Summary…) — films/specials for continuous series like One Piece.
- **Add:** Anime details shows **Related** right under episodes, then **Characters**, **Staff**, **Trailers**, and **More Like This** (AniList recommendations).
- **Add:** Mark episodes watched or unwatched on Anime and Asian Drama details (right-click an episode card; local checkmarks only).
- **Add:** Episodes auto-mark watched at 85% (movies, TV, Anime, Asian Drama); details show series progress (`N of T · %` / Completed) and a Watched check on finished movies.
- **Fix:** Anime details refresh Resume, the hero progress bar, and episode progress after you leave the player (same as Asian Drama).
- **Fix:** macOS no longer asks for your login Keychain password on every app update.
- **Fix:** Download page keeps every platform’s latest installer when a release ships only some platforms (each row shows that platform’s version and notes).
- **Fix:** Signed-in settings sync treats cloud as master — the local settings file is a cache only, so a partial/empty cache can no longer wipe Stremio, Nuvio, or other profile settings in the cloud.

### UI
- **Fix:** Anime / series details with a single season pull the episode row up under Play (no empty season-rail gap).
- **Change:** Anime **Pick your vibe** uses the same circular mood icons as Home (colored rings, focus/hover glow) — on TV they stay centered without scrolling.
- **Fix:** Anime TV D-pad follows the page order — Play → Trending → Continue Watching → Pick your vibe → catalog — and no longer gets stuck on a row or lands on a blank focus scope after leaving the player / returning from the nav rail.
- **Fix:** Asian Drama TV D-pad follows the page order — Play → Latest Update → Continue Watching → catalog (Continue no longer jumps ahead of Latest under the hero).
- **Fix:** Anime details episode row no longer leaves a blank band under titles when there’s no air date or synopsis — Related sits at the normal section gap.
- **Fix:** Anime details **More Like This** / **Related** rows align with Staff and Trailers (no extra left inset).
- **Fix:** Hub poster badges (Related Side Story, format labels) use gray with black text so they stay readable on light covers.
- **Fix:** Episode thumb badges (E# / duration) use a light pill with dark text so they stay readable on dark stills.
- **Change:** Clicking an episode on details no longer jumps that card to the start of the row — it only scrolls if the card was off-screen.
- **Change:** Details Play and action buttons sit directly under the synopsis instead of at the bottom of the hero.
- **Change:** Finished / restart threshold is 85% (was 90%) for Continue Watching and Resume.
- **Fix:** Series watched badge on details uses brand green on a dark pill (no longer gray-on-gray).
- **Fix:** Series and anime details show a 3-line synopsis with Read More (episode rows sit a bit lower so the hero has room).
- **Fix:** Anime / Asian Drama details no longer overflow the hero on short phones — Play stays; title, meta, and synopsis shrink or hide when the episode rail leaves little room.
- **Fix:** Series Production Info sits flush above seasons instead of floating mid-hero.
- **Change:** Production Info last row fills the card bottom (no empty footer strip).
- **Change:** Anime and Asian Drama details use the same Production Info card as movies.
- **Fix:** Production Info clips with rounded top and bottom instead of cutting the card square.
- **Remove:** Production Info card no longer shows a “Production Info” heading — facts start at the top of the card.

### Player
- **Fix:** Android TV ExoPlayer shows a **Sources** control again — a two-column servers / streams dialog so you can check another server and switch mid-play.
- **Fix:** Android TV ExoPlayer no longer shows tiled or shifted video frames (Anime and other streams).
- **Fix:** Switching stream providers updates the bottom source chip right away (no longer stuck on the previous name while Checking Sources runs).
- **Fix:** Back / Escape from the player no longer red-screens when subtitle auto-select or chrome overlays were still finishing after the route closed.
- **Fix:** Back / Escape from the player returns to details — not the stream loading screen (movies/TV, Anime, and Asian Drama).
- **Change:** Details trash next to Resume clears watch progress and that title’s cached stream provider (next Play re-resolves) — movies/TV and Anime (Anime also drops the saved source pin).
- **Change:** Multi-stream servers list every stream first, then check them one by one in the Source panel (`Checking 2/5…` on the server row).
- **Fix:** Stream open uses one open-pipeline middleware — identity headers, byte classify, then strip or direct; failed branches re-decide the next technique; decode confirm only observes (no hidden hwdec reopen).
- **Fix:** Source panel keeps the catalog stream row while PNG-strip plays via the local proxy — checking another provider no longer hides the playing Megaplay stream or leaves it stuck on a Checking spinner.
- **Fix:** Same CDN URL on another server no longer paints as Playing (blue pause) — play still switches instead of toggling the current server.
- **Fix:** Sources reload and stream check always re-fetch/probe — they no longer reuse a cached dead URL or skip check because the player looked “already playing.”
- **Fix:** Failed stream opens clear the cached extract and show an error instead of silently ignoring the failure.
- **Change:** Trailer player matches main player chrome — auto-hiding controls, center play/±10s, horizontal volume bar, fullscreen button + double-click, quality/speed chips, audio/subtitle list rows, a bottom-right **More videos** card that slides between trailers (click plays), and auto-plays the next trailer after a countdown when one ends.
- **Fix:** Trailer player crops YouTube logo / “More videos” chrome (cover + overscan; captions stay uncropped) and double-click fullscreen works through the WebView.
- **Fix:** Trailer player opens fullscreen over the shell (nav rail hidden) like the main player.
- **Change:** Audio and subtitle menus show each language in its native script (हिन्दी, தமிழ், Español…).
- **Change:** Quality menu hides Auto while ABR is on and highlights the resolution currently playing.
- **Change:** Subtitles language rows no longer show a leading translate icon.
- **Change:** Subtitle language choice sticks across episodes — pick once in the player; next episodes reuse that category (falls back to English if missing).
- **Fix:** Preferred subtitle auto-select actually applies after the stream opens (no longer looks selected until you tap it again).
- **Fix:** Dead anime/CDN opens no longer leave the seek bar pinned at the end like a finished episode.
- **Fix:** Playback starts faster — HLS Auto uses a shorter prefetch and a mid-high bitrate instead of pulling the top rung / two minutes ahead before the first frame (lock a higher Quality chip when you want max).
- **Fix:** Checking a stream provider in the background no longer plays that embed’s audio over the video you’re already watching.
- **Fix:** Embed/CDN streams keep the provider’s player Referer by identity (Vidzee and other template hosts no longer 403 into a silent dead play when the CDN renames).
- **Fix:** Play opens the loading screen immediately — including cache hits — instead of sitting idle while history/cache probe finishes.

### Sources
- **Fix:** Anime server score prefixes no longer stay green **+2 +2** when the CDN check fails — scores commit after a reachable stream (or **+2 −2** when extract works but the CDN is dead).
- **Fix:** Miruro AnimePahe / AllManga / AnimeDao / AnimeGG / AniKoto / HiAnime play like 1.2.406 again — keep upstream extract Referers (no force to miruro.tv), master-only probes, skip PNG-strip classify that false-rejected real HLS, and decode CF pipe bodies even when WebView hides the `x-obfuscated` header.
- **Fix:** Megaplay / kotocdn streams open via the open pipeline (PNG+TS → strip, plain HLS → direct, fail → other branch) instead of a one-shot strip guess.
- **Add:** Anime can use VidLink via MyAnimeList id (same embed sniff as movie/TV VidLink; MAL id from relations + Jikan, not AniList `idMal`).
- **Fix:** Anime Megaplay / VidNest use the card’s AniList id (and Megaplay also races MAL `/stream/mal/…`) — no Anikoto title match or id remap that could play the wrong show.
- **Fix:** Anime Megaplay keeps the megaplay Referer by provider identity, unwraps PNG-wrapped HLS via the local proxy when segments need it, and opens plain HLS directly.
- **Fix:** AllAnime / AllManga and Asian Drama (KissKh) keep their site Referer by provider identity when CDNs rename.
- **Fix:** Videasy opens the first working mirror quickly (no waiting on dead Neon/other servers) and keeps the player.videasy.to Referer by provider identity.
- **Fix:** VidSrc.sbs opens as soon as the first mirror works (short grace) instead of spinning until dead mirrors time out.
- **Fix:** VidFast captures the real HLS playlist from HLS.js (`Hls.loadSource`) instead of stopping on `blob:` video URLs.
- **Change:** Movie/TV template providers open with Referer from their embed host in provider config — CDN renames no longer need a per-provider patch.
- **Remove:** Anime no longer lists Vidwish as a separate source (same stack as Megaplay; `vidwish.live` redirects there).
