# 1.2.x — Dabaghin

**Status:** draft  
**Since release:** 1.2.164 (`v1.2.164` — no changelog file; tracking starts here)

User-facing changes for the next **1.2.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.2.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Player

- **Change:** While a video is buffering, the film info (title, metadata, overview) now appears on the center-left just like when paused.
- **Fix:** The mouse cursor stays visible while CHECKING SOURCES is on screen (it no longer disappears with the auto-hidden controls).
- **Fix:** Opening Source or other player menus no longer grabs the progress thumb so it follows the cursor over the menu.
- **Fix:** Clicking the player progress bar seeks again.
- **Change:** The anime Source panel’s SUB/DUB switch now sits next to the panel title as a single grouped toggle.
- **Fix:** Checking a server in the Source panel no longer reshuffles the server list.
- **Fix:** Tapping another server in the Source panel stops the previous check — only one server shows loading at a time.
- **Fix:** Leaving a movie or TV stream stops the audio — playback no longer continues after you go back.
- **Fix:** Closing the player no longer throws a seek-bar error in the debug console.

### UI

- **Change:** Settings → About no longer shows Rust engine status; Developer tools (splash preview) only in debug desktop builds.
- **Change:** The episode range selector on details now has a solid dark background, and its dropdown shows up to 8 ranges before scrolling.
- **Fix:** Quitting while Anime or Asian Drama is still loading no longer hangs the app on exit.
- **Fix:** Home and Asian Drama heroes show the synopsis again on desktop — kisskh hero cards fetch synopsis before bulk enrich, and the layout keeps at least one line when Latest sits on the backdrop.
- **Add:** Server reliability in Settings → Playback includes an Asian Drama tab (KissKH).

### Sources

- **Change:** Opening a title no longer searches torrents or loads Stremio streams until you open the Sources panel.
- **Add:** VidSrc as a separate multi-server provider using `vidsrc.win`; the existing `vsembed.su` provider is now named VSEmbed.
- **Remove:** SuperEmbed (multiembed.mov) is no longer offered as a built-in streaming provider.
- **Remove:** SmashyStream is no longer offered as a built-in streaming provider.
- **Remove:** PrimeWire is no longer offered as a built-in streaming provider.
- **Remove:** AnimeRealms is no longer offered — its watch API is gone (the old domain is parked; animerealms.com is a collectibles shop).
- **Fix:** VSEmbed CloudStream streams no longer stall on buffering — segment requests omit Referer/Origin (same as the browser).
- **Fix:** VidNest plays again — streams resolve via its API, and MovieBox CDN links omit Referer (that CDN returns 429 when Referer is set).
- **Fix:** AutoEmbed plays again — Forja opens the player page directly instead of the outer site that blocked nested playback.
- **Fix:** 2Embed plays again — uses the current `2embed.stream` embed (same as 2embed.online) and tries alternate servers when the first stalls.
- **Fix:** Template embed providers are less likely to get hijacked by popup ads while checking sources; headless extraction now blocks popup windows and main-frame ad redirects.
- **Fix:** Switching to another server mid-check no longer throws away a stream that was already found.
- **Fix:** VidLove / 111Movies no longer latch onto audio-only CDN clips before the real playlist loads.
- **Fix:** Anime AllAnime plays again — Forja accepts AllAnime’s direct MP4 links (Yt-mp4) and maps Default to those live sources (the old `--` clock hosts often return empty links now).
- **Fix:** Anime streams play again after a server shows as up — Megaplay/VidNest HLS and AllAnime MP4 CDNs now get the correct Referer (self-origin headers were failing the stream check).
- **Add:** Anime adds VidNest HiAnime and VidNest AnimePahe — AniList-native streams via the same VidNest API used for movies.
- **Fix:** Anime Miruro sources work again after Cloudflare — the WebView fallback now fetches the sources pipe separately instead of reusing the episodes response.
- **Fix:** Asian Drama no longer sticks on “Waiting for stream key…” when reopening a title — extract hard-reloads with a fresh page instead of reusing a cached kisskh shell, and cached `streamingcdn` links keep the correct kisskh Referer.
- **Fix:** Asian Drama titles marked Upcoming on kisskh no longer spin on a doomed stream check — the loading screen explains they are not published yet and shows the expected release date when available.

### Live & IPTV

- **Add:** Live Matches has a new vertical timeline view — a button next to Refresh switches between the card grid and a schedule grouped into hourly rows (same-hour streams share a line; swipe sideways for more), remembers the chosen view across app restarts, and includes an animated time ruler with Day / 12h / 6h scale buttons. Opening or reloading the timeline lands on now (not the first card); click the playhead time to jump back anytime.
- **Change:** Live Matches timeline: airing cards always show a play button (green on hover); hovering any card — live or upcoming — brings just that card in front of overlapping neighbours and highlights it in place — no scale-up.
- **Change:** The Live Matches timeline ruler now tints each day a different colour (today stays white) and shows a green NOW line at the current time.
- **Fix:** The Live Matches timeline NOW badge now sits centered on the vertical time line instead of the right edge.
- **Change:** Live Matches combines matching PPV and Streamed events into one card; the stream picker badges each source as PPV or Streamed.
- **Change:** Live Matches hides 24/7 always-on streams from All (and other sports); they only appear when you select the 24/7 category.
- **Fix:** Live match embeds on Windows no longer open as a white transparent surface.
- **Fix:** Leaving a Live Matches stream stops the audio — the embed no longer keeps playing after you go back.
- **Change:** Hovering any IPTV shelf tab (Live / Movies / Series) now shows its colour first, then expands to reveal reload; the whole tab is clickable, and switching tabs while loading no longer applies a stale catalog.
