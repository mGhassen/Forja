### TV
- **Fix:** D-pad up from Home catalog rows lands on hero Play (not stuck under the hero).
- **Fix:** Anime and Asian Drama hero Play / Details are in the D-pad graph; up from the first row focuses Play.
- **Fix:** Media details D-pad up from Play focuses the back chevron; OK on an episode selects it and moves to the play icon, OK on play starts streaming.
- **Fix:** Search overlay focuses the field on open; OK edits, right goes to clear (X), left returns, down from X goes to result cards.
- **Fix:** Stream loading overlay focuses Select providers / Cancel and D-pad navigates the server list.
- **Change:** Player progress bar: OK arms the thumb, left/right nudge, OK commits; up from the bar focuses Back. Volume stays on the remote volume keys when chrome is hidden.

### UI
- **Change:** Home Categories menu on TV highlights the focused row in white.
- **Change:** Home, Anime, and Asian Drama search icons stay gray until hover/focus.
- **Fix:** Search result cards on TV deselect when you move left to recommendations.
- **Change:** Web login success stays in the login card (loading → signed-in), without opening a separate confirmation page.
- **Change:** After Web login, Forja comes back to the front when you close the browser tab (or when it auto-closes).
- **Change:** Account → Connections uses clearer session cards with location flag, IP, and separate signed-in / last-active rows.
- **Fix:** Losing the cloud session returns to sign-in and clears account IPTV portals — no more silent Guest mode with the previous account still loaded.
- **Fix:** Home shows Stremio catalog rails again (e.g. **Cinemeta · Top**) — catalog fetches no longer die when a torrent cancels, and lean synced addons re-fetch full manifests.

### Features
- **Change:** Sign out and session loss reset account-bound local data (IPTV portals, synced prefs) before the desktop sign-in screen.

### Player
- **Add:** ExoPlayer floating menus for episodes, audio, subtitles, quality, and lean settings (speed + fit).
- **Remove:** PiP and Cast buttons on the ExoPlayer chrome.
- **Change:** Back button on movie and IPTV players sits a bit farther from the screen edge.
- **Change:** Torrent loading shows live peers, speed, and buffered size while the local engine starts.
- **Fix:** Starting a torrent no longer stutters the UI — engine job waits run off the main thread.
- **Fix:** Android ExoPlayer plays HLS and DASH streams again (missing Media3 modules).

### Live & IPTV
- **Change:** Deal portals is account-gated (admin feature flag) — hidden until enabled; still needs catalog credits to spend.
- **Fix:** Account feature flags and IPTV credits refresh when you open IPTV or bring the app back — no restart needed after admin toggles.
- **Change:** After search or returning from the player, the selected IPTV category scrolls into view as the 4th row instead of jumping to the top.
