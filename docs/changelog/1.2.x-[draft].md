### Features
- **Fix:** New profiles start with default settings instead of copying the previous profile.
- **Fix:** Profile settings never flash another profile’s data while loading or switching.
- **Fix:** After Web login, the portal hands the session to the app and leaves the browser signed out so the two no longer kick each other out.
- **Add:** Optional authenticator (TOTP) on the web Account page; sign-in asks for a code when enabled (app + portal).
- **Add:** Optional Google (and other) OAuth on web login when configured.
- **Change:** Signing out of the web portal clears this browser only; Account → Sessions can sign out all devices.
- **Change:** Admin ops login uses the same auth module as the portal (MFA + optional OAuth).

### UI
- **Change:** The update dialog shows changelogs for each version since yours (left list, up to 16) and links to the full web changelog.
- **Fix:** App updates check and download installers from the release CDN (R2).
- **Fix:** Built-in Nuvio scrapers show under Settings → Nuvio addons (same list as Sources), with toggles that stick.

### Player
- **Fix:** Progress thumb stays on the playhead — hover preview no longer seeks (or sticks to the cursor over pause/chrome); click the bar to seek.
- **Fix:** Anime Auto keeps trying the next server after a stream that looks live but won’t decode (instead of stopping on the first dead hit).

### Sources
- **Change:** In Sources → Nuvio, tapping a scraper loads it immediately (no Load next button); tap again to deselect and clear its rows; extra scrapers still load one at a time. Your scraper selection is remembered on this device.
- **Fix:** Anime HLS probes reject playlists whose media segments are PNG ads (nekostream / vivibebe / ibyteimg) so Sources no longer show green then fail on open.

### Live & IPTV
- **Fix:** Shared IPTV catalog scrape again pulls portals from Reddit paste links (pool Deal inventory).
- **Fix:** IPTV portal status dot checks when you select a portal, keeps the result for a few minutes, and re-checks on shelf reload or when that cache expires — each check also refreshes expiry and connection seats.
- **Change:** IPTV catalog categories and EPG channel names stay muted until hovered or selected (then bold white).
- **Remove:** IPTV catalog no longer shows an **All** category — opens on the first portal group.
- **Add:** Pin Live catalog groups (hover) to keep them under Already watched — remembered per portal on this device.
- **Change:** IPTV Sort panel drops the title/close chrome; the channel list section is labeled **Channels**.
