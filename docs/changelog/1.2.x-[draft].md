### UI
- **Fix:** Closing the app on Windows no longer freezes on the window — quit hides immediately and finishes teardown without hanging on media shutdown.
- **Fix:** The update screen fills the window height — header and Install stay pinned while only the changelog scrolls, and the logo/spacing shrink on shorter windows.

### Live & IPTV
- **Change:** Live Matches timeline zoom now uses a compact 4-tab control (Day / 12h / 6h / 3h), adding a tighter 3-hour view.
- **Fix:** Switching sport categories on the Live Matches timeline keeps the playhead on now instead of jumping to unrelated dates.
- **Change:** Opening the IPTV portals panel scrolls straight to the active portal, and adding a portal via share code selects it and scrolls to it in the list.
