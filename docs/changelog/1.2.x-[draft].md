# 1.2.x — Dabaghin

**Status:** draft  
**Since release:** 1.2.192 (`v1.2.192`)

User-facing changes for the next **1.2.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.2.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Player
- **Fix:** Switching torrent episodes no longer stops the torrent engine when the previous player closes — playback keeps the same swarm.
- **Fix:** Torrent / Stremio sessions no longer route localhost streams through the webstreaming extract list (which skipped them as unplayable).
- **Fix:** Torrent episodes no longer jump straight to “finished” / auto-next when mpv briefly reports a tiny duration while buffering, or when a local torrent hits early EOF after reading the real episode length (before any video frame).
- **Fix:** Next episode on a torrent season pack opens the localhost stream instead of treating it as a dead web extract.
- **Fix:** Next/previous episode during torrent playback reuses the season pack (or searches torrents) instead of only trying webstreaming and failing.
- **Fix:** Leaving the desktop player (Escape / Back) no longer crashes when exit is pressed twice while playback is stopping.
- **Fix:** Escaping the player before playback starts (anime, Asian Drama, or movies) returns to details — not a stuck black or loading screen.
- **Fix:** Playing a Stremio or Nuvio stream shows the Sources (torrent/Stremio/Nuvio) panel instead of a one-item `stremio_direct` server picker.
- **Add:** Player Sources includes the **Nuvio** tab with scraper filters, matching media details.
- **Change:** Sources opens on **Torrents** when available (else Nuvio, then Stremio) — there is no **All** kind; providers and scrapers live under **Filters → Providers**.
- **Fix:** Reloading a server in the Source panel after Play from cache re-fetches streams instead of silently reusing the cached links.
- **Change:** Sources (details and player) loads only the open category, keeps results for about 30 minutes, and adds a reload on each Torrents / Stremio / Nuvio chip. Closing the panel stops any still-running category fetch.
- **Fix:** Stremio/Torrentio magnets are no longer opened as a local file (which failed with “file name too long”); picking a torrent in Sources fails quietly in the status list instead of crashing the player.

### UI
- **Fix:** Server rows on the stream loading screen highlight and show a click cursor on hover so they look tappable.
- **Fix:** Closing the app on Windows no longer freezes on the window — quit hides immediately and finishes teardown without hanging on media shutdown.
- **Fix:** The update screen fills the window height — header and Install stay pinned while only the changelog scrolls, and the logo/spacing shrink on shorter windows.
- **Fix:** Home Films / TV Shows / Categories menu slides away again when you scroll past the hero (broken after Featured This Month extended the backdrop).

### Live & IPTV
- **Fix:** Opening an IPTV channel no longer throws a framework error about rebuilding during build.
- **Change:** Live Matches timeline zoom now uses a compact 4-tab control (Day / 12h / 6h / 3h), adding a tighter 3-hour view.
- **Fix:** Switching sport categories on the Live Matches timeline keeps the playhead on now instead of jumping to unrelated dates.
- **Fix:** Streamed always-on channels (Willow Cricket, Tennis Channel, Rally TV, …) appear under the **24/7** sport chip instead of their sport (Cricket / Tennis / …).
- **Fix:** PPV **24/7** channels stay playable (LIVE) even when their start/end times are stale.
- **Change:** Opening the IPTV portals panel scrolls straight to the active portal; scraping, share-code add, and manual add scroll the list to each newly found or added server.
- **Add:** Settings → Data & backup includes **IPTV portal cache** to clear live-channel health checks and channel scan results without removing portals.

### Sources
- **Fix:** Closing Sources no longer crashes when Filters tears down (`setState` after dispose).
- **Fix:** Sources row taps work again while Filters is open — Filters no longer sits over the Torrents / Stremio / Nuvio list and swallows clicks.
- **Change:** Nuvio **Filters → Providers** starts with no scrapers selected — pick the ones you want, then **Load next provider** runs them one at a time.
- **Fix:** Picking a Stremio or Torrents row no longer cancels the magnet resolve when Sources closes — playback can start instead of failing quietly.
- **Fix:** Stremio/Torrentio streams use the addon’s file index so the right episode in a season pack starts.
- **Fix:** Opening Sources with Filters no longer hits a red-screen rebuild error when the panel updates.
- **Change:** Opening **Sources** leaves **Filters** closed until you tap the tune control (details and player); closing Sources still dismisses Filters.
- **Fix:** Green Play no longer reopens Stremio when a previous Stremio Direct session polluted the webstreaming resume cache — it only reuses real web extractors.
- **Change:** Sources shows every fetched Torrent/Stremio row; Nuvio runs selected scrapers one at a time and **Load next provider** fetches one more.
- **Fix:** Closing Sources (or leaving a title) stops Nuvio scrapers — they no longer keep fetching after the panel is gone.
- **Change:** Asian Drama first checks KissKH mirror URLs in parallel (dead hosts show DOWN immediately), then opens a browser only for healthy mirrors — listed in Settings → Playback and the player Sources panel.
- **Fix:** Asian Drama mirror URL checks no longer freeze on CHECKING with no progress — a hung mirror no longer blocks auto-picking a working server.
- **Fix:** Asian Drama skips a silent KissKH mirror after one retry instead of waiting the full timeout before trying the next.
- **Fix:** Tapping a KissKH mirror during “Checking mirror URLs…” switches to that server immediately instead of ignoring the tap.
- **Fix:** Checking Videasy now lists every responsive named mirror collected during its bounded check instead of falling back to a single stream.
- **Fix:** Installed Stremio addons (and other settings) live in one store — old prefs copies are merged in once and removed so restarts cannot wipe them.

### Features
- **Change:** Settings, sources, addons, and related preferences now persist in the app settings file across restarts; API keys and login tokens stay in secure device storage.
- **Change:** On details, tapping an episode only selects it — use **Play** / **Resume** (or Sources) to start watching.

### TV
- **Change:** Opening the app on Android TV focuses the Home nav rail item first (not the hero Play button).
