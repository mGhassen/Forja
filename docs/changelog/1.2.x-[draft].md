### Live & IPTV
- **Fix:** Live match PPV and Streamed embeds no longer open as a white screen on desktop (catalog wrapper loads correctly).
- **Change:** IPTV portal end dates near expiry use orange instead of yellow, so they no longer look like favorited portals.
- **Fix:** Live IPTV on older Android TV (Android 7 and similar) is less choppy - deeper live buffer and a lower quality ceiling when the feed has adaptive variants.
- **Fix:** On Android TV IPTV, the top-right Player button (and source / stats) shows green D-pad focus like the other player controls.
- **Fix:** IPTV live channel cards on Android TV no longer show a gray box behind the logo.
- **Remove:** Picture-in-Picture from the IPTV player on Android TV.
- **Fix:** IPTV player controls on Android TV stay visible while you D-pad - they hide only after you stop.
- **Fix:** On Android TV IPTV catalog, Left from any category row returns to the nav rail (not only the first category).
- **Change:** IPTV Live / Movies / Series shelf labels go bold on hover or D-pad focus (not only when selected).

### Features
- **Add:** Link your Forja account on Android TV with a code or QR - approve on the web at `/connect`.
- **Change:** After sign-in, picking a profile uses the avatar profile splash (same as switching mid-session), then opens the app - no second logo boot splash.

### TV
- **Fix:** Android TV remote Back never quits to the launcher - it only pops screens or moves focus (nav ↔ page). The system Back path is consumed so Flutter cannot finish the Activity.
- **Change:** Android TV Who’s watching and the profile splash use a tighter layout (smaller avatars and title; splash avatar + name + status stacked in the center) so they fit leanback screens.

### UI
- **Fix:** Home and Asian Drama posters load again on Android 7 (Let's Encrypt trust on old system CA stores).
- **Change:** Android TV sign-in opens on a centered welcome over fractal glass, then a code/QR connect screen.
- **Change:** Android TV welcome is a single centered stack (logo, copy, Sign in, guest) - no two-column layout.
- **Change:** Android TV welcome Sign in is a solid brand-green pill (no outlined row).
- **Change:** Android TV welcome and link copy sit on a soft dark shadow (no frosted glass panel) so the fractal stays sharp.
- **Change:** Android TV link (code/QR) screen no longer offers Continue as guest - use Back to the welcome screen.
- **Fix:** Android TV keeps your signed-in session across app restarts and opens on your last profile.
- **Fix:** Cold start on Android TV / desktop no longer fails cloud sync with an expired token - the app force-refreshes the session, re-applies discarded refresh tokens, and retries profile load once if the server still says the JWT expired.
- **Fix:** After long idle on desktop, the rail no longer sticks on Guest while you’re still signed in - profiles reload with a real error and Retry if the network fails.
- **Fix:** Who’s watching profile tiles are no longer clipped at the bottom on short TV screens.
- **Fix:** Who’s watching supports D-pad focus - profiles, Manage profiles, and Use another account.
- **Fix:** Settings on Android TV supports D-pad - category list, detail rows, and back to the nav rail.
- **Fix:** Settings and subtitle sliders respond to Left/Right as soon as they’re focused (no OK first).
- **Fix:** Who’s watching and Profile & account show an error with Retry when profiles fail to load (no infinite spinner or fake “create a profile” when the fetch failed).
- **Fix:** Check for Updates only says you’re on the latest when the check succeeds - a failed check shows an error instead.
