### UI
- **Change:** Web login success stays in the login card (loading → signed-in), without opening a separate confirmation page.
- **Change:** After Web login, Forja comes back to the front when you close the browser tab (or when it auto-closes).
- **Change:** Account → Connections uses clearer session cards with location flag, IP, and separate signed-in / last-active rows.
- **Fix:** Losing the cloud session returns to sign-in and clears account IPTV portals — no more silent Guest mode with the previous account still loaded.

### Features
- **Change:** Sign out and session loss reset account-bound local data (IPTV portals, synced prefs) before the desktop sign-in screen.

### Player
- **Change:** Back button on movie and IPTV players sits a bit farther from the screen edge.
- **Change:** Torrent loading shows live peers, speed, and buffered size while the local engine starts.
- **Fix:** Starting a torrent no longer stutters the UI — engine job waits run off the main thread.

### Live & IPTV
- **Change:** Deal portals is account-gated (admin feature flag) — hidden until enabled; still needs catalog credits to spend.
- **Fix:** Account feature flags and IPTV credits refresh when you open IPTV or bring the app back — no restart needed after admin toggles.
- **Change:** After search or returning from the player, the selected IPTV category scrolls into view as the 4th row instead of jumping to the top.
