# 1.2.x — Dabaghin

**Status:** draft  
**Since release:** 1.2.308 (`v1.2.308`)

User-facing changes for the next **1.2.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.2.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

---

### Features
- **Add:** Settings → Playback → Simple resolve (experimental) — one provider at a time, probe streams, then open the player once (old race path unchanged when off).
- **Change:** Each Forja account can have at most 5 profiles (Add profile hides at the limit).
- **Fix:** Desktop Web login finishes when you are already signed in on the portal (stale browser session no longer blocks handoff).
- **Change:** After desktop Web login, the portal shows a simple centered confirmation with a 10-second countdown (or Close tab) instead of closing immediately.
- **Change:** The launch update prompt appears before sign-in (and before the splash), not after Home loads.
- **Change:** Picking or switching a profile always uses the avatar profile splash — never the logo boot splash.
- **Change:** Startup only loads services your profile needs (tabs + Direct torrent / Stremio / Webstreaming) — an IPTV-only profile no longer pulls movie catalogs or starts the torrent engine.

### UI
- **Fix:** Splash bottom status shows live boot steps again (proxy, WebStreamr, home feed, retries) and rotates hold lines instead of freezing on “Opening Home…”.
- **Change:** The desktop rail profile avatar opens Settings → Profile & account instead of Who’s watching.
- **Change:** Settings only shows categories and rows that match your tabs and play sources — an IPTV/Live-only profile hides movie Settings (Sources, WebStreamr, Debrid, Connected services, Lists); play-source tiles stay gated the same way; IPTV EPG/portals only when the IPTV tab is on.
- **Change:** The Settings category formerly called Navigation is now Features (same tab visibility, order, and default menu).

### Sources
- **Fix:** Multi-server providers (VidSrc.sbs, Videasy, VidNest, chip-rotate embeds) list every responsive mirror — no first-hit drop or grace cutoff.
- **Fix:** Server reliability Score never goes below 0 (fail prefixes still reduce the total).
- **Fix:** Anime Megaplay streams on the nekostream CDN keep the correct megaplay Referer (no more false 403 / dead Source rows).
- **Add:** Megaplay (and Vidwish) can play from AniList id via `/stream/ani/…` when Anikoto catalog match is missing.
- **Add:** Stream provider hosts, embed path templates, anime APIs/mirrors, and CDN Referer rules can be updated from Forja’s cloud config without waiting for an app release (falls back to built-in defaults offline).
- **Fix:** Miruro Cloudflare unlock no longer treats a blank WebView page as cleared, and no longer starts the pipe on a failed challenge load.
- **Change:** Anime play stops at the first working stream — no background scan of the rest while you watch; other servers stay for manual Source picks or if that stream dies.

### Player
- **Fix:** Progress thumb no longer stays magnetized to the cursor when hovering player chrome (Quality, Settings, center play / ±10, or the top bar) — especially right after a stream starts.
- **Fix:** Quitting on macOS (⌘Q or the red close button) no longer crashes after playback.
- **Fix:** Once a stream is playing, Forja no longer keeps auto-probing other streams or scanning more providers in the background.
- **Fix:** Online subtitle search no longer crashes when a Stremio addon has a missing manifest.
- **Fix:** The Source panel no longer jumps streams to the top when you play or check one — list order stays put.
- **Fix:** macOS picture-in-picture stays on every Space (and can float over other fullscreen apps) instead of sticking to one desktop.

### Live & IPTV
- **Change:** Live Matches opens in timeline view by default (card view still available; last choice is remembered).
- **Change:** M3U playlists stay on this device — they are no longer synced to your Forja account.
- **Add:** Account → IPTV on the web shows a VIP Activated banner when Find Portals scrape is unlocked on your account.
- **Add:** IPTV Deal — spend a catalog credit for up to 5 alive portals from the shared pool (region picker); credit balance on Portals and Account → IPTV.
- **Fix:** Find Portals scrape also reads tabular host/user/pass dumps and unicode-labeled cards; Stalker/MAC-only posts are skipped.
- **Add:** Live IPTV catalog sort — order categories and channels by playlist order, A–Z, or Z–A (remembered on this device).
