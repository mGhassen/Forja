# 1.2.x — Dabaghin

**Status:** draft  
**Since release:** 1.2.406 (`v1.2.406`)

User-facing changes for the next **1.2.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.2.x-[draft].md` starts.

Use the [thematic groups](../../.cursor/rules/changelog.mdc#thematic-groups-forja) below — **add a `### Group` heading only when that group has bullets**; never leave empty group headers. Every bullet starts with `**Add:**` · `**Change:**` · `**Fix:**` · `**Remove:**`.

### Features
- **Add:** Mark episodes watched or unwatched on Anime and Asian Drama details (right-click an episode card; local checkmarks only).
- **Fix:** macOS no longer asks for your login Keychain password on every app update.
- **Fix:** Download page keeps every platform’s latest installer when a release ships only some platforms (each row shows that platform’s version and notes).

### UI
- **Change:** Clicking an episode on details no longer jumps that card to the start of the row — it only scrolls if the card was off-screen.
- **Change:** Details Play and action buttons sit directly under the synopsis instead of at the bottom of the hero.
- **Fix:** Series and anime details show a 3-line synopsis with Read More (episode rows sit a bit lower so the hero has room).
- **Fix:** Series Production Info sits flush above seasons instead of floating mid-hero.
- **Change:** Production Info last row fills the card bottom (no empty footer strip).
- **Change:** Anime and Asian Drama details use the same Production Info card as movies.
- **Fix:** Production Info clips with rounded top and bottom instead of cutting the card square.
- **Remove:** Production Info card no longer shows a “Production Info” heading — facts start at the top of the card.

### Player
- **Change:** Details trash next to Resume clears watch progress and that title’s cached stream provider (next Play re-resolves).
- **Change:** Multi-stream servers list every stream first, then check them one by one in the Source panel (`Checking 2/5…` on the server row).
- **Fix:** Stream open uses a mind-tree middleware — PNG shells strip, plain HLS plays direct, and a failed branch re-decides the next technique instead of one static guess.
- **Fix:** Source panel keeps the catalog stream row while PNG-strip plays via the local proxy — checking another provider no longer hides the playing Megaplay stream or leaves it stuck on a Checking spinner.
- **Fix:** Sources reload and stream check always re-fetch/probe — they no longer reuse a cached dead URL or skip check because the player looked “already playing.”
- **Fix:** Failed stream opens clear the cached extract and show an error instead of silently ignoring the failure.
- **Change:** Trailer player matches main player chrome — auto-hiding controls, horizontal volume bar, fullscreen button + double-click, quality/speed chips, audio/subtitle list rows, a bottom-right **More videos** card with trailer thumbnails (opens the trailers list), and no separate trailers icon in the transport row.
- **Fix:** Trailer video uses contain fit (no cover zoom) and double-click fullscreen works through the WebView.
- **Fix:** Trailer player opens fullscreen over the shell (nav rail hidden) like the main player.
- **Change:** Audio and subtitle menus show each language in its native script (हिन्दी, தமிழ், Español…).
- **Change:** Quality menu hides Auto while ABR is on and highlights the resolution currently playing.
- **Change:** Subtitles language rows no longer show a leading translate icon.
- **Fix:** Dead anime/CDN opens no longer leave the seek bar pinned at the end like a finished episode.
- **Fix:** HLS Auto starts on the highest quality instead of the lowest rung.
- **Fix:** Checking a stream provider in the background no longer plays that embed’s audio over the video you’re already watching.
- **Fix:** Embed/CDN streams keep the provider’s player Referer by identity (Vidzee and other template hosts no longer 403 into a silent dead play when the CDN renames).
- **Fix:** Play opens the loading screen immediately — including cache hits — instead of sitting idle while history/cache probe finishes.

### Sources
- **Fix:** Megaplay / kotocdn streams open via the open mind-tree (PNG → strip, plain HLS → direct, fail → other branch) instead of a one-shot strip guess.
- **Add:** Anime can use VidLink via MyAnimeList id (same embed sniff as movie/TV VidLink; skipped when AniList has no MAL mapping).
- **Fix:** Anime Megaplay keeps the megaplay Referer by provider identity, unwraps PNG-wrapped HLS via the local proxy when segments need it, and opens plain HLS directly.
- **Fix:** AllAnime / AllManga and Asian Drama (KissKh) keep their site Referer by provider identity when CDNs rename.
- **Fix:** Videasy opens the first working mirror quickly (no waiting on dead Neon/other servers) and keeps the player.videasy.to Referer by provider identity.
- **Fix:** VidSrc.sbs opens as soon as the first mirror works (short grace) instead of spinning until dead mirrors time out.
- **Fix:** VidFast captures the real HLS playlist from HLS.js (`Hls.loadSource`) instead of stopping on `blob:` video URLs.
- **Change:** Movie/TV template providers open with Referer from their embed host in provider config — CDN renames no longer need a per-provider patch.
- **Remove:** Anime no longer lists Vidwish as a separate source (same stack as Megaplay; `vidwish.live` redirects there).

### Live & IPTV
- **Fix:** Closing the app no longer crashes when IPTV was still refreshing portals.
- **Fix:** Switching profiles with an empty local IPTV cache no longer deletes your cloud portals (cloud is master; local is cache only).
