### Features
- **Add:** Shahid hub and stream provider — browse Shahid catalog; sign in under Settings → Connected services; Android plays Widevine titles with ExoPlayer.
- **Add:** Packs can add their own Connected services Login / Logout (session auth) without hardcoding the service in the app.

### Player
- **Add:** Android ExoPlayer Widevine license support for streams that include a DRM license URL.

### Sources
- **Fix:** Shahid hub catalog loads again (top charts + search) after Shahid’s old filter API started returning 400.
- **Fix:** Shahid home rails show titles again (feed item shape + rail id param matched the kit host).
- **Fix:** Shahid stream resolve uses the current signed DRM license request (device headers, no broken schema) so Android Exo can get a Widevine row.
