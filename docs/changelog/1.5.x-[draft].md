# 1.5.x — Berka

**Status:** draft  
**Since release:** 1.5.0 (`v1.5.0`)

User-facing changes for the next **1.5.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.5.x-[draft].md` starts.

### Live & IPTV
- **Fix:** Turning the IPTV addon back on restores the programme guide (EPG) — it no longer stays stuck off after you disable and re-enable IPTV.
- **Fix:** Live Sports schedule shows Streamed (and other catalog) matches again — opening the tab no longer leaves an empty list while catalogs still finish in the background.
- **Fix:** IPTV portal and live channel status dots stop painting everything red on working providers (slower panels and “re-check all” no longer false-fail).
- **Fix:** Android TV live IPTV (Xtream/M3U) stays watchable through CDN reconnects — overlap skip matches stream bitrate, keeps a deeper local cushion, and avoids soft-reconnect thrash mid-gap (MediaKit and ExoPlayer).
- **Change:** PPV schedule and streams try more mirror APIs when the main ppv.st host is down.

### Features
- **Change:** First-run Official packs shows a checklist with Recommended already selected (and focus on Install) instead of downloading every ForjaHQ pack.

### UI
- **Fix:** Opening the app lands on your starred default tab (e.g. Home) instead of Settings when packs are still loading or a signed-in session restores in the background.
- **Fix:** ExoPlayer subtitle language list shows track names / sources (e.g. wyzie) instead of raw `.vtt` URLs.

### TV
- **Change:** Community Packs card shows the catalog URL so you can open it on your phone.
- **Change:** In the player, remote **Back** / **Exit** match desktop Escape — hide controls first, then arm with a “Press again to exit” hint, then leave.
- **Fix:** Subtitles dialog on Android TV opens with focus on the **X** close control (D-pad reachable) instead of **Off**.

### Sources
- **Fix:** Home loads again on fresh installs — the TMDB catalog key is baked into release builds (Android TV no longer toasts that the API key is missing).
- **Fix:** Home hub uses a TMDB-compatible catalog proxy (no API key required in the pack) so Home works when the app build forgot the dart-define (pack **1.0.20**).
