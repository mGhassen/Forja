### Live & IPTV
- **Change:** Shahid Connected services Login opens Shahid’s website so you can sign in with Google (or email); Forja imports the session when you finish.

### Features
- **Add:** Shahid hub and stream provider — browse Shahid catalog; sign in under Settings → Connected services; Android plays Widevine titles with ExoPlayer.
- **Add:** Packs can add their own Connected services Login / Logout (session auth) without hardcoding the service in the app.

### Player
- **Add:** Android ExoPlayer Widevine license support for streams that include a DRM license URL.
- **Fix:** Shahid Widevine titles no longer open as a green/gray MediaKit screen on desktop — toast that Android Exo is required instead.

### UI
- **Change:** On Mac, confirming an update installs into Forja and relaunches — no opening the DMG in Finder.
- **Add:** Download page can show other recent installer versions per platform (last few kept on the CDN).

### Sources
- **Fix:** Shahid hub catalog loads again (top charts + search) after Shahid’s old filter API started returning 400.
- **Fix:** Shahid home rails show titles again (feed item shape + rail id param matched the kit host).
- **Fix:** Shahid DRM license resolve works again (Mac web device headers + signed request) so Android Exo can get a Widevine row.
