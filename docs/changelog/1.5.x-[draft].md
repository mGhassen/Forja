### Features
- **Remove:** In-app Cloudflare Turnstile — sign-in uses web portal / QR device link (Turnstile stays on the web login page only).
- **Change:** Installing **ForjaHQ IPTV** adds the IPTV hub tab (live portals + movie/series details in one pack). **Addons → IPTV** (portals and live player prefs) appears only while that pack is installed.
