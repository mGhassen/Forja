# 1.5.x — Berka

**Status:** draft  
**Since release:** 1.5.0 (`v1.5.0`)

User-facing changes for the next **1.5.x** patch. Update on every push; edit or remove bullets when later pushes correct earlier work. On ship, this file becomes `done/X.Y.Z-[released].md` (exact patch from the release tag) and a fresh `1.5.x-[draft].md` starts.

### Live & IPTV
- **Change:** Live Sports **Schedule** chip defaults to **Airing** (in-play and 24/7) instead of the full 24h window.
- **Fix:** Changing Live Sports **Schedule** (Airing / Upcoming / horizon) refilters the loaded list in place — it no longer re-scrapes every catalog.
- **Fix:** Live Sports **Catalog** chip shows **All** or the selected catalog name (mirrors Schedule), not a static “Catalog” label.
- **Fix:** Live Sports **Providers** no longer lists TV-guide catalogs (Live Soccer TV, LiveOnSat, …) as stream sources — those stay schedule / channel hints only; streams come from resolve packs.
- **Fix:** Live Sports **Providers** only lists real stream links (same as the site) — matches still appear on the schedule when a catalog has no links yet; no fake “preparing” provider row.
- **Change:** Live Sports schedule catalogs are schedule-only — no embed URLs in the match list; Providers unlocks through live resolve packs.
- **Fix:** Streamed no longer opens the player on empty/dead fixtures — unlock must return a real playable playlist (same as the website showing no stream links).
- **Fix:** Live Sports player shows the bottom **Source** swap control again when Providers listed more than one stream — switching mirrors mid-match works like Forja Sports / IPTV.
- **Fix:** Turning the IPTV addon back on restores the programme guide (EPG) — it no longer stays stuck off after you disable and re-enable IPTV.
- **Fix:** Live Sports schedule shows Streamed (and other catalog) matches again — opening the tab no longer leaves an empty list while catalogs still finish in the background.
- **Fix:** IPTV portal and live channel status dots stop painting everything red on working providers (slower panels and “re-check all” no longer false-fail).
- **Fix:** Android TV live IPTV (Xtream/M3U) on ExoPlayer no longer seeks itself broken on the local continuity proxy — keeps a deep buffer without live-edge offset, and CDN reconnect no longer restarts when the player briefly reopens the loopback socket.
- **Change:** PPV schedule and streams try more mirror APIs when the main ppv.st host is down.
- **Fix:** On Android TV, holding ↑/↓ through IPTV categories keeps the green focus on the real focused row (no delayed second highlight when stride jumps 2–3 groups).

### Features
- **Change:** First-run Official packs shows a checklist with Recommended already selected (and focus on Install) instead of downloading every ForjaHQ pack.
- **Change:** Official / Community pack lists follow the published plugin catalog (and the Best experience bundle) from Forja admin — pack files still download from GitHub.

### UI
- **Fix:** Opening the app lands on your starred default tab (e.g. Home) instead of Settings when packs are still loading or a signed-in session restores in the background.
- **Fix:** ExoPlayer subtitle language list shows track names / sources (e.g. wyzie) instead of raw `.vtt` URLs.
- **Fix:** Player Episodes panel shows each episode’s air date again (orange when not yet aired) for Home, Anime, and Asian Drama.

### TV
- **Change:** Android TV no longer warms Chromium WebView at cold start — first Live unlock / trailer / captcha pays that cost instead.
- **Change:** Community Packs card shows the catalog URL so you can open it on your phone.
- **Change:** In the player, remote **Back** / **Exit** match desktop Escape — hide controls first, then arm with a “Press again to exit” hint, then leave.
- **Change:** Player floating menus on Android TV match desktop — compact translucent panels anchored near the seek bar (not a large centered opaque card).
- **Change:** When player chrome is hidden, D-pad **←/→** show controls and focus Play (no ±10s seek) — scrub on the progress bar after OK, or use Rewind / Fast-forward.
- **Fix:** Subtitles dialog on Android TV opens with focus on the **X** close control (D-pad reachable) instead of **Off**.
- **Fix:** Toasts with an action (Refresh, View, Install, …) on Android TV focus the button immediately; D-pad or Back returns focus to where you were.
- **Fix:** On the stream loading screen, D-pad **↑** from Cancel / servers lands on the last source in the list.
- **Fix:** In the movie / Exo player on Android TV, D-pad **↓** from the top **Player** button reaches the progress bar / transport (and **←** returns to Back).

### Player
- **Fix:** Forja Auto loading server list uses green hover / D-pad focus, and tapping a server checks it first (then continues the race if it misses).
- **Fix:** ExoPlayer on Android TV no longer auto-picks empty CEA-608 “Track 1” captions — preferred language uses real in-stream or online (Wyzie/Levrx) subs so dialogue shows again.
- **Fix:** On Android TV, switching MediaKit → ExoPlayer no longer leaves the video zoomed bigger than the screen.

### Sources
- **Fix:** Home loads again on fresh installs — the TMDB catalog key is baked into release builds (Android TV no longer toasts that the API key is missing).
- **Fix:** Home hub uses a TMDB-compatible catalog proxy (no API key required in the pack) so Home works when the app build forgot the dart-define (pack **1.0.20**).
- **Fix:** Home TV episode lists include air dates from TMDB (pack **1.0.21**) so details and the player Episodes panel can show them.
- **Fix:** Megaplay and HiAnime anime streams work again after their API started encrypting source URLs.
