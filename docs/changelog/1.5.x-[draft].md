### TV
- **Add:** Hub packs can name D-pad **←/→** between widgets (`focusLeft` / `focusRight`) — same as ↑/↓. Live Sports → from a selected match still lands on Providers.

### Live & IPTV
- **Fix:** IPTV VLC no longer freezes every few seconds on progressive MPEG-TS (Xtream) — live clock/cache tuned; software decode when the stream is raw `.ts`.
- **Add:** IPTV live HLS can use **AVPlayer on Mac** and **VLC on Windows** (install VLC for the Windows path) — MediaKit stays available; MPEG-TS still uses MediaKit.
- **Fix:** HLS IPTV (XUMO / CBS News) opens a single quality playlist instead of making MediaKit probe every ABR rung — same feeds Lume plays with AVPlayer.
- **Fix:** HLS IPTV no longer loops “reconnect at End of file” on the playlist — ffmpeg stops treating short `.m3u8` responses as a broken progressive download.
- **Fix:** macOS/Linux HLS IPTV (M3U `.m3u8`, CBS News, XUMO) uses hardware decode — no more black silent player from software TextureSW.
- **Fix:** HLS live channels (CBS News / M3U `.m3u8`) no longer get killed mid-start by the empty-cache reconnect timer — ABR can finish probing before recovery runs.
- **Fix:** M3U live channels that are HLS (`.m3u8`, e.g. XUMO playlists) play directly — they no longer hang forever in the MPEG-TS continuity proxy reconnect loop.
- **Fix:** Live Sports Catalog → All reuses schedules you already loaded per catalog — no full re-scrape; only missing packs fetch, and Refresh shows **Updated … ago**.
- **Change:** Live Sports schedule lists live / airing events first (then viewers, then kickoff) for All and every catalog chip.
- **Fix:** Live Sports Streamed viewer counts show again — match API dropped them; catalog sums viewers from stream mirrors for live / 24/7 / in-play cards.
- **Fix:** Live Sports Sports Streams (Stremio) match fixtures show again — kickoff times like `10 Sep 2026 · 16:45 UTC` parse correctly so schedule filters keep the events.
- **Fix:** Live Sports Flix-Streams multi-day events (US Open, Solheim Cup, …) stay on the board while the title date range is still active.
- **Fix:** Live Sports TimStreams catalog fills from sports Live TV channels when the site Events board is empty.
- **Fix:** Live Sports Streamed cards show team badges and posters again — match rows keep Streamed team badges / absolute poster URLs.
- **Fix:** Live Sports MobiKora schedule shows matches again — site cards link to `/` now, so fixtures use a stable id instead of being dropped.
- **Fix:** Live Sports ESPN catalog loads the week ahead — no more empty board on days with no games (was pinned to today only).
- **Fix:** Live Sports match details Providers stay two-column on wide even with one stream — left column fills first, then the right.
- **Fix:** Live Sports schedule loading hides Refresh and shows a top-right progress chip with the scrape label, and paints a list/card skeleton instead of a center spinner.
- **Fix:** Live Sports list loading skeleton uses soft grey placeholders instead of harsh white bars.
- **Fix:** Live Sports Providers no longer shows empty when the schedule has matches — fixture soft-match fields reach resolve packs again, discover lists embed mirrors (unlock still on play), Streamed owns its goat slots, and Streamic loads without a script crash.
- **Change:** Live Sports **Live TV** matching is driven by the hub pack (`liveTv` → portal channel search) — the app only provides the search bridge; Providers no longer kicks off IPTV matching, and search skips when the app is backgrounded.
- **Fix:** Live Sports Providers lists mirrors without unlocking — goat / gasm / sportsembed unlock only runs when you tap play (Streamed, PPV, Streamic, TimStreams, StreamFree, MobiKora, WatchFooty).
- **Fix:** Live Sports match details show Reload next to the Providers spinner — clears the list and rediscovers (skips the warm Providers / Live TV cache).
- **Change:** Live Sports schedule and streams ship as one pack — Catalog / Providers toggles per site in Settings.
- **Change:** Live stream unlock is pack-driven — the app only runs an opaque unlock service (no built-in goat/gasm site list).
- **Change:** Live Sports Providers paints stream rows as each pack finds the fixture — a spinner stays on the far right of the tab row until every pack finishes.
- **Fix:** Live Sports Catalog chip no longer overflows the top bar when a Stremio addon URL is selected before its name loads.
- **Fix:** TimStreams schedule and streams work again after the site moved to timst.cfd (including epiembeds unlock).
- **Fix:** Live Sports Catalog chip switches (All → PPV, etc.) reuse the already-loaded schedule — no re-scrape until Refresh.
- **Fix:** Live Sports match details Live TV search keeps full size (no FittedBox shrink), 16px gap from the pill, and a white hover/focus fill.
- **Change:** Live Sports is one hub — switch list/cards with the top-bar icon (left of Portals) and **Side panel** / **Detail page** under Addons → Live Sports Setup.
- **Remove:** The separate Live Sports Cards pack — existing Cards installs migrate to the merged hub (cards layout + detail open).
- **Fix:** On Android TV, IPTV Movies/Series on MediaKit no longer force-close the app on 4K open (leaner buffer; no refresh-rate switch on movies).
- **Fix:** Live Sports no longer leaves **Preparing playback…** stuck over a playing stream, and soft reconnects no longer re-unlock the same mirror on every brief buffer.
- **Add:** Live Sports Providers / Live TV stream lists show a thin scrollbar when there are many rows (same look as the match schedule).
- **Fix:** Live Sports source panel Reload and Close work with the D-pad on TV.
- **Fix:** IPTV Stream stats scrolls when there are more rows than fit (mouse wheel / scrollbar; on Android TV ↓ from Close then ↑/↓).
- **Fix:** IPTV portals that work on Mac/Android TV no longer show unreachable on Windows when DNS64 returns broken IPv6 — portal HTTP resolves A records (IPv4) instead of filtering empty AAAA-only lists.
- **Fix:** On Android TV IPTV Movies/Series, after switching Live/Movies/Series shelves, ↑ from the catalog reaches the shelf tabs or Portals again (channel place resets per shelf).
- **Fix:** On Android TV, leaving the IPTV player returns D-pad focus to the channel you were watching (including after changing channel in the guide).
- **Change:** Shahid Connected services Login opens your system browser on desktop; paste the connect script in the Shahid tab console to import the session. On Android TV, Login asks for email/password instead (browser paste is not available).
- **Fix:** Live Sports match details no longer crash when opening Providers / Live TV (hero action row flexed inside a FittedBox).
- **Fix:** On Android TV, Live Sports match details D-pad ↓ from Providers / Live TV reaches the stream list (↑ returns to the tabs).
- **Fix:** Live Sports match details soft dark scrim behind streams again — flush with the title (no card chrome, no side fade); left column fills first on wide.
- **Fix:** Live Sports Streamed streams on Windows unlock without needing Node installed — no more “No playable stream” when Mac/Android TV still play.
- **Fix:** Live Sports Streamed **golf** mirrors unlock again via embedhd.st → exposestrat.st (GOAT `/fetch` still fails to crack golf; odd dead `undefined` iframes are skipped).
- **Change:** Live Sports stream unlock runs in the live pack (not hardcoded Streamed/PPV/WatchFooty paths in the app).
- **Fix:** On Android TV, Live Sports D-pad ↓ from a sport circle or from **Portals** returns to the match you left (scrolls the schedule if needed) instead of getting stuck or jumping to the first row.
- **Fix:** Live Sports merged match cards add viewer counts from every catalog (e.g. PPV + StreamFree), and the details header prefers the sum of listed stream viewers when mirrors report their own counts.
- **Fix:** Live TV finds IPTV channels again on merged match cards — guide TV names (Sky, beIN, …) are kept when catalogs collapse into one card.
- **Fix:** Live TV IPTV channel matching no longer dies empty when the schedule refreshes or the last portal is M3U — search keeps running and falls back to an Xtream/Stalker portal.
