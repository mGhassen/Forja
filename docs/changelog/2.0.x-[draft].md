### Player

- **Fix:** On Windows, leaving picture-in-picture (Expand) restores the main player instead of staying black with a loading spinner.
- **Fix:** On TV, Skip Intro / Next Episode chips no longer pull up the rest of the player controls when you D-pad on them; Next Episode countdown → lands on the cancel X instead of Play.

### TV

- **Fix:** Opening Anime (and other catalog hubs) from the nav lands on hero **View details** again — not **Pick your vibe** or a mid-page row.

### UI

- **Fix:** On desktop hubs, the mouse wheel keeps scrolling the page when it passes over a horizontal row — only the trackpad still pans that row sideways.

### Features

- **Fix:** Dead cloud sessions no longer leave you “signed in” forever — revoked login ends the session; a network blip keeps you offline with a working Retry.
- **Fix:** Scanning or clicking the TV / desktop link QR while signed in on the website opens Connect again instead of a fake “same browser” sign-in error.
- **Fix:** After linking a device to an account that already has packs online, Forja Packs and Addons load on that device again instead of staying empty.
- **Fix:** On Windows, quitting Forja no longer signs you out — your session is still there when you reopen.
