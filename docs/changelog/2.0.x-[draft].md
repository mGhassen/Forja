### Sources
- **Add:** Simkl list sync mode and Auto sync on My List follow your Forja profile across devices (Simkl login stays on each device).
- **Add:** Simkl **Merge + delete** — sync still pulls new Simkl titles, and titles you removed in Forja stay off Simkl (and are not re-imported).
- **Add:** My List shows **Updating…** top-right while Auto sync lists is running.
- **Remove:** Auto sync lists on My List — toggle hidden; opening My List no longer runs list sync (use Sync Now).
- **Fix:** Opening My List with Auto sync on actually runs the sync (and shows the spinner) instead of keeping a warm cached grid.
- **Fix:** After Simkl Sync Now in Settings, My List refreshes instead of keeping the old grid.
- **Fix:** Removing a title from My List clears it on Simkl for real (including Plan to Watch films — uses Simkl’s library remove, not a no-op list call).
- **Fix:** Marking a still-airing series Completed shows that Simkl kept it as Watching (and the pin matches).
- **Fix:** Film list status changes send the movie to Simkl (not as a TV show).

### Player
- **Fix:** Anime / MegaPlay provider subtitles load instead of “Subtitle failed” (embed Referer on the VTT download).
- **Fix:** Picking a stream In-stream row no longer blanks provider subtitles or stacks duplicate In-stream English entries (AnimeKai and similar).
- **Fix:** MediaKit keeps sound and picture in sync on flaky HLS (desktop + Android TV) after a brief buffer hitch — no permanent lipsync drift.

### Features
- **Fix:** Anime details shows Season 1…N for multi-cour franchises; picking a season opens that entry. Related keeps films/specials with type badges (not the other seasons).
- **Fix:** Anime episode lists stay per season (AniList cour) instead of padding every season to the whole TMDB series total.
- **Change:** Anime season chips use Miruro-style labels (Season / OVA / Part + year) and include OVAs in the season rail.
- **Fix:** Anime seasons walk OVA bridges (so Season 1 reaches Season 2) and episode lists ignore AniList’s franchise-absolute “Episode 72” titles.

### UI
- **Add:** Switch between Forja cloud accounts on this device (Settings → Profile & account) without signing out of the others.
- **Change:** Settings → Addons splits built-in addons and pack settings into separate sections (same as the web portal).
- **Fix:** Offline downloads stay private to each account and profile (no shared library across identities).
- **Fix:** My List posters show the Simkl mark on the year · type line when you’re logged in (logo when linked, logo + red cross when not).
- **Fix:** Settings → Data → Export works on macOS (save dialog no longer crashes).

### TV
- **Fix:** Who’s signed in? works with the remote — focus lands on Add account / the account row first; remove X only after Right.
- **Fix:** On Android TV, Simkl “How should lists sync?” opens the focused option list on OK (Keep local / Use Simkl / Merge / Merge + delete / No sync).
- **Fix:** On Android TV, opening a catalog hub (Asian Drama, Anime, Home) moves focus into the hub even when the spotlight is still loading.
- **Fix:** On Android TV, series details / player Episodes **1 - 50** range opens a focused list on OK so you can pick another chunk with the remote.
